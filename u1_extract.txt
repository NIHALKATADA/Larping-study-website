TITLE: Feature normalization and feature scaling, stating why they are applied before model fitting
CONTENT: <p><strong>Definition:</strong> Feature Scaling and Normalization  are data preprocessing methods used to rescale and standardize the ranges of independent features so that differences in numerical magnitudes do not distort algorithm performance.</p>
<ul class="revision-list">
<li><strong>Feature Scaling:</strong> This technique involves linearly transforming numeric features so that they fall within a specific, strictly bounded standard range, most commonly between 0 and 1 (Min-Max scaling). This is particularly useful for algorithms that do not make assumptions about the distribution of the data, such as neural networks or distance-based models like KNN.</li>
<li><strong>Feature Normalization (Standardization):</strong> Often referred to as Z-score normalization, this process transforms the data distribution to center around a mean of zero with a standard deviation of one. It effectively handles outliers better than min-max scaling and is highly recommended for optimization algorithms like Gradient Descent (used in SVMs and Logistic Regression) to ensure smooth convergence.</li>
<li><strong>Purpose:</strong> Both techniques are critically applied before model fitting to ensure that features with naturally large magnitudes (e.g., salary in thousands) do not disproportionately dominate the objective function or distance calculations compared to features with smaller magnitudes (e.g., age in decades), ensuring fair and balanced learning across all variables.</li>
</ul>

--- TOPIC 22 ---
TITLE: Fundamental validation strategies used to evaluate the performance of a trained machine learning model
CONTENT: <p><strong>Definition:</strong> Model Validation Strategies  are systematic partitioning and testing methodologies used to empirically assess a machine learning model's generalization capabilities on unseen data.</p>
<ul class="revision-list">
<li><strong>Train-Test Split:</strong> This is the most fundamental validation strategy, where the complete dataset is randomly partitioned into two mutually exclusive subsets: a training set (typically 70-80% of the data) used strictly for model fitting, and a distinct testing set (20-30%) held out to simulate real-world, unseen data. The model's performance on the testing set provides a baseline estimate of its generalization error and helps detect obvious overfitting.</li>
<li><strong>K-Fold Cross Validation:</strong> This is a far more robust and rigorous technique used to maximize data efficiency and ensure stability. The dataset is divided into K equally sized, mutually exclusive subsets or "folds". The training and evaluation process is then repeated K separate times. In each iteration, the model is trained on K-1 folds and validated on the single remaining fold. The final performance metric is calculated as the average of the results across all K iterations, providing a much more reliable and unbiased estimate of model performance, especially on smaller datasets.</li>
</ul>

<li><strong>Standardization (Z-score):</strong> Transforms data to have a mean of 0 and standard deviation of 1. Formula: $Z = \frac{X - \mu}{\sigma}$. More robust to outliers than min-max scaling and preferred for gradient descent-based algorithms.</li>
<li><strong>Categorical Label Encoding:</strong> Converts categorical string values into numerical integer representations (e.g., Red=0, Green=1, Blue=2). Necessary because ML algorithms require numerical input. However, it may introduce ordinal relationships implicitly; hence, One-Hot Encoding is sometimes preferred for nominal data.</li>
</ul>

<li><strong>Outliers:</strong> Extreme outlier values severely skew models that minimize squared errors (like Linear Regression), as the squared penalty for outliers pulls the decision boundary or regression line away from the majority of the data.</li>
<li><strong>Inconsistencies and Duplicates:</strong> Duplicate entries can cause overfitting to certain patterns, while inconsistencies (like mixed date formats) lead to feature misinterpretation and degraded model fitting.</li>
</ul>
