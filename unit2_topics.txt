<li><strong>This Completely:</strong> This completely eliminates those features from the model.</li>
<li><strong>In Contrast,:</strong> In contrast, Ridge's (L2) circular constraint region lacks sharp corners, so the intersections usually occur off the axes, shrinking coefficients continuously without ever reaching exactly zero.</li>
</ul>

Topic 35: Write the mathematical formulas for Mean Absolute Error (MAE) and Mean Squared Error (MSE) and highlight their differences
<p><strong>Definition:</strong> MAE and MSE  are fundamental loss metrics in regression that measure model accuracy by evaluating the mean absolute error and mean squared error between predictions and ground-truth values.</p>
<ul class="revision-list">
<li><strong>The Formula:</strong> The formula for  Mean Absolute Error (MAE)  is  (1/n) Σ|yi - ŷi| , while the formula for  Mean Squared Error (MSE)  is  (1/n) Σ(yi - ŷi)² .</li>
<li><strong>The Fundamental:</strong> The fundamental difference lies in how they treat errors of different magnitudes.</li>
<li><strong>Because Mse:</strong> Because MSE squares the errors, it disproportionately and heavily penalizes large prediction errors (outliers), pulling the model strongly to correct them.</li>
<li><strong>Conversely, Mae:</strong> Conversely, MAE treats all errors proportionally and linearly, making it a much more robust metric when a dataset contains significant anomalies or extreme outliers that shouldn't dictate the model's overall fit.</li>
</ul>

Topic 36: Root Mean Squared Error (RMSE) and explain its interpretive advantage over Mean Squared Error (MSE)
<p><strong>Definition:</strong> Root Mean Squared Error (RMSE)  is a standard regression metric computed as the square root of Mean Squared Error, expressing model residual dispersion in the original measurement units of the target variable.</p>
<ul class="revision-list">
<li><strong>Root Mean:</strong> Root Mean Squared Error (RMSE)  is defined mathematically as the square root of the MSE:  √((1/n) Σ(yi - ŷi)²) .</li>
<li><strong>The Primary:</strong> The primary interpretive advantage of RMSE over MSE is that the square root operation transforms the error metric back into the exact same units as the original dependent target variable.</li>
<li><strong>For Example,:</strong> For example, if predicting house prices in dollars, MSE would be in 'squared dollars' (which is unintuitive), whereas RMSE would be in straightforward 'dollars', making it much easier for stakeholders to intuitively understand the model's average error magnitude.</li>
</ul>

Topic 37: R2 (R-squared) goodness-of-fit metric and distinguish it from Adjusted R2 in multiple regression
<p><strong>Definition:</strong> R-Squared (R²)  is a statistical goodness-of-fit metric that quantifies the percentage of total variance in the dependent variable explained by the independent variables in a regression model.</p>
<ul class="revision-list">
<li><strong>The R²:</strong> The R² (R-squared) metric measures the proportion of the total variance in the dependent variable that is successfully explained by the regression model, yielding a value between 0 and 1.</li>
<li><strong>However, Standard:</strong> However, standard R² has a flaw in multiple regression: it will mechanically increase or remain the same every time a new independent variable is added, even if that variable is useless.</li>
<li><strong>Adjusted R²:</strong> Adjusted R²  resolves this by actively penalizing the addition of unnecessary independent variables, providing a much more accurate and realistic evaluation of model goodness-of-fit for complex multiple regression models.</li>
</ul>

<p><strong>Definition:</strong> Ordinary Least Squares (OLS)  is a parameter estimation technique in linear regression that determines the best-fitting line by minimizing the sum of squared residuals between observed and predicted values.</p>
<ul class="revision-list">
<li><strong>Concept:</strong> To find the optimal $m$ and $c$, we take the partial derivatives of $J$ with respect to $m$ and $c$, and set them to zero.</li>
<li><strong>Concept:</strong> $\frac{\partial J}{\partial c} = -2 \sum_{i=1}^{n} (y_i - mx_i - c) = 0 \implies \sum y_i = m\sum x_i + nc$</li>
<li><strong>Concept:</strong> $\frac{\partial J}{\partial m} = -2 \sum_{i=1}^{n} x_i(y_i - mx_i - c) = 0 \implies \sum x_i y_i = m\sum x_i^2 + c\sum x_i$</li>
<li><strong>Concept:</strong> Solving these two normal equations yields the optimal formulas for slope $m$ and intercept $c$, which represent the best-fit line minimizing the squared errors.</li>
</ul>

<ul class="revision-list">

<li><strong>Concept:</strong> It iteratively takes steps proportional to the negative gradient until it converges to a local or global minimum.</li>

<p><strong>Definition:</strong> Regression Evaluation Metrics  are quantitative statistical measures used to assess the predictive accuracy, error magnitude, and explanatory goodness-of-fit of regression models.</p>
<ul class="revision-list">

<li><strong>Adjusted $R^2$:</strong> Modifies $R^2$ by penalizing the addition of non-useful predictive features.</li>
</ul>
