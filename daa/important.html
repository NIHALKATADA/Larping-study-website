Q79. Consider m=2,p=4,s=5,i=7 Generate Huffman Tree Calculate number of bits using frequency of characters and number of bits required to represent those characters.

Unit IV CO4 | Bloom L3 3 Marks End Term Score: 9.7

Given character frequencies: $m: 2, p: 4, s: 5, i: 7$ (total 18). We construct the optimal Huffman Tree using greedy min-heap merges:

  1. Merge 1: Combine $m(2)$ and $p(4)$ into node $(6)$ with edge bits $0, 1$.
  2. Merge 2: Combine $s(5)$ and node $(6)$ into node $(11)$ with edge bits $0, 1$.
  3. Merge 3: Combine $i(7)$ and node $(11)$ into root $(18)$.
CharacterFrequency ($f$)CodeBits ($l$)Total ($f \times l$)
$i$7017
$s$510210
$m$211036
$p$4111312

Total Bits: $\sum (f_i \times l_i) = 7 + 10 + 6 + 12 = \mathbf{35\text{ bits}}$ (versus fixed 2-bit encoding requiring $18 \times 2 = 36$ bits).

Huffman merges the lowest frequencies bottom-up: (m,p)->6, then (s,6)->11, then (i,11)->18. Assigning binary codes produces 1 bit for 'i', 2 for 's', and 3 each for 'm' and 'p'. Total size = 35 bits.

Q68. Explain the backtracking approach to the 4-Queens problem and show one valid arrangement of queens.

Unit V CO5 | Bloom L3 3 Marks End Term Score: 9.6

The 4-Queens problem positions 4 queens on a $4 \times 4$ chessboard such that no two attack each other. Backtracking systematically explores placements row by row, pruning branches when column or diagonal conflicts occur.

Backtracking Execution Steps:

  1. Row 1: Place $Q_1$ at column 1. In Row 2, column 3 is safe. In Row 3, all columns $(1,2,3,4)$ are attacked. Backtrack!
  2. Row 1: Move $Q_1$ to column 2 ($X[1] = 2$).
  3. Row 2: Testing columns yields column 4 safe ($X[2] = 4$).
  4. Row 3: Column 1 is safe from both earlier queens ($X[3] = 1$).
  5. Row 4: Testing columns reveals column 3 is safe ($X[4] = 3$).

Valid Arrangement: The resulting solution vector is $X = [2, 4, 1, 3]$ (placing queens at $(1,2), (2,4), (3,1), (4,3)$), where all column and diagonal constraints are completely satisfied.

Place queens row by row. Starting Queen 1 at column 1 leads to an impasse on row 3. Backtracking moves Queen 1 to column 2, leading to the valid configuration: columns 2, 4, 1, and 3.

Q80. Explain how dynamic programming can solve the LCS problem. Illustrate the construction of the table using two short strings.

Unit IV CO4 | Bloom L3 3 Marks End Term Score: 9.6

The Longest Common Subsequence (LCS) problem finds the maximum-length subsequence present in two sequences $X$ and $Y$. Dynamic Programming solves it by defining $L[i,j]$ as the LCS length of prefixes $X[1\dots i]$ and $Y[1\dots j]$ using the recurrence:

$$L[i,j] = \begin{cases} 0 & \text{if } i=0 \text{ or } j=0 \\ L[i-1,j-1] + 1 & \text{if } X[i] = Y[j] \\ \max(L[i-1,j], L[i,j-1]) & \text{if } X[i] \neq Y[j] \end{cases}$$

Illustration with $X = \text{"ABA"}$ and $Y = \text{"BA"}$:

  1. Initialize row $0$ and column $0$ to 0.
  2. For $X[1]=\text{'A'}$: $L[1,1]=0$, $L[1,2]=L[0,1]+1=1$.
  3. For $X[2]=\text{'B'}$: $L[2,1]=L[1,0]+1=1$, $L[2,2]=\max(L[1,2], L[2,1])=1$.
  4. For $X[3]=\text{'A'}$: $L[3,1]=\max(1,0)=1$, $L[3,2]=L[2,1]+1=2$.

Traceback: From cell $(3,2)$ with value 2, diagonal jumps identify characters $\text{'A'}$ at $(3,2)$ and $\text{'B'}$ at $(2,1)$, yielding the common subsequence $\text{LCS} = \text{"BA"}$ with length 2 in $O(m \cdot n)$ time.

DP creates a 2D grid matching string prefixes. When characters match, add 1 to the diagonal; otherwise take the maximum of top and left cells. Backtracking from the bottom-right corner reveals the LCS "BA" of length 2.

Q7. Solve the following recurrence using the substitution method: T(n) = 2T(n/2) + n

Unit III CO3 | Bloom L4 5 Marks Midterm Score: 9.5

Recurrence: T(n) = 2T(n/2) + n

Guess: T(n) = O(n log n). We need to prove that T(n) ≤ c · n log n for some constant c > 0.

Proof by induction:

  • Assume the bound holds for n/2, i.e., T(n/2) ≤ c · (n/2) log(n/2).
  • Substitute this into the recurrence:
    T(n) ≤ 2 · [c · (n/2) log(n/2)] + n
    T(n) ≤ c · n log(n/2) + n
    T(n) ≤ c · n(log n - log 2) + n
    T(n) ≤ c · n log n - c · n + n
  • We want T(n) ≤ c · n log n. This holds true if:
    c · n log n - c · n + n ≤ c · n log n
    -c · n + n ≤ 0
    c ≥ 1

Since we can choose c ≥ 1, the guess is correct.

Result: T(n) = O(n log n)

Quick Recall:

  • Assume the bound holds for n/2, i.e., T(n/2) ≤ c · (n/2) log(n/2).

  • We want T(n) ≤ c · n log n. This holds true if: c · n log n - c · n + n ≤ c · n log n -c · n + n ≤ 0 c ≥ 1

Q66. Explain backtracking in the N-Queens problem.

Unit V CO5 | Bloom L3 3 Marks End Term Score: 9.4

Backtracking solves the $N$-Queens problem by positioning queens row by row from row $1$ to $N$. For each row $k$, candidate columns $col \in \{1 \dots N\}$ are systematically tested against previously placed queens using a bounding function Place(k, col).

Safety Bounding Condition: A candidate placement is valid if and only if no earlier queen $i < k$ shares the same column ($X[i] == col$) or the same diagonal ($|X[i] - col| == |k - i|$). If safe, the algorithm sets $X[k] = col$ and recursively explores row $k+1$. If every column in row $k$ causes a conflict, the current state is identified as a dead end; the algorithm abandons the subtree and backtracks to row $k-1$ to advance the previous queen to alternative remaining columns.

bool Place(int k, int col) {
    for (int i = 1; i < k; i++)
        if (X[i] == col || abs(X[i] - col) == abs(i - k))
            return false;
    return true;
}

By executing Depth-First Search with bounding, backtracking dynamically prunes fruitless paths, reducing the search space from $O(N^N)$ down to a small fraction of $O(N!)$. The search completes when all $N$ queens are safely placed.

Place queens row by row. Before setting a queen, check if earlier queens threaten that column or diagonal. If a row has no safe columns, backtrack to the previous row and try its next column.

Place Function Bounding Condition Subtree Pruning Recursive Backtracking Diagonal Clash Check State Space Reduction

Backtracking is a systematic algorithmic paradigm for solving constraint satisfaction problems by incrementally constructing candidate solutions within a state-space tree. It traverses candidate states using Depth-First Search (DFS) and applies bounding functions.

Q65. Explain N-Queens problem.

Unit V CO5 | Bloom L2 3 Marks End Term Score: 9.1

The $N$-Queens problem is a classic combinatorial constraint satisfaction problem that requires placing $N$ non-attacking chess queens on an $N \times N$ chessboard. Under standard chess rules, a queen attacks any piece along the same row, column, or diagonal.

Problem Formulation & Constraints:

  • Representation: A 1D array $X[1 \dots N]$ where $X[i] = j$ signifies that Queen $i$ occupies row $i$ and column $j$. This representation inherently satisfies the row constraint of exactly one queen per row.
  • Column Constraint: No two queens share a column: $X[i] \neq X[k]$ for all distinct $i, k$.
  • Diagonal Constraint: No two queens share a major or minor diagonal: $|X[i] - X[k]| \neq |i - k|$ for all $i \neq k$.

Solutions exist for all $N \ge 4$ (no solutions exist for $N=2$ and $N=3$, while $N=1$ is trivial).

Place $N$ chess queens on an $N \times N$ chessboard such that no two queens threaten each other horizontally, vertically, or diagonally. We record the board using an array where index is the row and value is the column.

Q1. Define the Divide and Conquer paradigm. Explain its three basic steps with a suitable example.

Unit III CO3 | Bloom L2 5 Marks Midterm Score: 9.0
Divide and Conquer Paradigm

The Divide and Conquer paradigm is an algorithmic design strategy that solves a problem by recursively breaking it down into two or more sub-problems of the same or related type, until these become simple enough to be solved directly. The solutions to the sub-problems are then combined to give a solution to the original problem.

It consists of three basic steps:

  • Divide: Break the given problem into smaller sub-problems.
  • Conquer: Recursively solve these sub-problems. If the sub-problem size is small enough, solve it directly (base case).
  • Combine: Merge the solutions of the sub-problems to form the solution of the original problem.
Example: Merge Sort

In Merge Sort:

  • Divide: Divide the unsorted array of size n into two sub-arrays of size n/2.
  • Conquer: Recursively sort the two sub-arrays using Merge Sort.
  • Combine: Merge the two sorted sub-arrays into a single sorted array.

Quick Recall:

  • Divide: Break the given problem into smaller sub-problems.
  • Conquer: Recursively solve these sub-problems. If the sub-problem size is small enough, solve it directly (base case).
  • Combine: Merge the solutions of the sub-problems to form the solution of the original problem.

Occurs when the pivot randomly divides the array into proportional splits (e.g., 9-to-1 split or 3-to-1 split). Even an unbalanced split like 99-to-1 results in an O(n log n) running time, as the depth of the tree is bounded by a logarithmic function.

Worst Case: O(n²)

Occurs when the pivot is consistently the smallest or largest element, leading to completely unbalanced partitions (one sub-array of size n-1, and one of size 0).
