Q1. Define an algorithm. Write any four characteristics of a good algorithm.

Unit I CO1 | Bloom L1 2 Marks Midterm

An algorithm is a step-by-step procedure or set of rules to be followed in calculations or other problem-solving operations. Characteristics:

  • Finiteness: Must terminate after a finite number of steps.
  • Definiteness: Each step must be precisely defined.
  • Input: Has zero or more inputs.
  • Output: Produces one or more outputs.
  • Effectiveness: Operations must be basic enough to be done exactly and in finite time.

Quick Recall:

  • Finiteness: Must terminate after a finite number of steps.
  • Definiteness: Each step must be precisely defined.
  • Input: Has zero or more inputs.

Q3. Differentiate between time complexity and space complexity with one example.

Unit I CO1 | Bloom L2 3 Marks Midterm

Q1. Define algorithm correctness. Differentiate between partial correctness and total correctness with suitable examples.

Unit II CO2 | Bloom L1 2 Marks Midterm

Algorithm Correctness: An algorithm is correct if, for every valid input, it halts and produces the correct output as defined by its specifications.

  • Partial Correctness: If the algorithm halts, it produces the correct output (but it might not halt). Example: A while(true) loop that searches for an element and breaks when found. If the element isn't there, it might loop forever.
  • Total Correctness: The algorithm is guaranteed to halt, and when it halts, it produces the correct output. Example: A standard for-loop based linear search that scans an array from start to end and returns true/false.

Q2. What is a loop invariant? Explain the three steps—initialization, maintenance, and termination—used to prove the correctness of an algorithm.

Unit II CO2 | Bloom L1 3 Marks Midterm

A loop invariant is a condition or property that is true before and after each iteration of a loop. It is used to prove the correctness of loop structures.

  1. Initialization: The invariant must be true before the first iteration of the loop.
  2. Maintenance: If it is true before an iteration of the loop, it remains true before the next iteration.
  3. Termination: When the loop terminates, the invariant gives us a useful property that helps show the algorithm is correct.

Quick Recall:

  • Maintenance: If it is true before an iteration of the loop, it remains true before the next iteration.

Q3. Explain how loop invariants can be used to prove the correctness of a sorting algorithm.

Unit II CO2 | Bloom L2 5 Marks Midterm

In sorting algorithms like Insertion Sort, a loop invariant can be defined as: 'At the start of each iteration i, the subarray A[0...i-1] consists of the elements originally in A[0...i-1], but in sorted order.'

  • Initialization: For i=1, A[0] is just a single element, which is trivially sorted.
  • Maintenance: During iteration i, the algorithm inserts A[i] into its correct position in A[0...i-1], making A[0...i] sorted.
  • Termination: The loop ends when i = n. The invariant states that A[0...n-1] is sorted, which means the entire array is sorted, proving correctness.

Quick Recall:

  • Initialization: For i=1, A[0] is just a single element, which is trivially sorted.
  • Maintenance: During iteration i, the algorithm inserts A[i] into its correct position in A[0...i-1], making A[0...i] sorted.
  • Termination: The loop ends when i = n. The invariant states that A[0...n-1] is sorted, which means the entire array is sorted, proving correctness.

Q1. Define the Divide and Conquer paradigm. Explain its three basic steps with a suitable example.

Unit III CO3 | Bloom L2 5 Marks Midterm Score: 9.0
Divide and Conquer Paradigm

The Divide and Conquer paradigm is an algorithmic design strategy that solves a problem by recursively breaking it down into two or more sub-problems of the same or related type, until these become simple enough to be solved directly. The solutions to the sub-problems are then combined to give a solution to the original problem.

It consists of three basic steps:

  • Divide: Break the given problem into smaller sub-problems.
  • Conquer: Recursively solve these sub-problems. If the sub-problem size is small enough, solve it directly (base case).
  • Combine: Merge the solutions of the sub-problems to form the solution of the original problem.
Example: Merge Sort

In Merge Sort:

  • Divide: Divide the unsorted array of size n into two sub-arrays of size n/2.
  • Conquer: Recursively sort the two sub-arrays using Merge Sort.
  • Combine: Merge the two sorted sub-arrays into a single sorted array.

Quick Recall:

  • Divide: Break the given problem into smaller sub-problems.
  • Conquer: Recursively solve these sub-problems. If the sub-problem size is small enough, solve it directly (base case).
  • Combine: Merge the solutions of the sub-problems to form the solution of the original problem.

General Structure

The general structure of a Divide and Conquer algorithm can be represented recursively:

Algorithm DAndC(P)
{
    if Small(P) then
        return S(P); // Solve directly
    else
    {
        Divide P into smaller instances P1, P2, ..., Pk, k ≥ 1;
        Apply DAndC to each of these subproblems;
        return Combine(DAndC(P1), DAndC(P2), ..., DAndC(Pk));

  1. Divide: Split each n-digit number into two halves (high and low parts).

Q10. What is a recurrence relation? How it can be solved?

Unit II CO2 | Bloom L2 3 Marks End Term

A Recurrence Relation is an equation or inequality that defines a function $T(n)$ in terms of its values on smaller inputs (e.g., $T(n) = 2T(n/2) + O(n)$). In computer science, they describe the execution time of recursive algorithms.

Major Methods to Solve Recurrence Relations:

  1. Substitution Method: Guess the form of the mathematical solution and then use mathematical induction to find the constants and verify the solution.
  2. Recursion Tree Method: Visualizes the recurrence as a tree of recursive calls where nodes represent the cost incurred at each level; summing the costs across all levels yields the total cost.
  3. Master Theorem Method: A cookbook formula that provides instantaneous asymptotic solutions for recurrences of the form $T(n) = aT(n/b) + f(n)$ by comparing $f(n)$ with $n^{\log_b a}$.

Quick Recall: An equation expressing $T(n)$ using smaller inputs (e.g., $T(n/2)$). Solved via: (1) Substitution Method (guess + induction), (2) Recursion Tree (sum levels), (3) Master Method (formula for $aT(n/b) + f(n)$).

Q12. What is the principle of optimality? Explain in detail

Unit IV CO4 | Bloom L2 3 Marks End Term Score: 9.2

The Principle of Optimality (originally formulated by Richard Bellman) states that:

"An optimal policy has the property that whatever the initial state and initial decision are, the remaining decisions must constitute an optimal policy with regard to the state resulting from the first decision."

In algorithmic terms, a problem satisfies the principle of optimality (also called Optimal Substructure) if an optimal solution to the overall problem can be constructed efficiently from optimal solutions to its constituent subproblems.

Significance:

  • It is the foundational theoretical requirement for both Dynamic Programming and Greedy Algorithms.
  • Valid Example: Shortest Path in Graphs. If the shortest path from $A$ to $C$ passes through $B$, then the sub-path from $A$ to $B$ must also be the shortest path between $A$ and $B$.
  • Counter-Example: Longest Simple Path in general graphs does NOT satisfy the principle of optimality (cannot compose independently).

Quick Recall: An optimal solution to a problem contains optimal solutions to its subproblems. Necessary prerequisite for Dynamic Programming and Greedy algorithms (e.g., shortest paths).

Q14. Explain N-Queens problem.

The N-Queens Problem is a classic combinatorial constraint satisfaction problem that requires placing $N$ non-attacking chess queens on an $N \times N$ chessboard such that no two queens threaten each other.

  2. The same column.

Q16. Explain Big-O, Big-Ω and Big-Θ notation with examples.

The three fundamental asymptotic notations used to bound algorithm running time:

  1. Big-O Notation ($O$ - Asymptotic Upper Bound):$$f(n) = O(g(n)) \iff \exists c > 0, n_0 > 0 \text{ such that } 0 \le f(n) \le c \cdot g(n) \quad \forall n \ge n_0$$Represents the worst-case ceiling. Example: $3n + 5 = O(n)$ (with $c = 4, n_0 = 5$).
  2. Big-Omega Notation ($\Omega$ - Asymptotic Lower Bound):$$f(n) = \Omega(g(n)) \iff \exists c > 0, n_0 > 0 \text{ such that } 0 \le c \cdot g(n) \le f(n) \quad \forall n \ge n_0$$Represents the best-case floor. Example: $2n^2 - 3n = \Omega(n^2)$ (with $c = 1, n_0 = 3$).
  3. Big-Theta Notation ($\Theta$ - Asymptotically Tight Bound):$$f(n) = \Theta(g(n)) \iff \exists c_1, c_2 > 0, n_0 > 0 \text{ such that } 0 \le c_1 \cdot g(n) \le f(n) \le c_2 \cdot g(n) \quad \forall n \ge n_0$$Sandwiches $f(n)$ from both above and below. Holds if and only if $f(n) = O(g(n))$ and $f(n) = \Omega(g(n))$. Example: $6n^2 + 4n = \Theta(n^2)$.

Quick Recall:

  • Big-O ($O$): Upper bound / worst-case ceiling ($f(n) \le c \cdot g(n)$).
  • Big-Omega ($\Omega$): Lower bound / best-case floor ($f(n) \ge c \cdot g(n)$).
  • Big-Theta ($\Theta$): Tight bound sandwiched between constants ($c_1 g(n) \le f(n) \le c_2 g(n)$).

Q17. Explain the aggregate method of amortized analysis.

Unit I CO1 | Bloom L2 3 Marks End Term

In Amortized Analysis, the average running time of an operation over a worst-case sequence of $n$ operations is computed, guaranteeing that the average cost per operation is small even if an occasional single operation is expensive.

The Aggregate Method:

  • In the aggregate method, we determine the total worst-case cost $T(n)$ for an entire sequence of $n$ operations.
  • The amortized cost per operation is then directly computed as:$$\text{Amortized Cost} = \frac{T(n)}{n}$$
  • Every operation in the sequence is assigned the same identical amortized cost, regardless of whether it was cheap or expensive.
  • Classic Example: Dynamic Array Resizing. Appending $n$ items triggers occasional array doubling ($1 + 2 + 4 + \dots + n = 2n$ copy cost) plus $n$ simple inserts. Total cost $T(n) \le 3n$. Amortized cost per append $= \frac{3n}{n} = O(1)$.

Quick Recall: Finds the total worst-case time $T(n)$ for a sequence of $n$ operations and divides by $n$ ($\text{Cost} = T(n)/n$). Assigns every operation the same average cost (e.g., dynamic array append is amortized $O(1)$).

Q50. Explain the Floyd–Warshall algorithm and demonstrate how it updates an all-pairs distance matrix.

Unit V CO5 | Bloom L3 5 Marks End Term Score: 9.5

The Floyd-Warshall Algorithm is a Dynamic Programming algorithm that finds the shortest paths between all pairs of vertices in a directed, weighted graph (allowing negative edge weights, but no negative cycles).

Core DP Formulation:

Let $D^{(k)}[i, j]$ be the length of the shortest path from vertex $i$ to vertex $j$ using only intermediate vertices from the set $\{1, 2, \dots, k\}$.

$$D^{(k)}[i, j] = \min\left(D^{(k-1)}[i, j],\, D^{(k-1)}[i, k] + D^{(k-1)}[k, j]\right)$$

How the Matrix is Updated:

  1. Initialization ($D^{(0)}$): Direct edge weights from adjacency matrix ($D[i, i] = 0$, $D[i, j] = w(i, j)$, or $\infty$ if no direct edge).
  2. Iteration over $k = 1$ to $|V|$: At each phase $k$, vertex $k$ is considered as a potential intermediate waypoint. If travelling from $i$ to $k$ and then $k$ to $j$ is shorter than the currently recorded distance from $i$ to $j$, the matrix cell is updated.
  3. Final Matrix ($D^{(|V|)}$): Contains the true all-pairs shortest path distances.

Complexity: Three nested loops running $|V|$ times yield a time complexity of $\mathbf{\Theta(V^3)}$ and space complexity of $\Theta(V^2)$.

Quick Recall: All-Pairs Shortest Path via DP. Triple loop over intermediate node $k$: $D[i, j] = \min(D[i, j], D[i, k] + D[k, j])$. Time complexity $\Theta(V^3)$.

Q64. Explain why Rabin–Karp verifies the characters after finding equal hash values.

Q96. Explain the Master Method and demonstrate how its three standard cases are used to solve recurrences.

Unit II CO2 | Bloom L2 5 Marks End Term Score: 9.6

The Master Method solves recurrences of the form:

$$T(n) = a T(n/b) + f(n) \quad \text{where } a \ge 1, b > 1$$

It compares $f(n)$ asymptotically with the critical function $n^{\log_b a}$:

  1. Case 1 ($f(n)$ grows polynomially slower than $n^{\log_b a}$):
    If $f(n) = O(n^{\log_b a - \epsilon})$ for some $\epsilon > 0$:$$T(n) = \mathbf{\Theta(n^{\log_b a})}$$Example: $T(n) = 8T(n/2) + 1000n^2$. $n^{\log_2 8} = n^3$. Since $n^2 = O(n^{3-1})$, $T(n) = \Theta(n^3)$.
  2. Case 2 ($f(n)$ and $n^{\log_b a}$ have the same order of growth):
    If $f(n) = \Theta(n^{\log_b a} \log^k n)$ for $k \ge 0$:$$T(n) = \mathbf{\Theta(n^{\log_b a} \log^{k+1} n)}$$Example: $T(n) = 2T(n/2) + n$. $n^{\log_2 2} = n$. Here $f(n) = n = \Theta(n^1 \log^0 n) \implies T(n) = \Theta(n \log n)$.
  3. Case 3 ($f(n)$ grows polynomially faster and satisfies regularity):
    If $f(n) = \Omega(n^{\log_b a + \epsilon})$ for some $\epsilon > 0$ and $a f(n/b) \le c f(n)$ for $c < 1$:$$T(n) = \mathbf{\Theta(f(n))}$$Example: $T(n) = 2T(n/2) + n^2$. $n^{\log_2 2} = n$. Since $n^2 = \Omega(n^{1+1})$, $T(n) = \Theta(n^2)$.

Quick Recall: Compares $f(n)$ with $n^{\log_b a}$. Case 1: tree leaves dominate $\implies \Theta(n^{\log_b a})$. Case 2: equal work per level $\implies \Theta(n^{\log_b a} \log n)$. Case 3: root dominates $\implies \Theta(f(n))$.

Q97. Explain the matrix-chain multiplication problem and show how the split position affects the number of scalar multiplications.

The Matrix Chain Multiplication Problem finds the optimal parenthesization of a product of $n$ matrices $A_1 A_2 \dots A_n$ that minimizes total scalar multiplications. Matrix multiplication is associative ($(AB)C = A(BC)$), but the parenthesization dramatically impacts operations.

Impact of Split Position $k$:

To multiply $A_{i..j}$, we choose an intermediate split point $k$ ($i \le k < j$) such that $(A_i \dots A_k)(A_{k+1} \dots A_j)$.

Recurrence: $m[i, j] = \min_{i \le k < j} \{m[i, k] + m[k+1, j] + p_{i-1} p_k p_j\}$.

Concrete Demonstration on 3 Matrices:

  • Dimensions: $A_1(10 \times 100), A_2(100 \times 5), A_3(5 \times 50)$.
  • Split at $k = 1$ ($(A_1(A_2 A_3))$): Cost $= (100 \times 5 \times 50) + (10 \times 100 \times 50) = 25,000 + 50,000 = \mathbf{75,000}$.
  • Split at $k = 2$ ($((A_1 A_2)A_3)$): Cost $= (10 \times 100 \times 5) + (10 \times 5 \times 50) = 5,000 + 2,500 = \mathbf{7,500}$.

Splitting at $k=2$ is 10 times faster than splitting at $k=1$, demonstrating the critical role of optimal parenthesization.

Quick Recall: Matrix multiplication is associative. Different parenthesization splits $k$ yield massive performance differences: $(A_1(A_2 A_3))$ costs 75,000 multiplications vs $((A_1 A_2)A_3)$ costing only 7,500 (10x reduction).
