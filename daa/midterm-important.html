Q14. Find the time complexity: for(i = 1; i <= n; i++) { for(j = 1; j <= i; j++) { count++; } }

Unit I CO1 | Bloom L3 5 Marks Midterm Score: 9.5

The outer loop runs n times. The inner loop runs i times. The total number of executions is the sum of the first n integers:

Summation: 1 + 2 + 3 + ... + n = n(n+1)/2 = (n2 + n)/2.

Final time complexity: O(n2).

Q15. Find the time complexity: for(i = 1; i <= n; i = i * 2) { printf("%d", i); }

Unit I CO1 | Bloom L3 5 Marks Midterm Score: 9.5

The loop variable i starts at 1 and multiplies by 2 each time. Sequence of i values: 1, 2, 4, 8, ..., 2k.

The loop terminates when 2k > n, which means k ≈ log2(n). The total iterations is roughly log2(n).

Final time complexity: O(log n).

Q7. Solve the following recurrence using the substitution method: T(n) = 2T(n/2) + n

Unit III CO3 | Bloom L4 5 Marks Midterm Score: 9.5

Recurrence: T(n) = 2T(n/2) + n

Guess: T(n) = O(n log n). We need to prove that T(n) ≤ c · n log n for some constant c > 0.

Proof by induction:

  • Assume the bound holds for n/2, i.e., T(n/2) ≤ c · (n/2) log(n/2).
  • Substitute this into the recurrence:
    T(n) ≤ 2 · [c · (n/2) log(n/2)] + n
    T(n) ≤ c · n log(n/2) + n
    T(n) ≤ c · n(log n - log 2) + n
    T(n) ≤ c · n log n - c · n + n
  • We want T(n) ≤ c · n log n. This holds true if:
    c · n log n - c · n + n ≤ c · n log n
    -c · n + n ≤ 0
    c ≥ 1

Since we can choose c ≥ 1, the guess is correct.

Result: T(n) = O(n log n)

Q18. Compare Bubble, Selection, Insertion on 64, 34, 25, 12, 22, 11, 90, 45, 78, 33.

Unit II CO2 | Bloom L4 5 Marks Midterm Score: 9.0

All three have worst-case O(n^2). However, for an almost-sorted array, Insertion Sort is highly preferable because its best-case time complexity approaches O(n) as it only compares a few elements before finding the correct position. Bubble sort can also be O(n) if a flag is used to break early, but it generally involves more swaps. Selection Sort is always O(n^2) comparisons.

Q1. Define the Divide and Conquer paradigm. Explain its three basic steps with a suitable example.

Unit III CO3 | Bloom L2 5 Marks Midterm Score: 9.0
Divide and Conquer Paradigm

The Divide and Conquer paradigm is an algorithmic design strategy that solves a problem by recursively breaking it down into two or more sub-problems of the same or related type, until these become simple enough to be solved directly. The solutions to the sub-problems are then combined to give a solution to the original problem.

It consists of three basic steps:

  • Divide: Break the given problem into smaller sub-problems.
  • Conquer: Recursively solve these sub-problems. If the sub-problem size is small enough, solve it directly (base case).
  • Combine: Merge the solutions of the sub-problems to form the solution of the original problem.
Example: Merge Sort

In Merge Sort:

  • Divide: Divide the unsorted array of size n into two sub-arrays of size n/2.
  • Conquer: Recursively sort the two sub-arrays using Merge Sort.
  • Combine: Merge the two sorted sub-arrays into a single sorted array.

Q35. Explain the best-case, average-case, and worst-case time complexity of Quick Sort.

Best Case: O(n log n)

Occurs when the pivot chosen at each step divides the array into two roughly equal halves. The recursion tree has a depth of log(n) and partitioning at each level takes O(n) time. Recurrence: T(n) = 2T(n/2) + O(n)

Average Case: O(n log n)

Occurs when the pivot randomly divides the array into proportional splits (e.g., 9-to-1 split or 3-to-1 split). Even an unbalanced split like 99-to-1 results in an O(n log n) running time, as the depth of the tree is bounded by a logarithmic function.

Worst Case: O(n²)

Occurs when the pivot is consistently the smallest or largest element, leading to completely unbalanced partitions (one sub-array of size n-1, and one of size 0). This creates a skewed recursion tree of depth n. Example: sorting an already sorted array when the first or last element is chosen as the pivot. Recurrence: T(n) = T(n-1) + O(n)
