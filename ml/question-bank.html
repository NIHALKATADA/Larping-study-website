Q29. Differentiate between Ridge L2 and Lasso L1 regularization penalties.

Q30. Why does Lasso L1 regularization perform automatic feature selection while Ridge L2 does not?

Because these coefficients become zero, Lasso effectively performs automatic feature selection by dropping irrelevant variables from the model. Ridge (L2) regularization, utilizing a squared penalty, shrinks coefficients asymptotically towards zero but rarely makes them exactly zero, meaning all features remain in the final model.

Q32. State the formula for Root Mean Squared Error (RMSE) and explain its advantage over MSE.

Furthermore, like MSE, it heavily penalizes larger errors because the errors are squared before being averaged, which is highly beneficial when large errors are particularly undesirable.

Q34. Why is Adjusted R2 preferred over standard R2 in Multiple Linear Regression?

Adjusted R-squared is preferred because it incorporates a penalty for adding non-significant predictors, thereby adjusting for the number of terms in the model. This provides a more accurate and reliable measure of goodness-of-fit for multiple linear regression models, preventing overfitting by ensuring only useful variables increase the score.

Q37. Write the single-sample log-loss (binary cross-entropy) cost function formula.

Unit III CO3 | Bloom L1 2 Marks Midterm

Binary Cross-Entropy (Log-Loss) is a performance metric and cost function for binary classification models that quantifies the penalty for classification errors based on predicted probabilities. The single-sample log-loss, also known as binary cross-entropy, is calculated using the formula Cost = - [y * log(ŷ) + (1 - y) * log(1 - ŷ)]. In this equation, y represents the true binary label of the sample (either 0 or 1), and ŷ represents the model's predicted probability that the sample belongs to class 1. This cost function heavily penalizes highly confident but incorrect predictions, guiding the model toward more accurate probability estimates.

Q38. Define a decision boundary in a binary classification problem.

Depending on the algorithm and data, this boundary can be linear (like a hyperplane in SVM or Logistic Regression) or non-linear (like in Decision Trees or RBF-kernel SVMs). Any new data point falling on one side of this boundary is assigned to the first class, while points on the other side are assigned to the second class.

Ordinary Least Squares (OLS)

Ordinary Least Squares (OLS) is a parameter estimation technique in linear regression that determines the best-fitting line by minimizing the sum of squared residuals between observed and predicted values. Simple Linear Regression models the relationship between a dependent variable $y$ and an independent variable $x$ as: $\hat{y} = mx + c$, where $m$ is the slope and $c$ is the intercept.

Objective Function: The OLS method aims to minimize the Sum of Squared Residuals (SSR) between actual and predicted values. The cost function $J$ is:
$J(m, c) = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 = \sum_{i=1}^{n} (y_i - (mx_i + c))^2$

Derivation Framework:

  • To find the optimal $m$ and $c$, we take the partial derivatives of $J$ with respect to $m$ and $c$, and set them to zero.

  • Solving these two normal equations yields the optimal formulas for slope $m$ and intercept $c$, which represent the best-fit line minimizing the squared errors.

Log-Loss (Binary Cross-Entropy) is a convex loss function used in binary classification that penalizes divergent probabilistic predictions relative to the true binary ground truth labels. The cost function for Logistic Regression is Log-Loss, also known as Binary Cross-Entropy.

Formula:

  • Log-Loss, conversely, guarantees a convex cost function with a single global minimum, penalizing confident wrong predictions heavily using logarithms.

Confusion Matrix and Metrics

A Confusion Matrix is a specific tabular layout that visualizes the performance of an algorithm by comparing predicted classifications against actual ground truth outcomes. Confusion Matrix: A $2 \times 2$ table used to evaluate binary classification performance.

  • True Positive (TP): Predicted Positive, Actual Positive
  • True Negative (TN): Predicted Negative, Actual Negative
  • False Positive (FP - Type I Error): Predicted Positive, Actual Negative
  • False Negative (FN - Type II Error): Predicted Negative, Actual Positive

Evaluation Formulas:

  • Accuracy: $\frac{TP + TN}{TP + TN + FP + FN}$. The overall correct predictions.
  • Precision: $\frac{TP}{TP + FP}$. Out of all predicted positives, how many were actually positive?
  • Recall (Sensitivity): $\frac{TP}{TP + FN}$. Out of all actual positives, how many did the model find?
  • F1-Score: $2 \times \frac{Precision \times Recall}{Precision + Recall}$ (Harmonic Mean).

Importance of F1-Score for Imbalanced Data:
If a dataset has 99% Negative and 1% Positive instances, a model predicting "Negative" every time achieves 99% accuracy but fails its actual purpose. F1-Score completely ignores True Negatives, focusing strictly on the model\'s ability to correctly balance identifying the minority Positive class (Recall) without generating excessive false alarms (Precision).

Q159. Describe the assignment and centroid update steps in the K-Means clustering algorithm.

Unit IV CO4 | Bloom L2 3 Marks End Term Score: 9.2

K-Means operates via an iterative Expectation-Maximization (EM) optimization framework minimizing Within-Cluster Sum of Squares (WCSS):

  1. Assignment Step (Expectation Step):

    Given fixed centroid locations $\{\mu_1, \mu_2, \dots, \mu_K\}$, each data point $x_i \in D$ is assigned to its nearest centroid according to minimum Euclidean distance:

    $$c_i = \arg\min_{k \in \{1, \dots, K\}} \|x_i - \mu_k\|^2$$

    This partitions the feature space into $K$ convex Voronoi regions $S_k = \{x_i \mid c_i = k\}$.

  2. Centroid Update Step (Maximization Step):

    Given the fixed cluster assignments $S_k$, each centroid $\mu_k$ is recalculated as the arithmetic mean of all data points currently belonging to cluster $S_k$:

    $$\mu_k = \frac{1}{|S_k|} \sum_{x_i \in S_k} x_i$$
  3. Termination: The algorithm alternates between Assignment and Update until convergence criteria are met (centroids shift by $< \epsilon$, assignments freeze, or maximum iterations reached).
  • Step 1 (Assignment): Every data point calculates its distance to all $K$ centers and joins whichever center is closest.
  • Step 2 (Update): Each centroid moves to the exact geographic average (mean) position of all its assigned members.
  • Loop: Repeat Steps 1 and 2 until the centroids stop moving (convergence).

Q162. Analyze why K-Means is sensitive to the initial placement of centroids and to outliers, and explain how K-Means++ initialization reduces this sensitivity.

Sensitivity Analysis of Standard K-Means:

  • Initial Centroid Sensitivity: The K-Means objective function (WCSS) is non-convex with numerous local minima. Random initialization (Forgy method) often places multiple initial centroids within the same natural cluster, resulting in sub-optimal convergence where distinct true clusters are erroneously merged while others are artificially split.
  • Outlier Sensitivity: Centroid locations are updated via the arithmetic mean: $\mu_k = \frac{1}{|S_k|} \sum x_i$. Because the Euclidean distance is squared in WCSS, extreme anomalous data points exert massive leverage, dragging the centroid far away from the true dense cluster core.

How K-Means++ Resolves Initialization:

  1. Selects the first centroid $\mu_1$ uniformly at random from the dataset $X$.

  3. Selects the next centroid $\mu_{k}$ with probability proportional to the squared distance: $$P(x) = \frac{D(x)^2}{\sum_{x' \in X} D(x')^2}$$
  4. Repeats steps 2–3 until $K$ centroids are chosen. This probabilistic dispersion forces centroids to be geographically spread across the data space, mathematically guaranteeing an expected upper bound of $O(\log K)$ times the optimal clustering error.
  • The Flaw: Bad random starting centers get trapped in awful local dead-ends. Outliers pull centroids off-course because distance errors are squared.
  • K-Means++ Solution: Instead of random guessing, K-Means++ picks the first center randomly, then picks subsequent centers with a probability proportional to squared distance $D(x)^2$ from existing centers.
  • Analogy: Like placing cell towers as far apart from each other as possible to maximize signal coverage.

Q165. Explain the complete K-Means clustering algorithm. Derive its objective function (WCSS), outline convergence criteria, and discuss its sensitivity to initial centroid placement.

Unit IV CO4 | Bloom L4 5 Marks End Term Score: 9.6

1. Algorithmic Framework: K-Means is a centroid-based partitioning algorithm that divides a dataset $X = \{x_1, \dots, x_N\} \subset \mathbb{R}^d$ into $K$ disjoint clusters $S = \{S_1, \dots, S_K\}$.

  1. Initialization: Select $K$ initial centroid vectors $\{\mu_1^{(0)}, \dots, \mu_K^{(0)}\}$ (via K-Means++).
  2. Assignment Step: Assign each observation $x_i$ to its closest centroid: $$S_k^{(t)} = \left\{ x_i : \|x_i - \mu_k^{(t)}\|^2 \le \|x_i - \mu_j^{(t)}\|^2, \; \forall j \in \{1, \dots, K\} \right\}$$
  3. Update Step: Recompute each centroid as the barycenter of its assigned set: $$\mu_k^{(t+1)} = \frac{1}{|S_k^{(t)}|} \sum_{x_i \in S_k^{(t)}} x_i$$
  4. Iteration: Repeat until convergence criteria are satisfied.

2. Derivation of the Objective Function (WCSS):

The objective function is the Within-Cluster Sum of Squares (Inertia):

$$J(\mu_1, \dots, \mu_K) = \sum_{k=1}^K \sum_{x_i \in S_k} \|x_i - \mu_k\|^2$$

To find the optimal centroid $\mu_k$ that minimizes $J$ for a fixed partition $S_k$, compute the partial gradient with respect to $\mu_k$ and set it to zero:

$$\frac{\partial J}{\partial \mu_k} = \frac{\partial}{\partial \mu_k} \sum_{x_i \in S_k} (x_i - \mu_k)^T (x_i - \mu_k) = -2 \sum_{x_i \in S_k} (x_i - \mu_k) = 0$$ $$\sum_{x_i \in S_k} x_i - \sum_{x_i \in S_k} \mu_k = 0 \implies \sum_{x_i \in S_k} x_i = |S_k| \mu_k$$ $$\mathbf{\mu_k = \frac{1}{|S_k|} \sum_{x_i \in S_k} x_i}$$

This derives the arithmetic mean as the mathematically exact global minimizer of squared Euclidean error for any cluster partition.

3. Convergence Criteria:

  • Centroid Shift Threshold: $\max_k \|\mu_k^{(t+1)} - \mu_k^{(t)}\| < \epsilon$.
  • Assignment Stability: No data points change cluster labels between iterations ($S_k^{(t+1)} = S_k^{(t)}$).
  • Objective Plateau: Relative reduction $|J^{(t+1)} - J^{(t)}| / J^{(t)} < \delta$.

4. Sensitivity to Initial Centroid Placement: Because $J$ is non-convex, standard random seeding causes convergence to sub-optimal local minima. For example, two centroids initialized in the same true cluster will split it while leaving other true clusters merged. K-Means++ eliminates this by selecting seeds sequentially with probability proportional to squared distance $D(x)^2$, guaranteeing an $O(\log K)$ approximation ratio.

  • Algorithm: 1) Pick $K$ centroids, 2) Assign each point to closest centroid, 3) Move centroid to the group average, 4) Repeat until stable.
  • Math Proof: Taking the derivative of squared error and setting to zero proves that the average (mean) is the exact mathematical minimum.
  • Convergence: Stops when centroids stop moving or point assignments freeze.
  • Initialization Trap: Starting centroids in bad places causes poor local solutions. K-Means++ fixes this by spreading out starting seeds.

  • Density-Reachable: Point $q$ is density-reachable from $p$ if there exists a chain $p_1, p_2, \dots, p_n$ with $p_1 = p, p_n = q$ such that $p_{i+1}$ is directly density-reachable from $p_i$.
  • Density-Connected: Points $p$ and $q$ are density-connected if there exists a core point $o$ such that both $p$ and $q$ are density-reachable from $o$.
  • Border Point: A non-core point that is directly density-reachable from a core point.
  • Noise Point: Any point that is not density-reachable from any core point.

  1. Initialize all points as UNVISITED. Set cluster identifier $C = 0$.
  2. For each point $p \in D$:

    • Mark $p$ as VISITED. Find neighbors $N_\varepsilon(p)$.
    • If $|N_\varepsilon(p)| < \text{MinPts}$, mark $p$ as NOISE (may later be reclassified as border).

      • Pop point $q$ from $S$.
      • If $q$ is marked NOISE, reassign $q$ to cluster $C$ (it is a border point).
      • If $q$ is UNVISITED:
        • Mark $q$ as VISITED.
        • Compute $N_\varepsilon(q)$. If $|N_\varepsilon(q)| \ge \text{MinPts}$, append all points in $N_\varepsilon(q)$ to $S$.
        • If $q$ is not a member of any cluster, assign $q$ to cluster $C$.

  • Border: On the fringe; touches a core point but has fewer than MinPts neighbors.
  • Noise: Isolated; not close enough to any core point.

1. Agglomerative (Bottom-Up) Clustering Architecture:

  1. Initialization: Treat each of the $N$ data instances as an individual singleton cluster: $C_i = \{x_i\}$. Compute the symmetric $N \times N$ pairwise proximity matrix $\mathbf{D}$.
  2. Iterative Merge: Find the two clusters $C_A, C_B$ with minimal linkage distance $D(C_A, C_B) = \min_{i, j} D(C_i, C_j)$.
  3. Matrix Update: Merge $C_A$ and $C_B$ into a single cluster $C_{\text{new}} = C_A \cup C_B$. Update the proximity matrix using the Lance-Williams recurrence relation.
  4. Termination: Repeat steps 2–3 for $N-1$ iterations until all points coalesce into a single root cluster.

2. Dendrogram Construction and Cutting:

A dendrogram visually plots the merge sequence: the X-axis enumerates data instances, while the Y-axis represents the dissimilarity height at which merges occur.

3. Linkage Metrics Comparison:

  • Single Linkage ($d_{\min}$): $D(A, B) = \min_{a \in A, b \in B} d(a, b)$. Forms elongated chains; sensitive to noise bridges.
  • Complete Linkage ($d_{\max}$): $D(A, B) = \max_{a \in A, b \in B} d(a, b)$. Forms compact spherical clusters of equal diameter; avoids chaining.
  • Average Linkage ($d_{\text{avg}}$): $D(A, B) = \frac{1}{|A||B|} \sum_{a, b} d(a, b)$. Unbiased, robust to noise.
  • Ward's Method: Minimizes total within-cluster variance increase: $\Delta \text{ESS} = \frac{|A||B|}{|A|+|B|} \|\mu_A - \mu_B\|^2$. Produces high-quality spherical clusters.

4. Selecting Optimal Cuts: Search for the longest vertical gap in the dendrogram unbroken by any horizontal merge lines. Placing a horizontal threshold cut line through this vertical interval yields the most naturally distinct, well-separated cluster count ($K$).

  • Bottom-Up: Starts with every point in its own cluster, then merges the two closest clusters at each step until one big cluster remains.
  • Dendrogram: A tree showing when and at what distance clusters merged.
  • Linkage: Single = closest points (chains); Complete = farthest points (round blobs); Average = average distance (balanced).
  • Optimal Cut: Find the longest vertical stretch without horizontal merge bars and slice horizontally with a scissors line to get $K$ clusters.

Q169. Detail Self-Organizing Maps (SOM). Explain how competitive learning, topology preservation, and neighborhood functions reduce data dimensionality.

Unit IV CO4 | Bloom L4 5 Marks End Term Score: 9.1

1. Architectural Foundations: A Self-Organizing Map (SOM) is an unsupervised neural network mapping continuous high-dimensional input vectors $x \in \mathbb{R}^D$ onto a discrete 1D or 2D lattice of neurons $j = 1, \dots, M$. Each neuron $j$ maintains a prototype weight vector $w_j = [w_{j1}, \dots, w_{jD}]^T \in \mathbb{R}^D$.

2. Three Foundational Processes of SOM:

  1. Competitive Process (Winner-Take-All):

    For an input sample $x$, all neurons compute their Euclidean distance to $x$. The neuron whose weight vector is closest is designated the Best Matching Unit (BMU), denoted $c$:

    $$c = \arg\min_{j} \|x - w_j\|$$
  2. Cooperative Process (Neighborhood Function):

    The BMU excites not only itself but also spatial neighbors on the 2D grid. The topological influence is governed by a symmetric Gaussian neighborhood function centered at grid position $r_c$:

    $$h_{cj}(t) = \exp\left( -\frac{\|r_c - r_j\|^2}{2 \sigma^2(t)} \right)$$

    where the neighborhood width decays over training iterations $t$: $\sigma(t) = \sigma_0 \exp(-t / \tau_1)$.

  3. Adaptive Process (Weight Update Rule):

    Weight vectors of the BMU and its neighbors are updated to move closer to input $x$:

    $$w_j(t+1) = w_j(t) + \alpha(t) h_{cj}(t) [x - w_j(t)]$$

    where learning rate $\alpha(t) = \alpha_0 \exp(-t / \tau_2)$ decays monotonically.

3. Topology Preservation & Dimensionality Reduction: Because neighboring neurons on the 2D lattice are pulled toward similar input regions, the network stretches and folds like an elastic net to mirror the non-linear manifold of the high-dimensional data, preserving topological adjacency relationships in 2D space.

  • 2D Neural Grid: Flattens complex multi-dimensional data onto a 2D sheet of neurons.
  • Competitive Learning: The neuron closest to the input point wins the competition (Best Matching Unit / BMU).
  • Cooperation: The winner pulls its grid neighbors along with it using a bell-shaped Gaussian curve.
  • Topology Preservation: Nearby data points end up close together on the 2D map, creating an intuitive low-dimensional visualization.

  • $\\gamma = 0.99$ (Farsighted): Patient grandmaster, willing to sacrifice short-term pieces to win the whole match later.
  • Math Purpose: Keeps infinite sums bounded and prevents infinite reward loops.

Q178. Describe the epsilon - greedy strategy in details.

The $\varepsilon$-Greedy Action Selection Strategy resolves the fundamental Exploration vs. Exploitation Trade-off in reinforcement learning:

  1. Decision Rule:
    • With probability $1 - \varepsilon$, the agent exploits its current knowledge by selecting the greedy action with the highest estimated action-value: $$a^* = \arg\max_{a \in \mathcal{A}} Q(s, a)$$
    • With probability $\varepsilon$, the agent explores by selecting an action uniformly at random from all $|\mathcal{A}|$ candidate actions: $$a \sim \text{Uniform}(\mathcal{A})$$
  2. Formal Probability Distribution: $$\pi(a \mid s) = \begin{cases} 1 - \varepsilon + \frac{\varepsilon}{|\mathcal{A}|}, & \text{if } a = \arg\max_{a'} Q(s, a') \\ \frac{\varepsilon}{|\mathcal{A}|}, & \text{if } a \ne \arg\max_{a'} Q(s, a') \end{cases}$$

  • Exploitation ($1 - \\varepsilon$ chance): Pick the best move you already know works (Greedy).
  • Exploration ($\\varepsilon$ chance): Try a completely random move to discover better hidden strategies.
  • Decay: Start with high $\\varepsilon$ ($1.0$) early on when the agent knows nothing, and slowly reduce it down to $0.01$ once the agent becomes an expert.

Definition: A Value Function in RL is a mathematical expectation quantifying the long-term cumulative discounted return an agent can expect to accumulate starting from a given state (State-Value $V^\pi(s)$) or from taking a specific action in a state (Action-Value $Q^\pi(s, a)$) while adhering to policy $\pi$:

$$V^\pi(s) = \mathbb{E}_\pi \left[ \sum_{k=0}^\infty \gamma^k R_{t+k+1} \;\middle|\; S_t = s \right]$$

Critical Significance in RL:

  1. Resolves Immediate Reward Deception: Immediate rewards can be misleading (e.g., greedily grabbing a pawn in chess can lead to instant checkmate). Value functions look beyond instantaneous gains to quantify total strategic sustainability.
  2. Enables Policy Improvement: In Generalized Policy Iteration (GPI), value functions serve as the benchmark to evaluate policy quality and guide greedy policy improvements: $\pi'(s) = \arg\max_a Q^\pi(s, a)$.
  3. Solves the Credit Assignment Dilemma: By bootstrapping through the Bellman equation ($V(s) = R + \gamma V(s')$), value functions assign credit to early decisions that set up future success.
  • A value function predicts the total future jackpot an agent will collect starting from a given situation.
  • Why it matters: Prevents shortsighted traps (like taking an easy bait piece in chess that loses the whole game).
  • Credit Assignment: Makes sure early setup moves get recognized for enabling late-game victories.

Q182. Explain the mechanism of Q-Learning as an off-policy Temporal Difference algorithm.

Unit V CO5 | Bloom L2 3 Marks End Term Score: 9.4

Q-Learning combines two foundational computational paradigms:

  1. Temporal Difference (TD) Bootstrapping:

    Unlike Monte Carlo methods that must wait for full episode termination to calculate return $G_t$, Q-learning updates its estimate after a single timestep using bootstrapping: updating an estimate from another estimate:

    $$\text{Target} = R_{t+1} + \gamma \max_a Q(S_{t+1}, a)$$
  2. Off-Policy Decoupling:

    Q-learning decouples the Behavior Policy from the Target Policy:

    • Behavior Policy (Exploratory): Dictates how the agent interacts with the environment to generate transitions $(S_t, A_t, R_{t+1}, S_{t+1})$. Typically an exploratory policy like $\varepsilon$-greedy or softmax.
    • Target Policy (Greedy / Optimal): Dictates how the update target is calculated. It independently evaluates the strictly greedy policy by using the maximum operator $\max_a Q(S_{t+1}, a)$ regardless of what action the behavior policy actually takes next.
  3. Implication: The agent can explore randomly or learn from historical experience replay buffers, and is still mathematically guaranteed to converge to the optimal action-value function $Q^*$ provided all state-action pairs continue to be visited.
  • Temporal Difference (TD): Updates its knowledge immediately after one step, without waiting for the game to end.
  • Off-Policy: The agent plays using an adventurous, exploratory strategy ($\\varepsilon$-greedy), but calculates its learning updates assuming it will play like a flawless grandmaster ($\\max Q$).
  • Advantage: Can learn from past recorded games, replay buffers, or random button mashing.

Mathematical definitions and formulations of the core RL trilogy:

  1. Policy ($\pi$): The operational behavioral strategy of the agent, defining a probability distribution over actions given a state: $$\pi(a \mid s) = \mathbb{P}(A_t = a \mid S_t = s) \quad \text{such that } \sum_{a \in \mathcal{A}} \pi(a \mid s) = 1$$ (or deterministic mapping $a = \pi(s)$).

Action-Value Function ($Q^\pi(s, a)$): The expected cumulative discounted future return when starting in state $s$, executing an arbitrary action $a$, and strictly following policy $\pi$ thereafter: $$Q^\pi(s, a) = \mathbb{E}_\pi \left[ \sum_{k=0}^\infty \gamma^k R_{t+k+1} \;\middle|\; S_t = s, A_t = a \right]$$

Connecting Identity: $V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) Q^\pi(s, a)$.

  • Policy ($\\pi$): The decision rule: "If you see state $s$, pick action $a$."
  • $V(s)$: The expected total score if you start at position $s$.
  • $Q(s, a)$: The expected total score if you choose move $a$ from position $s$.
  • $V(s)$ is simply the weighted average of all $Q(s, a)$ values for that state.

Q187. Describe various components of Markov Decision Process in details.

Unit V CO5 | Bloom L2 5 Marks End Term Score: 9.3

A Markov Decision Process (MDP) provides the formal mathematical model for sequential stochastic decision problems, specified by the 5-tuple $(\mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma)$:

  1. State Space ($\mathcal{S}$): The set of all valid environment states. The core invariant is the Markov Property: $$\mathbb{P}(S_{t+1}=s_{t+1}, R_{t+1}=r_{t+1} \mid S_t=s_t, A_t=a_t, \dots, S_0=s_0, A_0=a_0) = \mathbb{P}(S_{t+1}=s_{t+1}, R_{t+1}=r_{t+1} \mid S_t=s_t, A_t=a_t)$$ The current state is a sufficient statistic for the entire history of interactions.
  2. Action Space ($\mathcal{A}$): The set of all available agent actions. Can be discrete (finite buttons) or continuous (multidimensional control torques $\mathbb{R}^d$).
  3. Transition Probability Function ($\mathcal{P}$): $$\mathcal{P}(s' \mid s, a) = \mathbb{P}(S_{t+1} = s' \mid S_t = s, A_t = a) \quad \text{where } \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) = 1$$ Encapsulates environment stochasticity, specifying the probability distribution over all possible successor states.
  4. Reward Function ($\mathcal{R}$): $$\mathcal{R}(s, a, s') = \mathbb{E}[R_{t+1} \mid S_t = s, A_t = a, S_{t+1} = s']$$ Assigns a numerical scalar to transitions, defining the task goal according to the Reward Hypothesis: all goals can be formalized as the maximization of expected cumulative reward.
  5. Discount Factor ($\gamma \in [0, 1)$): Discounts future rewards exponentially: $G_t = \sum_{k=0}^\infty \gamma^k R_{t+k+1}$, guaranteeing convergence of infinite series and modeling economic/temporal preference.
  6. Policy ($\pi$): The agent's decision function: $\pi(a \mid s) = \mathbb{P}(A_t = a \mid S_t = s)$.
  • States ($\\mathcal{S}$): All possible positions or situations.
  • Actions ($\\mathcal{A}$): All possible moves or decisions.
  • Transitions ($\\mathcal{P}$): The probability rules of the game (odds of landing on state $s'$).
  • Rewards ($\\mathcal{R}$): Immediate points awarded for each move.
  • Discount Factor ($\\gamma$): Value depreciation factor for future points ($0.9$ means points next turn are worth 90% of points now).
  • Markov Rule: The future depends ONLY on where you are right now, not how you got here.

Q190. Formulate a Markov Decision Process (MDP). Define State-Value V(s) and Action-Value Q(s, a) functions and derive the Bellman Expectation Equation.

Unit V CO5 | Bloom L4 5 Marks End Term Score: 9.8

1. Mathematical Formulation of an MDP: Defined by 5-tuple $(\mathcal{S}, \mathcal{A}, \mathcal{P}, \mathcal{R}, \gamma)$ where discounted cumulative return is $G_t = \sum_{k=0}^\infty \gamma^k R_{t+k+1} = R_{t+1} + \gamma G_{t+1}$.

2. Core Value Function Definitions:

  • State-Value Function: $V^\pi(s) = \mathbb{E}_\pi [G_t \mid S_t = s]$
  • Action-Value Function: $Q^\pi(s, a) = \mathbb{E}_\pi [G_t \mid S_t = s, A_t = a]$

3. Derivation of the Bellman Expectation Equation for $V^\pi(s)$:

Start from the definition of $V^\pi(s)$ and substitute the recursive return $G_t = R_{t+1} + \gamma G_{t+1}$:

$$V^\pi(s) = \mathbb{E}_\pi [R_{t+1} + \gamma G_{t+1} \mid S_t = s]$$

Using the Law of Total Expectation, expand across all possible actions $a \sim \pi(a \mid s)$:

$$V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) \mathbb{E}_\pi [R_{t+1} + \gamma G_{t+1} \mid S_t = s, A_t = a]$$

Expand the inner expectation over all possible next states $s' \sim \mathcal{P}(s' \mid s, a)$ and rewards:

$$\mathbb{E}_\pi [R_{t+1} + \gamma G_{t+1} \mid S_t = s, A_t = a] = \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma \mathbb{E}_\pi [G_{t+1} \mid S_{t+1} = s'] \right]$$

Recognizing that $\mathbb{E}_\pi [G_{t+1} \mid S_{t+1} = s'] = V^\pi(s')$, substitute this back:

$$\mathbf{V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s) \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma V^\pi(s') \right]}$$

4. Derivation for $Q^\pi(s, a)$:

Similarly, expressing $Q^\pi(s, a)$ in terms of successor action-values:

$$\mathbf{Q^\pi(s, a) = \sum_{s' \in \mathcal{S}} \mathcal{P}(s' \mid s, a) \left[ \mathcal{R}(s, a, s') + \gamma \sum_{a' \in \mathcal{A}} \pi(a' \mid s') Q^\pi(s', a') \right]}$$

Conclusion: The Bellman Expectation Equation expresses the value of a state recursively as the immediate expected reward plus the discounted expected value of the succeeding state.

  • Return Decomposition: Future points $G_t$ = (Points right now $R_{t+1}$) + $\\gamma \\times$ (Points from next turn onwards $G_{t+1}$).
  • The Big Idea: The value of your current state equals the immediate reward you expect, plus the discounted value of where you land next.
  • Derivation Steps:
    1. Substitute $G_t = R_{t+1} + \\gamma G_{t+1}$ into expectation.
    2. Sum over actions weighted by policy $\\pi(a|s)$.
    3. Sum over next states weighted by transitions $\\mathcal{P}(s'|s,a)$.
    4. Replace $\\mathbb{E}[G_{t+1}]$ with $V(s')$.

1. The Markov Property:

A stochastic process possesses the Markov property if the conditional probability distribution of future states and rewards depends strictly upon the current state and action, and is conditionally independent of all preceding past states and actions:

$$\mathbb{P}(S_{t+1} = s_{t+1}, R_{t+1} = r_{t+1} \mid S_t, A_t, S_{t-1}, A_{t-1}, \dots, S_0, A_0) = \mathbb{P}(S_{t+1} = s_{t+1}, R_{t+1} = r_{t+1} \mid S_t, A_t)$$

In concise terms: "The future is independent of the past given the present."

2. The Five Elements of an MDP:

  1. State Space ($\mathcal{S}$): The set of all possible environmental situations.
  2. Action Space ($\mathcal{A}$): The set of all permissible actions available to the agent.
  3. Transition Probability Matrix ($\mathcal{P}$): $\mathcal{P}(s' \mid s, a) = \mathbb{P}(S_{t+1} = s' \mid S_t = s, A_t = a)$.
  4. Reward Function ($\mathcal{R}$): $\mathcal{R}(s, a, s') = \mathbb{E}[R_{t+1} \mid S_t = s, A_t = a, S_{t+1} = s']$.
  5. Discount Factor ($\gamma \in [0, 1)$): Balances present vs. future reward importance.

3. Concrete Example: Automated Warehouse Delivery Drone:

  • States ($\mathcal{S}$): Battery levels: $\{\text{High, Medium, Low, Depleted}\}$.

  • Rewards ($\mathcal{R}$): Delivering package yields $+10$; waiting yields $0$; battery running out to Depleted incurs $-50$ penalty.
  • Discount Factor ($\gamma = 0.95$): Compels the drone to prioritize long-term battery replenishment over reckless short-term deliveries.
  • Markov Property: History doesn't matter. What happens next depends ONLY on where you are right now.

Q192. Explain the Q-Learning algorithm in detail. Write the Q-value update rule, outline the step-by-step training loop, and explain how learning rate alpha and discount factor gamma control convergence.

Unit V CO5 | Bloom L4 5 Marks End Term Score: 9.8

1. Algorithm Overview: Q-Learning is a model-free, off-policy Temporal Difference (TD) control algorithm designed to find the optimal action-value function $Q^*(s, a)$ directly from environmental transitions without requiring an explicit model of transition dynamics.

2. Mathematical Q-Value Update Rule:

$$Q(S_t, A_t) \leftarrow Q(S_t, A_t) + \alpha \left[ \underbrace{R_{t+1} + \gamma \max_{a \in \mathcal{A}} Q(S_{t+1}, a)}_{\text{TD Target}} - Q(S_t, A_t) \right]$$

where the Temporal Difference Error is $\delta_t = R_{t+1} + \gamma \max_a Q(S_{t+1}, a) - Q(S_t, A_t)$.

3. Step-by-Step Complete Training Loop:

  1. Initialization: Initialize table $Q(s, a)$ arbitrarily (e.g., zeros) for all $s \in \mathcal{S}, a \in \mathcal{A}$. Set $Q(\text{terminal}, \cdot) = 0$.
  2. Episode Loop: For each episode $e = 1, \dots, E$:
    1. Initialize environment and observe initial state $S$.
    2. Step Loop: For each timestep $t$ until $S$ is terminal:
      • Select action $A$ from state $S$ using an exploratory policy derived from $Q$ (e.g., $\varepsilon$-greedy).
      • Execute action $A$, observe scalar reward $R$ and successor state $S'$.
      • Compute target $Y = R + \gamma \max_a Q(S', a)$ (if $S'$ is terminal, $Y = R$).
      • Update cell: $Q(S, A) \leftarrow Q(S, A) + \alpha [Y - Q(S, A)]$.
      • Transition state: $S \leftarrow S'$.
    3. Decay exploration rate: $\varepsilon \leftarrow \max(\varepsilon_{\min}, \varepsilon \times \lambda)$.

4. How Hyperparameters Control Convergence:

  • Learning Rate ($\alpha \in (0, 1]$): Determines the step size toward TD targets. For guaranteed convergence to $Q^*$, the Robbins-Monro stochastic conditions must hold: $\sum_{t=1}^\infty \alpha_t = \infty$ and $\sum_{t=1}^\infty \alpha_t^2 < \infty$. If $\alpha = 1.0$, the agent overwrites past knowledge instantly; if $\alpha$ is too small, learning is excessively slow. A typical schedule is $\alpha \in [0.01, 0.1]$.
  • Discount Factor ($\gamma \in [0, 1)$): Controls the effective temporal planning horizon $H \approx \frac{1}{1 - \gamma}$. If $\gamma = 0$, the update only considers immediate reward $R$. As $\gamma \to 1$ (e.g., $0.99$), Bellman backup propagates values across long credit assignment chains, stabilizing long-horizon convergence.
  • Concept: Q-Learning fills out a cheat sheet table ($Q$-table) mapping states and actions to expected points.
  • Training Loop:
    1. Look at your current position $S$.
    2. Pick an action $A$ using $\\varepsilon$-greedy (usually best known, sometimes random).
    3. Make the move, receive reward $R$, and see new state $S'$.
    4. Update the table cell using the TD formula.
    5. Move to $S'$ and repeat until game over.
  • Hyperparameters:
    • $\\alpha$ (Learning Rate): How fast new experiences overwrite old knowledge.
    • $\\gamma$ (Discount Factor): How far into the future the agent plans ahead.
