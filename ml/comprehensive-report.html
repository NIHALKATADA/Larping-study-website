Unit I: Introduction to Machine Learning

Machine Learning Paradigms

An overview of the fundamental learning frameworks.
  • Supervised Learning: Uses labeled input data to predict specific targets.
  • Unsupervised Learning: Discovers hidden patterns in unlabeled data.
  • Reinforcement Learning: Learns through environmental interaction and reward maximization.
Having established the core principles of Machine Learning Paradigms, we now turn our attention to The 7-Step ML Lifecycle.

The 7-Step ML Lifecycle

The structured end-to-end process for developing ML models.
  • Data Collection: Gathering raw data from diverse sources.
  • Data Preprocessing: Cleaning and formatting raw datasets.
  • Model Training: Algorithms learning patterns autonomously from historical data.
  • Model Evaluation: Assessing performance on unseen validation sets to prevent overfitting.
Transitioning from The 7-Step ML Lifecycle, we now examine Exploratory Data Analysis (EDA), which builds upon these foundational rules.

Exploratory Data Analysis (EDA)

Analytical investigation to summarize core dataset characteristics.
  • Objective: Identify structures, anomalies, and underlying patterns before modeling.
  • Techniques: Computing summary statistics (mean, variance).
  • Visualization: Using histograms for distributions and scatter plots for feature correlations.
Now that we have a solid grasp of Exploratory Data Analysis (EDA), the natural next step is to explore Data Preprocessing & Cleaning.

Data Preprocessing & Cleaning

Essential techniques for preparing uncleaned, unstructured data.
  • Handling Missing Values: Removing rows/columns or applying statistical imputation (mean/mode).
  • Data Normalization: Scaling numerical features into standardized ranges to stabilize convergence.
  • Impact: Prevents algorithms from being biased by varied scales or failing due to missing entries.
Now that we have a solid grasp of Data Preprocessing & Cleaning, the natural next step is to explore Feature Engineering & Selection.

Feature Engineering & Selection

Transforming variables to maximize an algorithm predictive capability.
  • Categorical Encoding: Converting string labels into numeric formats (e.g., label encoding).
  • Feature Engineering: Creating meaningful mathematical representations from raw attributes.
  • Feature Selection: Filtering down to the most relevant variables to reduce dimensionality and noise.

Unit II: Regression Models & Optimization

Linear Regression Formulation

Mathematical models predicting continuous outcomes using linear equations.
  • Simple Linear Regression: Models one independent variable (h(x) = θ0 + θ1x).
  • Multiple Linear Regression: Extends to n independent variables.
  • Ordinary Least Squares (OLS): Analytically minimizes the sum of squared residual errors between predictions and targets.
To fully appreciate Cost Functions & Gradient Descent, we must apply what we just learned about Linear Regression Formulation.

Cost Functions & Gradient Descent

Optimization strategies for training robust regression models.
  • Mean Squared Error (MSE): Cost function heavily penalizing large errors.
  • Gradient Descent: Iterative optimization algorithm preferred over Normal Equations for high-dimensional data.
  • Learning Rate (α): Controls step size; if too high, optimization may overshoot the global minimum and diverge.
To fully appreciate Polynomial Regression, we must apply what we just learned about Cost Functions & Gradient Descent.

Polynomial Regression

Extensions of linear models capable of capturing complex trends.
  • Non-Linearity: Uses higher-degree feature transformations to fit curved patterns.
  • Model Linearity: Remains technically linear with respect to its optimizable weight parameters.
While Polynomial Regression gives us the theoretical background, Model Complexity & Bias-Variance Trad... provides the next layer of complexity.

Model Complexity & Bias-Variance Tradeoff

Balancing capacity to ensure models generalize to unseen data.
  • Overfitting (High Variance): Model memorizes training noise; reduced by regularization or simpler models.
  • Underfitting (High Bias): Overly simplistic model fails to capture underlying data structures.
  • Tradeoff: Finding the optimal complexity sweet spot that minimizes total prediction error.
Now that we have a solid grasp of Model Complexity & Bias-Variance Trad..., the natural next step is to explore Regularization Techniques.

Regularization Techniques

Methods adding complexity penalties to regression loss functions to prevent overfitting.
  • Ridge (L2): Adds squared magnitude penalties, shrinking coefficients toward zero.
  • Lasso (L1): Adds absolute magnitude penalties, uniquely performing automatic feature selection by zeroing irrelevant weights.
Having established the core principles of Regularization Techniques, we now turn our attention to Regression Evaluation Metrics.

Regression Evaluation Metrics

Statistical measures to quantify model prediction accuracy.
  • MAE & MSE: Evaluate average magnitude of absolute and squared errors, respectively.
  • RMSE: Converts MSE back to original units for easier interpretation.
  • R-Squared: Measures proportion of explained variance.
  • Adjusted R-Squared: Penalizes non-significant variables, making it superior for multiple regression.

Unit III: Classification & Advanced Algorithms

Logistic Regression & Binary Classification

Probabilistic modeling for categorical target outcomes.
  • Sigmoid Function: Non-linear activation mapping real values to probabilities between 0 and 1.
  • Decision Threshold: Typically 0.5, used to assign discrete binary class labels based on probabilities.
  • Log-Loss (Cross-Entropy): Cost function highly penalizing confident yet incorrect classifications.
While Logistic Regression & Binary Classifi... gives us the theoretical background, K-Nearest Neighbors (KNN) provides the next layer of complexity.

K-Nearest Neighbors (KNN)

Non-parametric algorithm leveraging spatial proximity.
  • Mechanism: Predicts class via majority vote among the K closest training points.
  • Distance Metrics: Often utilizes Euclidean distance to measure similarity.
  • K Hyperparameter: A small K risks overfitting to noise, while a large K risks underfitting by over-smoothing boundaries.
To fully appreciate Decision Trees & Information Theory, we must apply what we just learned about K-Nearest Neighbors (KNN).

Decision Trees & Information Theory

Tree-based algorithms built via recursive dataset partitioning.
  • Entropy: Quantifies uncertainty or impurity in a subset of data.
  • Information Gain: Node split criterion maximizing homogeneity by selecting features that most reduce entropy.
  • Gini Impurity: Faster, alternative metric computing the probability of misclassification.
To fully appreciate Naive Bayes Classifier, we must apply what we just learned about Decision Trees & Information Theory.

Naive Bayes Classifier

Probabilistic classifier grounded in Bayes Theorem.
  • Bayes Theorem: Calculates posterior probabilities using prior, likelihood, and evidence.
  • Naive Assumption: Termed naive because it assumes strict conditional independence between all input features, simplifying computations.
Having established the core principles of Naive Bayes Classifier, we now turn our attention to Support Vector Machines (SVM).

Support Vector Machines (SVM)

Robust margin-based classification finding optimal separating hyperplanes.
  • Hyperplanes & Support Vectors: Decision boundaries maximizing the margin between closest data points of different classes.
  • Hard vs. Soft Margin: Soft margins use slack variables/hinge loss to allow misclassifications for non-separable data.
  • Kernel Trick: Projects data into higher dimensions (e.g., via RBF) to linearly separate non-linear distributions.
While Support Vector Machines (SVM) gives us the theoretical background, Ensemble Methods & Evaluation provides the next layer of complexity.

Ensemble Methods & Evaluation

Combining multiple weak models and comprehensively evaluating predictions.
  • Bagging vs. Boosting: Random Forests build independent parallel trees (bagging) while AdaBoost/XGBoost build sequential correcting trees (boosting).
  • Confusion Matrix: Tabulates True Positives, False Positives, True Negatives, and False Negatives.
  • F1-Score: Harmonic mean of precision and recall, essential for assessing highly imbalanced datasets.
