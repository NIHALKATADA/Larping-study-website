# Revision Hub Rules & Development Invariants

- **Never Hand-Edit Generated Subject HTML**: Files under `daa/`, `dbms/`, `java/`, `maths/`, `ml/`, `os/` (`question-bank.html`, `midterm-important.html`, `interactive-quiz.html`, `assistant-index.json`) and `global/assistant-index.json` are generated by `scripts/build_site.py`. Always edit JSON under `data/<subject>/` or Jinja2 templates under `templates/`, then run:
  ```powershell
  python scripts\build_site.py; npm test
  ```
- **Black Glass `backdrop-filter` Chromium Bug**: Never add `contain: paint` or `will-change: opacity/transform` on any ancestor of an element using `backdrop-filter: blur(...)`, as Chromium disables the blur and renders the element flat/transparent.
- **Zero Inline `<style>` / `<script>` Bloat**: Keep shared styles in `shared/design-system.css` and shared logic in `shared/app-utils.js` / `shared/quiz-logic.js`.
- **Keep Root Clean**: Place maintenance or one-off utilities in `scripts/` (or scratch), never at repository root.
- **Deployment & Cloud Stack**:
  - Hosting & serverless AI (`api/chat.js`, `api/config.js`): **Vercel** (`vercel.json` redirects `/subjects/* -> /*`). Prefer Git-linked or Vercel CLI deployment (`vercel --prod`) over manual ZIP drag-and-drop.
  - Auth & Profile DB (`profile.html`, `reset-password.html`, `schema*.sql`): **Supabase** (check Supabase project status before testing auth flows).
