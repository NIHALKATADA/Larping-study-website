Q6. Let p: It is raining, q: I carry an umbrella, r: I wear a raincoat. Write the following statements in symbolic form. (a) It is raining and I carry an umbrella. (b) It is not raining but I wear a raincoat.

Unit I CO1 | Bloom L2 2 Marks Score: 9.3

(a) p ∧ q

(b) ¬p ∧ r (Note: 'but' translates to logical AND)

Q23. Construct a truth table for each of the following compound propositions. (a) (p ↔ q) ⊕ (¬p ↔ ¬r) (b) (¬p ↔ ¬q) ↔ (q ↔ r)

Unit I CO1 | Bloom L3 5 Marks Score: 9.5

Since these involve 3 variables (p, q, r), we construct an 8-row truth table for each. (Left as exercise for detailed 8 rows).

(a) (p ↔ q) ⊕ (¬p ↔ ¬r)

We evaluate p ↔ q and ¬p ↔ ¬r separately for 8 rows, then apply XOR.

(b) (¬p ↔ ¬q) ↔ (q ↔ r)

Evaluate ¬p ↔ ¬q and q ↔ r separately for 8 rows, then apply biconditional.

Q2. Write the solution of the following Generating function: G(x) = 1 / (1 - 2x)

Unit II CO2 | Bloom L2 2 Marks Score: 9.4

The generating function 1 / (1 - rx) corresponds to the sequence r^n.

Here, r = 2, so the solution is an = 2n.

a2 = a12 = 22 = 4.

a3 = a22 = 42 = 16.

Q6. Find the value of: (i) 7P2 and (ii) 9C2

Unit II CO2 | Bloom L2 2 Marks Score: 9.5

(i) 7P2 = 7! / (7-2)! = 7 × 6 = 42.

(ii) 9C2 = 9! / (2! × (9-2)!) = (9 × 8) / 2 = 36.

Q13. Solve the following recurrence relation: a_n = 10a_{n-1} - 25a_{n-2}, a_0 = 3, a_1 = 25

Unit II CO2 | Bloom L3 3 Marks Score: 9.2

Characteristic equation: r^2 - 10r + 25 = 0 ⇒ (r - 5)^2 = 0, so r = 5 (repeated).

General solution: an = (c1 + c2n)5n.

For n=0: 3 = c1.

For n=1: 25 = (3 + c2) × 5 ⇒ 3 + c2 = 5 ⇒ c2 = 2.

Solution: an = (3 + 2n)5n.

Q16. How many different 4-letter words can be formed using the letters of the word MATH, when each letter can be used only once?

Unit II CO2 | Bloom L2 3 Marks Score: 9.2

The word MATH has 4 distinct letters.

The number of 4-letter words that can be formed is the number of permutations of 4 letters, which is 4! = 4 × 3 × 2 × 1 = 24.

Q21. Find the value of n: (n + 1)P_3 = 5 x nP_2

Unit II CO2 | Bloom L3 5 Marks Score: 9.3

Using the permutation formula: (n+1)! / (n+1-3)! = 5 × [n! / (n-2)!].

(n+1)! / (n-2)! = 5 × n! / (n-2)!

Canceling (n-2)! from both sides gives (n+1)! = 5 × n!.

(n+1)n! = 5n! ⇒ n + 1 = 5 ⇒ n = 4.

Q7. Define the following terms with graphs: (i) n-Cube (ii) Pseudograph

Unit III CO3 | Bloom L1 2 Marks Score: 9.3

(i) n-Cube ($Q_n$): A graph with $2^n$ vertices, represented by bit strings of length $n$. Two vertices are connected if their bit strings differ by exactly one bit.

(ii) Pseudograph: An undirected graph that may contain both multiple (parallel) edges and self-loops.

Q19. Determine the number of vertices and edges and find the in-degree and out-degree of each vertex for the given directed multigraph.

Unit III CO3 | Bloom L3 3 Marks Score: 9.0

Count the vertices $|V|$ and edges $|E|$. For each vertex, the in-degree is the number of incoming arrows (including self-loops), and the out-degree is the number of outgoing arrows (including self-loops). Sum of in-degrees = Sum of out-degrees = $|E|$.
