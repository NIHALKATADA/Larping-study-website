Q1. Determine whether each of the following is a proposition. If it is a proposition, state whether it is True or False. (a) Every prime number greater than 2 is odd. (b) 7 + 8 = 16. (c) The Moon is a planet. (d) India is located in Asia.

(a) It is a proposition. It is True.

(b) It is a proposition. It is False (since 7+8=15).

Q14. Let p and q be the propositions “The election is decided” and “The votes have been counted,” respectively. Express each of these compound propositions as an English sentence. (a) ¬q → ¬p (b) ¬p → ¬q (c) ¬q ∨ (¬p ∧ q)

Unit I CO1 | Bloom L3 3 Marks Score: 8.0

(a) ¬q → ¬p: If the votes have not been counted, then the election is not decided.

(b) ¬p → ¬q: If the election is not decided, then the votes have not been counted.

(c) ¬q ∨ (¬p ∧ q): The votes have not been counted, or the election is not decided and the votes have been counted.

Q25. State the converse, contrapositive, and inverse of each of these conditional statements. (a) If it snows tonight, then I will stay at home. (b) I go to the beach whenever it is a sunny summer day.

Unit I CO1 | Bloom L3 5 Marks Score: 5.2

(a) If it snows tonight, then I will stay at home.

Let p: It snows tonight, q: I stay at home.

Converse (q → p): If I stay at home, then it snows tonight.

Inverse (¬p → ¬q): If it does not snow tonight, then I will not stay at home.

Contrapositive (¬q → ¬p): If I do not stay at home, then it does not snow tonight.

(b) I go to the beach whenever it is a sunny summer day.

This means: If it is a sunny summer day, then I go to the beach. (p: It is a sunny summer day, q: I go to the beach)

Converse: If I go to the beach, then it is a sunny summer day.

Inverse: If it is not a sunny summer day, then I do not go to the beach.

Contrapositive: If I do not go to the beach, then it is not a sunny summer day.

Q9. Solve the following recurrence relation: a_n = 4a_{n-1} - a_{n-2}

Unit II CO2 | Bloom L3 2 Marks Score: 7.2

The characteristic equation is r^2 - 4r + 1 = 0.

Using the quadratic formula, the roots are r = (4 ± √12) / 2 = 2 ± √3.

The solution is an = c1(2 + √3)n + c2(2 - √3)n.

Q17. Solve the following recurrence relation: a_n = 6a_{n-1} - 9a_{n-2}, a_0 = 1, a_1 = 9

Unit II CO2 | Bloom L3 3 Marks Score: 8.2

Characteristic equation: r^2 - 6r + 9 = 0 ⇒ (r - 3)^2 = 0. Root: r = 3 (repeated).

General solution: an = (c1 + c2n)3n.

For n=0: c1 = 1.

For n=1: (1 + c2)3 = 9 ⇒ 1 + c2 = 3 ⇒ c2 = 2.

Solution: an = (1 + 2n)3n.

Q18. Solve the following recurrence relation: a_n - 4a_{n-1} + 5a_{n-2} - 2a_{n-3} = 0 given a_0 = 1, a_1 = 3, a_2 = 8

Factoring gives (r - 1)^2(r - 2) = 0, so roots are r = 1, 1, 2.

From conditions:
c1 + c3 = 1
c1 + c2 + 2c3 = 3
c1 + 2c2 + 4c3 = 8.

Solving yields c1 = -2, c2 = -1, c3 = 3.

Q20. Solve the following recurrence relation by using generating function: a_n = 3a_{n-1} + 2a_{n-2} given a_0 = 1, a_1 = 3

Unit II CO2 | Bloom L4 3 Marks Score: 7.4

Let G(x) be the generating function. Multiply by x^n and sum:
G(x) - 1 - 3x = 3x(G(x) - 1) + 2x^2 G(x).

G(x)(1 - 3x - 2x^2) = 1 ⇒ G(x) = 1 / (1 - 3x - 2x^2).

Let the roots of 1 - 3x - 2x^2 = 0 be finding roots of r^2 - 3r - 2 = 0, r = (3 ± √17)/2.

The sequence is given by expanding via partial fractions, resulting in an = c1((3 + √17)/2)n + c2((3 - √17)/2)n where constants are found from initial conditions.

Q21. Find the value of n: (n + 1)P_3 = 5 x nP_2

Unit II CO2 | Bloom L3 5 Marks Score: 9.3

Using the permutation formula: (n+1)! / (n+1-3)! = 5 × [n! / (n-2)!].

(n+1)! / (n-2)! = 5 × n! / (n-2)!

Canceling (n-2)! from both sides gives (n+1)! = 5 × n!.

(n+1)n! = 5n! ⇒ n + 1 = 5 ⇒ n = 4.

Q22. Solve the following recurrence relation by using generating function: a_n = 3a_{n-1} - 2a_{n-2} given a_0 = 2, a_1 = 5

Unit II CO2 | Bloom L4 5 Marks Score: 7.2

Let G(x) be the generating function. G(x) - 2 - 5x = 3x(G(x) - 2) - 2x^2 G(x).

G(x)(1 - 3x + 2x^2) = 2 - x ⇒ G(x) = (2 - x) / ((1 - x)(1 - 2x)).

Using partial fractions: (2 - x) / ((1 - x)(1 - 2x)) = A / (1 - x) + B / (1 - 2x).

Solving gives A = -1 and B = 3. Thus, G(x) = -1/(1 - x) + 3/(1 - 2x).

Solution: an = 3(2n) - 1.

Q23. Solve the following recurrence relation: a_{n+2} - 7a_{n+1} + 12a_n = 0, given a_1 = 2, a_2 = 7.

Unit II CO2 | Bloom L4 5 Marks Score: 8.5

Characteristic equation: r^2 - 7r + 12 = 0 ⇒ (r - 3)(r - 4) = 0. Roots: 3, 4.

General solution: an = c13n + c24n.

Using conditions: 3c1 + 4c2 = 2 and 9c1 + 16c2 = 7.

Multiply first by 4: 12c1 + 16c2 = 8. Subtracting the second gives 3c1 = 1 ⇒ c1 = 1/3.

Then 4c2 = 2 - 1 = 1 ⇒ c2 = 1/4.

Solution: an = 3n-1 + 4n-1.

Q27. Solve the following recurrence relation by using generating function: a_n = 2a_{n-1} + 3a_{n-2} given a_0 = 1, a_1 = 2

Unit II CO2 | Bloom L4 5 Marks Score: 5.8

Let G(x) be the generating function. G(x) - 1 - 2x = 2x(G(x) - 1) + 3x^2 G(x).

G(x)(1 - 2x - 3x^2) = 1 ⇒ G(x) = 1 / ((1 - 3x)(1 + x)).

Using partial fractions: 1 / ((1 - 3x)(1 + x)) = A / (1 - 3x) + B / (1 + x) gives A = 3/4, B = 1/4.

Solution: an = (3/4)3n + (1/4)(-1)n.

Q30. Solve the following recurrence relation by using generating function: a_n = a_{n-1} + a_{n-2} given a_0 = 0, a_1 = 1

Unit II CO2 | Bloom L4 5 Marks Score: 6.7

This is the Fibonacci sequence.

Let G(x) be the generating function. G(x) - x = x G(x) + x^2 G(x).

G(x)(1 - x - x^2) = x ⇒ G(x) = x / (1 - x - x^2).

Using partial fractions with roots of 1 - x - x^2 = 0, we get Binet's formula: an = (1/√5) [ ((1+√5)/2)n - ((1-√5)/2)n ].

Q1. Define the following terms with graphs: (i) Complete Bipartite Graph (ii) Complete graph

Unit III CO3 | Bloom L1 2 Marks Score: 5.4

(i) Complete Bipartite Graph: A bipartite graph $G=(V, E)$ with partition $V = V_1 \cup V_2$ is a complete bipartite graph if every vertex in $V_1$ is connected to every vertex in $V_2$. Denoted as $K_{m,n}$ where $m=|V_1|$ and $n=|V_2|$.

(ii) Complete graph: A simple graph in which every pair of distinct vertices is connected by a unique edge. A complete graph on $n$ vertices is denoted as $K_n$.

Q4. State the Handshaking Theorem.

Unit III CO3 | Bloom L1 2 Marks Score: 5.5

The Handshaking Theorem states that in any undirected graph, the sum of the degrees of all vertices is equal to twice the number of edges. Mathematically, $\sum_{v \in V} deg(v) = 2|E|$. As a consequence, the number of vertices with an odd degree must be even.
