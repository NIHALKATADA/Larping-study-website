Tautology & Contradiction

  • Tautology: A proposition that is always True (e.g., p ∨ ¬p).
  • Contradiction: A proposition that is always False (e.g., p ∧ ¬p).
  • Contingency: A proposition that can be True or False depending on truth values.

Conditionals

For a conditional statement p → q:

TypeForm
Converseq → p
Inverse¬p → ¬q
Contrapositive¬q → ¬p

Note: p → q ≡ ¬q → ¬p (Logically equivalent to contrapositive)

Key Logical Equivalences

De Morgan's¬(p ∧ q) ≡ ¬p ∨ ¬q
¬(p ∨ q) ≡ ¬p ∧ ¬q
Implicationp → q ≡ ¬p ∨ q
Double Negation¬(¬p) ≡ p
Biconditionalp ↔ q ≡ (p → q) ∧ (q → p)

Unit II: Counting Methods CO2

Permutations & Combinations

  • Permutation (Order matters):
    nPr = n! / (n-r)!
  • Combination (Order doesn't matter):
    nCr = n! / (r!(n-r)!)
  • Identity: nCr = nCn-r

Linear Homogeneous Recurrences

Form: an = c1an-1 + c2an-2 + ... + ckan-k

  • Degree/Order: k (number of previous terms involved)
  • Characteristic Eq: rk - c1rk-1 - ... - ck = 0

Solving Recurrences (Roots)

Based on roots of the Characteristic Equation:

RootsGeneral Solution
Distinct (r1 ≠ r2)an = c1r1n + c2r2n
Repeated (r1 = r2)an = (c1 + c2n)r1n
Multiplicity man = (c1 + c2n + ... + cmnm-1)r1n

Generating Functions

For a sequence a0, a1, a2..., G(x) = Σ anxn

  • Sequence 1, 1, 1, ...: G(x) = 1 / (1 - x)
  • Sequence 1, 2, 3, ...: G(x) = 1 / (1 - x)2
  • Sequence an: G(x) = 1 / (1 - ax)
  • Fibonacci Sequence: G(x) = x / (1 - x - x2)

Unit III: Graph Theory CO3

Complete & Bipartite Graphs

  • Complete Graph (Kn): Every pair of vertices is connected by a unique edge. Edges = n(n-1)/2.
  • Bipartite Graph: Vertices can be partitioned into V1 and V2 such that every edge connects V1 to V2.
  • Complete Bipartite (Km,n): Every vertex in V1 connects to every vertex in V2. Edges = m × n.

Handshaking Theorem

Σ deg(v) = 2|E|

  • The sum of degrees of all vertices is always even (twice the number of edges).
  • The number of vertices with an odd degree must be even.

Graph Matrices

  • Adjacency Matrix (A): Square matrix. Aij = number of edges between vi and vj.
  • Incidence Matrix (M): Rows = vertices, Columns = edges. Mij = 1 if edge ej is incident on vi.

Graph Isomorphism

Two graphs G1 and G2 are isomorphic if they share the same structure. They must have the same:

  • Number of vertices and edges
  • Degree sequence (list of vertex degrees)
  • Number of cycles of same length
