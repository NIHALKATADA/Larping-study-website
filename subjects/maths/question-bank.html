Q9. Define the following terms with examples. (a) Tautology (b) Conditional Statement

Unit I CO1 | Bloom L1 2 Marks

(a) Tautology: A compound proposition that is always true, regardless of the truth values of the propositional variables that occur in it. Example: p ∨ ¬p (Either it is raining or it is not raining).

(b) Conditional Statement: A statement of the form p → q, which is false only when p is true and q is false. It is read as 'if p, then q'. Example: If it rains, then I will stay at home.

Q19. Using logical laws (without truth tables), prove the following (a) (p → q) ≡ (¬q → ¬p) (b) ¬(p → q) ≡ p ∧ ¬q

Unit I CO1 | Bloom L4 3 Marks

(a) Prove: (p → q) ≡ (¬q → ¬p)
LHS = p → q
≡ ¬p ∨ q (Implication law)
≡ q ∨ ¬p (Commutative law)
≡ ¬(¬q) ∨ ¬p (Double negation)
≡ ¬q → ¬p (Implication law) = RHS. Hence Proved.

(b) Prove: ¬(p → q) ≡ p ∧ ¬q
LHS = ¬(p → q)
≡ ¬(¬p ∨ q) (Implication law)
≡ ¬(¬p) ∧ ¬q (De Morgan's law)
≡ p ∧ ¬q (Double negation) = RHS. Hence Proved.

Q26. Show that ¬(p ∨ (¬p ∧ q)) and ¬p ∧ ¬q are logically equivalent by developing a series of logical equivalences.

Unit I CO1 | Bloom L4 5 Marks

We start with the LHS:

¬(p ∨ (¬p ∧ q))

≡ ¬p ∧ ¬(¬p ∧ q) (De Morgan's law)

≡ ¬p ∧ (¬(¬p) ∨ ¬q) (De Morgan's law)

≡ ¬p ∧ (p ∨ ¬q) (Double negation law)

≡ (¬p ∧ p) ∨ (¬p ∧ ¬q) (Distributive law)

≡ F ∨ (¬p ∧ ¬q) (Negation law)

≡ ¬p ∧ ¬q (Identity law)

This is exactly the RHS. Hence proved.

Q27. Define the following terms with suitable truth table: (a) Tautology (b) Biconditional Statement (c) Contingency (d) Contrapositive (e) Exclusive OR

Unit I CO1 | Bloom L2 5 Marks

(a) Tautology: A proposition that is always true. Ex: p ∨ ¬p.

(b) Biconditional Statement: p ↔ q. True when both have same truth value.

(c) Contingency: A proposition that is neither a tautology nor a contradiction (has both True and False values).

(d) Contrapositive: Of p → q is ¬q → ¬p. They are logically equivalent.

(e) Exclusive OR: p ⊕ q. True when exactly one of p or q is true.

Q15. Solve the following recurrence relation by using generating function: a_n = 7a_{n-1}, a_0 = -2

G(x) (1 - 7x) = -2 ⇒ G(x) = -2 / (1 - 7x).

The coefficient of x^n in G(x) gives the sequence: an = -2 × 7n.

Q4. State the Handshaking Theorem.

Unit III CO3 | Bloom L1 2 Marks

The Handshaking Theorem states that in any undirected graph, the sum of the degrees of all vertices is equal to twice the number of edges. Mathematically, $\sum_{v \in V} deg(v) = 2|E|$. As a consequence, the number of vertices with an odd degree must be even.
