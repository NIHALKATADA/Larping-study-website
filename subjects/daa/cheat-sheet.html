Unit I: Introduction & Basics CO1

Algorithm Characteristics

  • Finiteness: Terminates after a finite number of steps.
  • Definiteness: Each step is precisely defined.
  • Input: Zero or more inputs.
  • Output: One or more outputs.
  • Effectiveness: Operations must be basic and doable in finite time.

Loop Invariant

A property true before and after each loop iteration. Used to prove correctness.

  • Initialization: True before first iteration.
  • Maintenance: If true before iteration, remains true before next.
  • Termination: Gives useful property when loop ends.

Heap Data Structure

  • Max Heap: Parent ≥ Children. Largest at root.
  • Min Heap: Parent ≤ Children. Smallest at root.

MAX-HEAPIFY: Maintains max-heap property. O(log n).

BUILD-MAX-HEAP: Bottom-up heap construction. O(n).

Substitution Method

Steps to solve recurrences:

  1. Guess the form of the solution (e.g., O(n log n)).
  2. Use mathematical induction to prove the guess.
  3. Substitute guessed bound into recurrence.
  4. Show condition holds for constants.

Unit II: Core Mechanics CO2

Time vs Space Complexity

Time Complexity: Time taken as a function of input length.

Space Complexity: Memory required as a function of input length.

Example: Mergesort: Time O(n log n), Space O(n). Bubble Sort: Time O(n²), Space O(1).

Unit III: Advanced Concepts CO3

Asymptotic Bounds

  • Best-case: Minimum time required. Lower bound.
  • Worst-case: Maximum time required. Upper bound (Big-O).
  • Average-case: Expected time required over all inputs.

Divide and Conquer

Breaks problem down recursively.

  • Divide: Break into smaller sub-problems.
  • Conquer: Recursively solve sub-problems (or directly if small).
  • Combine: Merge solutions.

Examples: Merge Sort, Quick Sort, Binary Search.

Unit IV: Design Patterns & Architectures CO4

Amortized Analysis

Calculates the average time per operation over a sequence, guaranteeing performance even if a single operation is expensive.

Aggregate Method: Computes total time T(n) for n ops, sets cost to T(n)/n.

Master Theorem

For recurrences of form T(n) = aT(n/b) + f(n)

Calculate c = log_b(a), compare n^c with f(n):

  • Case 1: f(n) is smaller -> O(n^c)
  • Case 2: f(n) is equal -> O(n^c log n)
  • Case 3: f(n) is larger -> O(f(n))

Unit V: Modern Ecosystem CO5

Algorithm Correctness

  • Partial Correctness: If the algorithm halts, output is correct. (May loop forever).
  • Total Correctness: Guaranteed to halt AND produce correct output.

Radix & Bucket Sort

Radix Sort: Sorts digit by digit using stable sort (e.g., Counting Sort) for each place value. O(d(n+k))

Bucket Sort: Divides elements into buckets based on value, sorts buckets individually, then concatenates. Best for uniformly distributed data.
