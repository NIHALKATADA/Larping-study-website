Unit I: Introduction & Basics CO1

JVM Ecosystem & Internals

Java compiles to bytecode, making it platform-independent (WORA). The ClassLoader Subsystem handles dynamic class loading, linking, and initialization. The Execution Engine parses bytecode using an Interpreter and a JIT (Just-In-Time) compiler.

javac App.java // Produces App.class (Bytecode)
java App       // JVM Execution Engine runs Bytecode
Trap: ClassNotFoundException vs NoClassDefFoundError. ClassNotFoundException is thrown during explicit dynamic loading (e.g., Class.forName()). NoClassDefFoundError occurs if a class was present at compile-time but is missing at runtime during implicit loading.

Data Types & Memory Semantics

Primitives reside on the Thread Stack; Objects reside on the Shared Heap. Java explicitly defines sizes regardless of the OS (e.g., int is always 32-bit). Object references themselves are passed by value (a copy of the reference is passed).

int x = 5; // Stack primitive
Integer y = Integer.valueOf(5); // Heap object reference on stack
Pro Tip: Autoboxing & Constant Pool. Integer a = 100; Integer b = 100; a == b is TRUE because integers between -128 and 127 are cached in the IntegerCache. Outside this range, they are distinct objects!

Unit II: Core Mechanics & OOP CO2

Polymorphism & Dynamic Dispatch

Method overloading is compile-time polymorphism (Static Binding). Method overriding is runtime polymorphism (Dynamic Dispatch/Binding), utilizing the vtable to invoke the subclass implementation. super is used to invoke the overridden superclass method.

Parent obj = new Child();
obj.display(); // Calls Child's display() at runtime
Trap: Method Hiding. You cannot override static methods. If a child class defines the same static method, it hides the parent's method. The call is resolved at compile-time based on the reference type, not the object type!

Interfaces vs Abstract Classes

Interfaces define contracts (can have default and static methods since Java 8). Abstract classes can hold state (instance variables) and constructors. A class can implement multiple interfaces but extend only one class.

interface Flyer { default void land() { /* body */ } }
abstract class Bird { abstract void sing(); }
Pro Tip: The Diamond Problem. If a class implements two interfaces with identical default methods, the compiler forces you to override the method and explicitly invoke the desired interface's method using InterfaceName.super.method().

Constructors & Initialization Blocks

Instance Initialization Blocks (IIB) run before the constructor but after the call to super(). Static blocks run once when the class is loaded by the ClassLoader. Constructors can be chained using this().

class Demo {
    static { System.out.println("Static Init"); }
    { System.out.println("Instance Init"); }
    Demo() { System.out.println("Constructor"); }
}

Unit III: Memory, Multithreading & Concurrency CO3

Garbage Collection & Memory Tuning

GC reclaims unreachable objects. The Heap is divided into Young Gen (Eden, S0, S1) and Old Gen. Objects surviving multiple Minor GCs are promoted. ZGC and G1GC are modern concurrent collectors minimizing pause times.

System.gc(); // Suggests GC, doesn't guarantee it.
// TLABs (Thread-Local Allocation Buffers) speed up Eden allocation.
Trap: Memory Leaks. Java can have memory leaks if strong references to unused objects are maintained (e.g., an ever-growing static HashMap). The GC will not clear them!

Thread Synchronization & Visibility

synchronized utilizes intrinsic locks (monitors) to guarantee mutual exclusion. The volatile keyword guarantees memory visibility across threads by reading/writing directly to Main Memory instead of CPU caches, but it does NOT guarantee atomicity.

volatile boolean flag = true;
synchronized(this) { count++; } // Prevents Race Conditions
Pro Tip: Happens-Before Relationship. A write to a volatile field happens-before every subsequent read of that field. This prevents instruction reordering by the JIT compiler and CPU, ensuring safe publication.

Unit IV: Collections Framework & Generics CO4

Generics & Type Erasure

Generics provide compile-time type safety. Type Erasure means the JVM removes generic type info during compilation to maintain backward compatibility, replacing them with upper bounds or Object. You cannot instantiate a generic array (new T[]).

List<String> list = new ArrayList<>();
// Compiles to: List list = new ArrayList();
Trap: Covariance vs Contravariance (PECS). List<Object> is NOT a supertype of List<String>. Use wildcards: ? extends T for Producer (read-only), ? super T for Consumer (write-only).

Collections Internals (HashMap)

HashMap computes the hash of the key to find the bucket array index. If collisions occur, it forms a LinkedList. To prevent DoS attacks via collision degradation, Java 8 introduced the Treeification Threshold (8), transforming lists into Red-Black Trees for O(log n) lookup.

Map<String, Integer> map = new HashMap<>();
map.put("Key", 1); // Uses hashCode() and equals()
Pro Tip: ConcurrentHashMap. Instead of locking the entire map (like HashTable), ConcurrentHashMap uses CAS (Compare-And-Swap) operations and synchronizes only the specific node (bucket) being updated, allowing high concurrency.

Unit V: Exceptions & Modern Java 8+ Features CO5

Exception Handling & Hierarchy

Throwable is the root. Error (JVM crash) and RuntimeException (logic bugs) are Unchecked. Everything else (e.g., IOException) is Checked and must be handled. try-with-resources automatically closes objects implementing AutoCloseable.

try (BufferedReader br = new BufferedReader(new FileReader("x.txt"))) {
    br.readLine();
} catch (IOException e) { /* handled */ }
Trap: Finally Overwrite. If a try block returns a value (e.g., 5), but the finally block also has a return statement (e.g., 10), the finally block silently overwrites the result. The method returns 10!

Lambdas & Streams API

Streams enable declarative data processing. Intermediate operations (filter, map) are lazy and do nothing until a Terminal operation (collect, reduce) is invoked. Lambdas (->) implement Functional Interfaces (SAM: Single Abstract Method).

List<Integer> evens = list.stream()
    .filter(n -> n % 2 == 0) // Lazy Intermediate
    .collect(Collectors.toList()); // Terminal Execution
Pro Tip: invokedynamic. Lambdas are NOT anonymous inner classes. The compiler uses the invokedynamic bytecode instruction to generate the lambda implementation dynamically at runtime, heavily optimizing memory and class-loading overhead.

String Pool & Immutability

String objects are immutable; modifying one creates a new instance. String literals are stored in the String Constant Pool to save memory. Use StringBuilder for heavy concatenations to avoid generating garbage objects.

String s1 = "Hi"; String s2 = new String("Hi");
// s1 == s2 is FALSE (s2 is forced into the main Heap).
// s1.equals(s2) is TRUE.
