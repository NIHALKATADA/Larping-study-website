Unit I: Introduction & Basics CO1

Java Environment

  • JDK (Java Development Kit): JRE + Dev Tools (javac, etc.)
  • JRE (Java Runtime Environment): JVM + Core Libraries
  • JVM (Java Virtual Machine): Executes Bytecode. Makes Java Platform-Independent (WORA).

Constructors & Keywords

  • Constructor: Special block, same name as class, no return type. Initializes objects.
  • this: Reference to current object. Used to resolve shadowing and chain constructors.
  • super: Reference to parent object. Invokes parent constructors/methods.

Multithreading

  • Thread Class: class MyThread extends Thread
  • Runnable Interface: class MyRunnable implements Runnable
  • Lifecycle: New -> Runnable -> Running -> Waiting/Blocked -> Terminated
  • Synchronization: Prevents thread interference.

Collections Framework (List)

  • ArrayList: Dynamic array, fast random access, slow insertion/deletion.
  • LinkedList: Doubly linked list, fast insertion/deletion, slow access.
  • Vector: Legacy, synchronized (thread-safe) dynamic array.

Unit III: Advanced Concepts CO3

Memory Management

  • Heap: Stores objects and instance variables. Globally accessible.
  • Stack: Stores local variables and object references. Thread-specific.
  • Garbage Collection: Automatically deletes unreferenced objects in the Heap.

Collections Framework (Set & Map)

  • HashSet: Unordered unique elements. Backed by HashMap.
  • TreeSet: Sorted unique elements.
  • HashMap: Key-value pairs. Keys must be unique. Unordered.
  • TreeMap: Sorted key-value pairs based on keys.

Strings

  • Immutable: Strings cannot be changed once created. Safe for threads.
  • String Pool: Special memory area for literals to save space.
  • == vs equals(): `==` compares references. `.equals()` compares content.
  • StringBuilder/Buffer: Mutable sequence of characters.

Java 8+ Features

  • Lambda Expressions: (a, b) -> a + b;
  • Streams API: Functional-style operations on streams of elements.
  • Optional: Container object to prevent NullPointerException.
  • Default Methods: Interfaces can have methods with bodies.

Unit V: Modern Ecosystem CO5

OOP Pillars

  • Encapsulation: Data hiding using private variables and public getters/setters.
  • Abstraction: Hiding implementation details (Abstract Classes / Interfaces).
  • Inheritance: Reusing code from a parent class (IS-A relationship).
  • Polymorphism: One interface, multiple methods (Overloading / Overriding).

Exception Handling

try {
    // Risky code
} catch (ExceptionType e) {
    // Handle error
} finally {
    // Always executes
}
  • Checked: Compile-time exceptions (e.g., IOException).
  • Unchecked: Run-time exceptions (e.g., NullPointerException).

Type Casting

  • Implicit (Widening): Small to large type. int a = 10; double d = a;
  • Explicit (Narrowing): Large to small type. double d = 10.5; int a = (int)d;
  • Upcasting: Subclass to Superclass (Automatic).
  • Downcasting: Superclass to Subclass (Requires cast).
