Naive Bayes Classifier

Bayes' Theorem:
P(A|B) = [P(B|A) * P(A)] / P(B)

  • P(A|B): Posterior
  • P(B|A): Likelihood
  • P(A): Prior
  • P(B): Marginal

Logistic Regression

Sigmoid Function:
σ(z) = 1 / (1 + e-z)

Output range: [0, 1]

Log-Loss (Binary Cross-Entropy):
Cost = -[y log(ŷ) + (1-y)log(1-ŷ)]

Support Vector Machines (SVM)

  • Hyperplane: Linear decision boundary separating classes.
  • Support Vectors: Closest data points to hyperplane.
  • Hard vs Soft Margin: Soft margin allows misclassifications (slack) to prevent overfitting.
  • Kernel Trick: Maps data to higher dims (RBF, Poly) for non-linear separation.

Unit III: Advanced Concepts CO3

Linear Regression

Hypothesis: hθ(x) = θ0 + θ1x1 + ... + θnxn

Cost Function (MSE):
J(θ) = (1/2m) ∑ (hθ(x(i)) - y(i))2

Goal: Minimize sum of squared residual errors (OLS).

Unit IV: Design Patterns & Architectures CO4

Gradient Descent

Iterative optimization algorithm.

Update Rule:
θj := θj - α * ∂J(θ)/∂θj

  • α = Learning Rate
  • Too high: Overshoots minimum
  • Too low: Slow convergence

K-Nearest Neighbors (KNN)

Non-parametric, instance-based learning.

Euclidean Distance:
d(p, q) = √(∑ (qi - pi)2)

Choosing K:
Small K = Overfitting (High variance)
Large K = Underfitting (High bias)

Bias-Variance Tradeoff

IssueBiasVarianceFix
UnderfittingHighLowIncrease complexity
OverfittingLowHighRegularize, more data, prune

Decision Trees

Entropy:
H(S) = - ∑ pi log2(pi)

Gini Impurity:

Information Gain: Reduction in entropy after splitting a node.

Data Scaling

Min-Max Normalization:
x' = (x - xmin) / (xmax - xmin)

Z-Score Standardization:
z = (x - μ) / σ

Ensures features with large ranges don't dominate distance calculations.
