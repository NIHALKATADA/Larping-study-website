Unit I: Fundamentals & Hypothesis Spaces CO1

The Bias-Variance Decomposition

Total Error = Bias² + Variance + Irreducible Error. Bias is the simplifying assumptions (underfitting). Variance is hypersensitivity to noise (overfitting).

Example: Linear regression on sine wave data has high bias; a 50-depth decision tree on noisy data has high variance.

Curse of Dimensionality & Manifold Hypothesis

As dimensions $D$ increase, the volume of the space grows exponentially, making data extremely sparse. The Manifold Hypothesis posits that real-world high-dimensional data actually lies on low-dimensional, non-linear manifolds embedded within the high-dimensional space.

Example: 1024-pixel images exist in a 1024D space, but valid human faces only span a tiny 50D manifold within it.

Trick: PCA only discovers linear manifolds. If the examiner asks to untangle a "Swiss Roll" dataset, you MUST use non-linear methods like ISOMAP or t-SNE!

Inductive Bias & No Free Lunch Theorem

No Free Lunch Theorem: Averaged over all possible data distributions, every algorithm performs equally well. Thus, an algorithm must make assumptions (Inductive Bias) to learn effectively.

Example: CNNs have an inductive bias for spatial locality (nearby pixels are related); RNNs assume sequential temporality.

Unit II: Linear Models & Optimization Convexity CO2

Logistic Regression & Cross-Entropy

Uses the Sigmoid function $\sigma(z) = \frac{1}{1 + e^{-z}}$ to map logits to probabilities. Optimized via Log-Loss (Binary Cross-Entropy), heavily penalizing confident, wrong predictions logarithmically.

Example: Predicting if an email is spam. If the model outputs 0.99 for a ham email, the log-loss penalty approaches infinity.

SVMs, Maximum Margin & Kernel Trick

SVMs maximize the margin $\frac{2}{||w||}$ between support vectors. The Kernel Trick uses Mercer’s theorem to implicitly compute dot products in a high-dimensional feature space without explicit transformation mapping $\phi(x)$.

Example: An RBF kernel classifying concentric circles by projecting them into 3D space where a flat hyperplane can cleanly slice them.

Pro-Tip: The $C$ parameter in Soft-Margin SVM controls the penalty for misclassification. Low $C$ = wide margin (high bias). High $C$ = hard margin (high variance/overfitting).

VC Dimension & PAC Learning Bounds

Probably Approximately Correct (PAC) framework provides mathematical bounds on sample complexity. Vapnik-Chervonenkis (VC) Dimension is the maximum number of points a hypothesis class can perfectly shatter (memorize).

Example: A 2D linear classifier has a VC dimension of 3, meaning it can perfectly classify any arrangement of 3 points, but fails on some arrangements of 4 points (like XOR).

Unit III: Ensemble Theory & Information Metrics CO3

Ensemble Meta-Algorithms

Bagging trains parallel models on bootstrapped data (decreases variance). Boosting trains sequential weak learners focused on correcting prior residual errors (decreases bias).

Example: Random Forest (Bagging) averages 100 deep trees. XGBoost (Boosting) strings together 100 shallow stumps to minimize a gradient loss function.

Information Gain & Gini Impurity

Decision trees recursively partition data. They maximize Information Gain (reduction in Shannon Entropy $H = -\sum p \log_2 p$) or minimize Gini Impurity ($1 - \sum p^2$) at each node split.

Example: Predicting disease. Splitting on "Fever = True" yields child nodes that are much purer (lower entropy) than the parent node.

Trick: Information Gain is inherently biased towards attributes with high cardinality (e.g., User ID). The examiner will test this: always use Gain Ratio to penalize high-branching attributes!

Precision-Recall vs ROC-AUC

ROC curve plots True Positive Rate vs False Positive Rate. PR curve plots Precision vs Recall. ROC is misleading for heavily imbalanced datasets because TNs dominate the FPR denominator.

Example: Fraud detection (0.1% fraud). An ROC-AUC of 0.90 looks great, but PR-AUC reveals the model has terrible precision and produces massive false alarms.

Unit IV: Gradient Dynamics & Deep Architectures CO4

Backpropagation & The Chain Rule

Neural networks update weights via gradient descent: $\theta = \theta - \alpha \nabla J(\theta)$. Backprop efficiently calculates the gradient of the loss function with respect to weights by propagating errors backward using the calculus chain rule.

Example: If a network predicts 0.9 for a dog image (label 1), backprop sends the 0.1 error backwards, nudging earlier convolutional filters to activate stronger on dog ears.

Vanishing Gradients & Modern Activations

Deep networks using Sigmoid/Tanh suffer from vanishing gradients because their derivatives max out at 0.25; gradients decay exponentially through layers. ReLU ($f(x) = \max(0, x)$) solves this by providing a constant derivative of 1 for positive inputs.

Example: Training a 100-layer ResNet. With Sigmoid, the first layer never updates. With ReLU and Skip Connections, the gradient flows directly to early layers.

Regularization: L1 vs L2 (Weight Decay)

L1 (Lasso): Adds $\lambda \sum |w|$ to the loss. Encourages sparse weight vectors (exact zeros) due to diamond-shaped constraint geometry.
L2 (Ridge): Adds $\lambda \sum w^2$. Prevents exploding weights by decaying them proportionally.

Example: Use L1 for gene expression data to eliminate 99% of irrelevant genes. Use L2 in Neural Networks (Weight Decay) to keep activations stable.

Pro-Tip: Dropout is mathematically equivalent to a form of L2 regularization, acting as an ensemble of sub-networks by randomly zeroing activations during training!

Unit V: Unsupervised Topology & MLOps CO5

K-Means & The E-M Algorithm

K-Means is a specific instance of the Expectation-Maximization (EM) algorithm. E-step: Assign points to nearest centroid. M-step: Recalculate centroids. It converges to a local optimum minimizing within-cluster sum of squares (WCSS).

Example: Clustering retail shoppers based on recency and frequency of purchases. K-Means finds $K$ distinct buyer personas.

Principal Component Analysis (PCA) Eigen-theory

PCA projects data onto orthogonal axes of maximum variance. It computes the eigenvectors (directions) and eigenvalues (magnitude of variance) of the data's covariance matrix. It removes multicollinearity.

Example: Given square footage and number of rooms (highly correlated), PCA collapses them into a single "house size" principal component axis.

Data Leakage & Time-Series Validation

Leakage occurs when information from the validation/test set maliciously bleeds into the training set, causing deceptively high performance that fails in production.

Example: Applying `StandardScaler().fit_transform(X)` on the entire dataset before doing `train_test_split()`. The test set's mean/variance leaked into the scaler!

Trick: Standard K-Fold CV on Time-Series data causes future leakage (training on Friday to predict Thursday). You must strictly use Rolling Origin / TimeSeriesSplit.
