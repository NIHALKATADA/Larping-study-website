Q1. Differentiate between supervised, unsupervised, and reinforcement learning paradigms based on input data and learning targets.

Unit I CO1 | Bloom L2 2 Marks

Supervised learning requires labeled input data where the model learns to predict specific learning targets based on historical examples. Unsupervised learning operates on unlabeled input data, aiming to discover hidden patterns, structures, or groupings without predefined targets. In contrast, reinforcement learning focuses on an agent interacting with an environment, learning to make a sequence of decisions by maximizing cumulative rewards rather than relying on explicit input-output pairs.

Unit I CO1 | Bloom L1 2 Marks

The 7-Step Machine Learning Lifecycle is a structured approach to developing ML models, and four of its critical stages include Data Collection, Data Preprocessing, Model Training, and Model Evaluation. Data Collection involves gathering raw data from various sources, while Data Preprocessing cleans and formats this data for analysis. Model Training uses algorithms to learn patterns from the data, and Model Evaluation assesses the trained model's performance on unseen data to ensure accuracy and generalization.

Exploratory Data Analysis (EDA) is a critical preprocessing step that involves investigating datasets to summarize their main characteristics, often utilizing statistical graphics and data visualization methods. Its primary objective is to uncover underlying structures, identify missing values, spot anomalies or outliers, and test hypotheses before formal modeling begins. By conducting EDA, data scientists can make informed decisions about feature selection and engineering, ultimately leading to more robust machine learning models.

Q4. Explain the significance of feature engineering in preparing raw datasets for model training.

Unit I CO1 | Bloom L2 2 Marks

Feature engineering is the process of transforming raw dataset attributes into meaningful features that better represent the underlying business problem to predictive models. This step is highly significant because the quality and relevance of features directly impact a machine learning algorithm's learning capability and predictive accuracy. Effective feature engineering can simplify model complexity, reduce the risk of overfitting, and significantly improve model performance on unseen data.

Q6. Mention two common strategies for handling missing values during data cleaning.

The first strategy involves removing rows or columns that contain missing data, which is effective when the proportion of missing values is very low. The second strategy is imputation, where missing values are replaced with estimated values such as the mean, median, or mode of the respective feature to preserve the overall dataset size.

Data normalization and feature scaling play a vital role in model fitting by ensuring that all features operate on a similar scale, preventing features with exceptionally large numerical ranges from disproportionately dominating the objective function. This standardization leads to faster and more stable convergence during optimization algorithms like Gradient Descent. Ultimately, proper scaling ensures that each feature contributes equally to the model's learning process, enhancing the overall accuracy and reliability of the predictions.

Model fitting is the foundational process in machine learning where a model's internal parameters are adjusted to best align with the patterns observed in the training data. However, fitting alone is insufficient; model validation is strictly necessary to evaluate how well this trained model generalizes to new, unseen data. Proper validation helps detect overfitting, ensuring that the model has learned the true underlying trends rather than simply memorizing the training dataset's noise.

While data collection emphasizes volume and variety, feature selection emphasizes relevance and dimensionality reduction to improve model performance and reduce computational costs.

Conversely, the dependent variable, or target, is the specific outcome or output that the model is attempting to predict or classify. The fundamental goal of supervised learning is to map the relationship between these independent predictors and the dependent target accurately.

The model is first trained exclusively on the training set, allowing it to learn patterns and adjust its parameters. Finally, it is evaluated on the unseen testing set using specific performance metrics, which verifies its ability to generalize and confirms that it has not simply overfitted to the training data.

Q15. Write the hypothesis function for a Simple Linear Regression model and define its components.

Unit II CO2 | Bloom L1 2 Marks Score: 9.3

The hypothesis function for a Simple Linear Regression model is mathematically represented as h(x) = θ0 + θ1*x. In this equation, θ0 represents the y-intercept, which is the predicted value when the input is zero. The component θ1 is the slope or weight that determines the impact of the input feature, while x represents the independent input feature itself.

Q16. State the equation for Multiple Linear Regression with n independent variables.

Unit II CO2 | Bloom L1 2 Marks

The equation for Multiple Linear Regression is expressed as y = θ0 + θ1*x1 + θ2*x2 + ... + θn*xn. In this formulation, y is the predicted dependent variable, and θ0 acts as the fundamental y-intercept or bias term. The terms θ1 through θn represent the learned coefficients or weights, each corresponding to its respective independent input variable x1 through xn.

Q17. Define residual error ei in linear regression analysis.

Unit II CO2 | Bloom L1 2 Marks

In linear regression analysis, the residual error, denoted as ei, quantifies the difference between the actual observed value and the value predicted by the model. It is mathematically defined as ei = yi - ŷi, where yi is the true target value and ŷi is the estimated prediction. Analyzing these residuals is crucial, as they help evaluate the accuracy of the model's fit and identify any unexplained variance in the data.

Q18. State the primary mathematical objective of the Ordinary Least Squares (OLS) method.

Unit II CO2 | Bloom L1 2 Marks

The primary mathematical objective of the Ordinary Least Squares (OLS) method is to determine the optimal line of best fit for a given dataset. It achieves this by systematically minimizing the sum of the squared residual errors between the actual observed values and the model's predicted values. By squaring the residuals, OLS heavily penalizes larger errors, ensuring the resulting model is as mathematically precise as possible.

Q19. Write the Mean Squared Error (MSE) cost function Jθ used in linear regression.

Unit II CO2 | Bloom L1 2 Marks

The Mean Squared Error (MSE) cost function, often denoted as J(θ), is defined as J(θ) = (1/2m) Σ (hθ(xi) - yi)². In this formula, m represents the total number of training examples in the dataset. This cost function calculates the average of the squared differences between the predicted hypotheses hθ(xi) and the actual target values yi, providing a standard metric to optimize the model's weights.

Q20. Why is Gradient Descent preferred over the analytical Normal Equation for high-dimensional datasets?

Unit II CO2 | Bloom L2 2 Marks

Gradient Descent is highly preferred for high-dimensional datasets because it is computationally efficient and scales well with an increasing number of features. Conversely, the analytical Normal Equation requires calculating the inverse of an n x n matrix, where n is the number of features. This matrix inversion has a computational complexity of roughly O(n³), making the Normal Equation impractically slow and resource-intensive for large-scale modern datasets.

Q21. What is the learning rate α in Gradient Descent, and what happens if it is set too high?

Unit II CO2 | Bloom L2 2 Marks

The learning rate, denoted by α, is a crucial hyperparameter in Gradient Descent that dictates the step size the algorithm takes when moving towards the minimum of the cost function. If the learning rate is set too high, the algorithm may overshoot the global minimum during optimization. This overshoot can lead to a failure to converge, causing the cost function to oscillate wildly or diverge entirely, breaking the learning process.

Q22. Define Polynomial Regression and explain how it captures non-linear data trends.

Unit II CO2 | Bloom L1 2 Marks

Polynomial Regression is an extension of linear regression that models the relationship between independent and dependent variables as an nth-degree polynomial function. By raising the input features to higher powers and adding them to the equation, the model curve gains the flexibility to bend and twist. This mathematical flexibility allows the model to accurately capture and fit complex, non-linear trends that a simple straight line would completely miss.

Q23. Is Polynomial Regression considered a linear or non-linear model? Explain briefly.

Unit II CO2 | Bloom L2 2 Marks

Despite its ability to fit curves, Polynomial Regression is strictly considered a linear model within the context of statistics. This classification is because the model remains linear with respect to its learnable parameters or coefficients. Even though the input features themselves undergo non-linear transformations (such as being squared or cubed), the final equation is still a linear combination of those transformed features and their respective weights.

Q24. Define Overfitting and list two common causes.

Unit II CO2 | Bloom L1 2 Marks

Overfitting is a modeling error that occurs when a machine learning algorithm learns the training data excessively well, effectively memorizing the noise and statistical fluctuations rather than the underlying pattern. As a result, the model performs excellently on training data but poorly on unseen test data. Two common causes of overfitting include utilizing overly complex models with too many parameters and training the model on small, insufficient, or highly noisy datasets.

Q25. Define Underfitting and mention how it can be identified.

Unit II CO2 | Bloom L1 2 Marks Score: 9.7

Underfitting is a condition where a machine learning model is far too simple or constrained to capture the true underlying patterns and complexities of the data. It can be easily identified when the model exhibits poor predictive performance and high error rates on both the training dataset and the validation dataset. Ultimately, an underfitted model fails to extract meaningful insights, acting as an overly generalized approximation of the problem.

Q26. Explain the Bias-Variance tradeoff in the context of model complexity.

Unit II CO2 | Bloom L2 2 Marks

The Bias-Variance tradeoff represents the delicate balance required when tuning model complexity to achieve optimal generalization. As model complexity increases, bias typically decreases because the model can better fit the data, but variance increases, increasing the risk of overfitting. Conversely, lower complexity increases bias but decreases variance, leading to underfitting; the ultimate goal is to find the sweet spot that minimizes the total combined error.

Q27. State two techniques to reduce overfitting in regression models.

Unit II CO2 | Bloom L1 2 Marks

One primary technique to reduce overfitting in regression models is introducing Regularization, such as L1 (Lasso) or L2 (Ridge), which adds penalty terms to constrain the model's weights. A second effective technique is reducing the overall model complexity by performing strict feature selection, thereby removing irrelevant or redundant variables. Both methods force the model to focus on the most significant data patterns, improving generalization on unseen datasets.

Q28. What is Regularization, and why is it added to regression cost functions?

Unit II CO2 | Bloom L2 2 Marks

Regularization is a powerful mathematical technique used to constrain or shrink the coefficient estimates towards zero to discourage highly complex models. It achieves this by adding a specific penalty term directly to the regression cost function. This penalty prevents the model's weights from becoming excessively large, thereby reducing variance, preventing overfitting, and significantly improving the model's ability to generalize to new, unseen data.

Q29. Differentiate between Ridge L2 and Lasso L1 regularization penalties.

Unit II CO2 | Bloom L2 2 Marks

Ridge Regularization, or L2, adds a penalty term to the cost function that is strictly equal to the sum of the squared magnitudes of the model's coefficients. In contrast, Lasso Regularization, or L1, incorporates a penalty equal to the sum of the absolute values of those coefficients. While both methods successfully reduce overfitting, their differing mathematical approaches lead to significantly different effects on the final weights of the model's features.

Q30. Why does Lasso L1 regularization perform automatic feature selection while Ridge L2 does not?

Unit II CO2 | Bloom L2 2 Marks Score: 9.3

Lasso (L1) regularization utilizes an absolute value penalty, which structurally encourages sparsity by forcing the coefficients of less important features exactly to zero. Because these coefficients become zero, Lasso effectively performs automatic feature selection by dropping irrelevant variables from the model. Ridge (L2) regularization, utilizing a squared penalty, shrinks coefficients asymptotically towards zero but rarely makes them exactly zero, meaning all features remain in the final model.

Q31. Write the mathematical formula for Mean Absolute Error (MAE).

Unit II CO2 | Bloom L1 2 Marks

The mathematical formula for Mean Absolute Error is written as MAE = (1/n) Σ |yi - ŷi|. In this equation, yi represents the actual observed target values, while ŷi represents the model's corresponding predicted values. The variable n denotes the total number of samples being evaluated, making MAE a measure of the average absolute distance between predictions and truth.

Q32. State the formula for Root Mean Squared Error (RMSE) and explain its advantage over MSE.

Unit II CO2 | Bloom L1 2 Marks

The formula for Root Mean Squared Error is RMSE = √((1/n) Σ (yi - ŷi)²). RMSE provides a measure of the average magnitude of the error. Its primary advantage over Mean Squared Error (MSE) is that taking the square root converts the error metric back into the same units as the target variable, making it much easier to interpret. Furthermore, like MSE, it heavily penalizes larger errors because the errors are squared before being averaged, which is highly beneficial when large errors are particularly undesirable.

Q33. What does the R2 (R-squared) coefficient measure, and what is its standard range?

Unit II CO2 | Bloom L2 2 Marks

The R-squared (R²) coefficient, also known as the coefficient of determination, measures the proportion of variance in the dependent variable that is predictably explained by the independent variables in a regression model. Its standard range lies between 0 and 1, where 0 indicates that the model explains none of the variability and 1 indicates it explains all of it. A higher R-squared value generally indicates a better fit for the model, although it should be evaluated in context with other metrics.

Q34. Why is Adjusted R2 preferred over standard R2 in Multiple Linear Regression?

Unit II CO2 | Bloom L2 2 Marks

Standard R-squared artificially inflates whenever a new independent variable is added to a model, even if that variable does not meaningfully improve the predictions. Adjusted R-squared is preferred because it incorporates a penalty for adding non-significant predictors, thereby adjusting for the number of terms in the model. This provides a more accurate and reliable measure of goodness-of-fit for multiple linear regression models, preventing overfitting by ensuring only useful variables increase the score.

Q35. Write the Sigmoid activation function formula and state its output range.

Unit III CO3 | Bloom L1 2 Marks Score: 9.0

The mathematical formula for the Sigmoid activation function is σ(z) = 1 / (1 + e^(-z)). This function maps any real-valued number into a continuously bounded output range strictly between 0 and 1. Because of this specific S-shaped output range, it is ideal for tasks such as binary classification and probability estimation, as the output can be directly interpreted as the probability of a data point belonging to the positive class.

Q36. What is the standard threshold value used in Logistic Regression for binary classification?

Unit III CO3 | Bloom L2 2 Marks

In Logistic Regression for binary classification, the standard decision threshold value is typically set to 0.5. If the model's predicted probability for an instance is greater than or equal to 0.5, the instance is classified into the positive class (class 1). Conversely, if the predicted probability is strictly less than 0.5, it is classified into the negative class (class 0). This threshold can be adjusted depending on the specific requirements of precision and recall for the problem.

Q37. Write the single-sample log-loss (binary cross-entropy) cost function formula.

Unit III CO3 | Bloom L1 2 Marks

The single-sample log-loss, also known as binary cross-entropy, is calculated using the formula Cost = - [y * log(ŷ) + (1 - y) * log(1 - ŷ)]. In this equation, y represents the true binary label of the sample (either 0 or 1), and ŷ represents the model's predicted probability that the sample belongs to class 1. This cost function heavily penalizes highly confident but incorrect predictions, guiding the model toward more accurate probability estimates.

Q38. Define a decision boundary in a binary classification problem.

Unit III CO3 | Bloom L1 2 Marks

A decision boundary in a binary classification problem is a geometric hypersurface that separates the underlying feature space into two distinct regions, one for each class. Depending on the algorithm and data, this boundary can be linear (like a hyperplane in SVM or Logistic Regression) or non-linear (like in Decision Trees or RBF-kernel SVMs). Any new data point falling on one side of this boundary is assigned to the first class, while points on the other side are assigned to the second class.

Q39. Explain the core working mechanism of the K-Nearest Neighbors (KNN) algorithm.

Unit III CO3 | Bloom L2 2 Marks

The K-Nearest Neighbors (KNN) algorithm operates as a non-parametric, instance-based learning method. When tasked with classifying a new, unseen data point, the algorithm calculates the distance between this point and all other points in the training dataset using a metric like Euclidean distance. It then identifies the 'K' closest data points (neighbors) and assigns the new point to the class that represents the statistical mode (majority vote) among those K neighbors.

Q40. State the formula for Euclidean distance between two points in n-dimensional space.

Unit III CO3 | Bloom L1 2 Marks Score: 9.3

The formula for Euclidean distance between two points, p and q, in an n-dimensional feature space is d(p, q) = √(Σ (q_i - p_i)²) for i=1 to n. This metric calculates the length of the straight-line path connecting the two points. It is widely used as the default distance metric in various machine learning algorithms, including K-Nearest Neighbors and K-Means clustering, to quantify the similarity or dissimilarity between data instances.

Q41. What happens to KNN classification performance if K is set too small or too large?

Unit III CO3 | Bloom L2 2 Marks

Setting the parameter K too small in the KNN algorithm causes the model to become overly sensitive to local noise and outliers in the training data, leading to severe overfitting and complex decision boundaries. Conversely, setting K too large causes the decision boundary to become overly smooth and generalized, leading to underfitting as the model fails to capture intricate local patterns. A balanced K value must be chosen, typically via cross-validation, to achieve optimal generalization.

Q42. Define Entropy in Information Theory and write its mathematical equation.

Unit III CO3 | Bloom L1 2 Marks

In Information Theory, Entropy is a fundamental metric used to quantify the level of uncertainty, impurity, or randomness within a given dataset. The mathematical equation for Entropy is H(S) = - Σ p_i * log2(p_i), where p_i represents the proportion or probability of elements belonging to a specific class i within the set S. A completely pure dataset has an entropy of 0, while a dataset with equally distributed classes has maximum entropy.

Q43. Define Information Gain and explain its role in building Decision Trees.

Unit III CO3 | Bloom L1 2 Marks

Information Gain measures the expected reduction in Entropy (or impurity) that is achieved by partitioning a dataset according to a specific attribute. In the context of building Decision Trees, Information Gain plays a critical role as the primary criterion for selecting the best feature to split on at each internal node. The algorithm evaluates all available features and selects the one that yields the highest Information Gain, thereby maximizing the homogeneity of the resulting child nodes.

Q44. State the Gini Impurity formula used for evaluating node splits in Decision Trees.

Unit III CO3 | Bloom L1 2 Marks

The Gini Impurity formula, commonly used in CART decision trees, is defined as Gini = 1 - Σ (p_i)², where p_i is the probability of an item belonging to class i. This metric quantifies the likelihood of a randomly chosen element from the set being incorrectly labeled if it were randomly labeled according to the distribution of labels in the subset. A Gini Impurity of 0 indicates perfect purity, while higher values indicate a more diverse mix of classes.

Q45. State Bayes' Theorem formula and label each term ((P(A|B), P(B| A), P(A), P(B)).

Unit III CO3 | Bloom L1 2 Marks

Bayes' Theorem is mathematically stated as P(A|B) = [P(B|A) * P(A)] / P(B). In this context, P(A|B) represents the posterior probability of class A given predictor B. P(B|A) is the likelihood, which is the probability of predictor B given class A. P(A) represents the prior probability of class A occurring independently, and P(B) is the marginal probability or evidence of predictor B occurring.

Q46. Why is the Naive Bayes classifier termed "naive"?

Unit III CO3 | Bloom L2 2 Marks

The Naive Bayes classifier is termed "naive" because it relies on the very strong, and often mathematically unrealistic, assumption of conditional independence among all features. Specifically, it assumes that the presence or value of one particular feature is entirely unrelated to the presence or value of any other feature, given the class label. Despite this simplification, the algorithm frequently performs surprisingly well in real-world complex applications like text classification and spam filtering.

Q47. Define a Hyperplane and Support Vectors in Support Vector Machines (SVM).

Unit III CO3 | Bloom L1 2 Marks

In the context of Support Vector Machines (SVM), a Hyperplane is the geometric, linear decision boundary that separates the feature space into regions corresponding to different classes. Support Vectors are the critical, specific data points from the training set that lie closest to the hyperplane. These vectors directly dictate the exact position and orientation of the hyperplane; if they were removed or altered, the boundary's position would shift significantly.

Q48. Differentiate between Hard Margin SVM and Soft Margin SVM.

Unit III CO3 | Bloom L2 2 Marks

Hard Margin SVM strictly enforces that a hyperplane must perfectly separate classes without allowing any misclassifications, making it highly susceptible to overfitting and completely failing if the data is not perfectly linearly separable. In contrast, Soft Margin SVM introduces a hyperparameter (usually denoted as C) and slack variables to intentionally allow a certain degree of misclassification or margin violations. This approach greatly improves the model's robustness and generalization when dealing with noisy, overlapping real-world data.

Q49. Explain the purpose of Kernel functions (e.g., RBF, Polynomial) in SVM.

Unit III CO3 | Bloom L2 2 Marks

Kernel functions, such as the Radial Basis Function (RBF) or Polynomial kernels, are mathematically utilized in SVM to compute the dot product of data points as if they were projected into a transformed, higher-dimensional feature space. The "Kernel Trick" allows the algorithm to perform this calculation without explicitly computing the coordinates of the data in that higher dimension. This enables SVMs to efficiently discover highly complex, non-linear decision boundaries that perfectly separate non-linearly separable input data.

Q50. Describe the voting structure and ensemble approach used in Random Forests.

Unit III CO3 | Bloom L2 2 Marks Score: 9.0

Random Forests are ensemble models that construct a multitude of individual decision trees during the training phase, with each tree built independently using a bootstrapped subset of the training data and a random subset of features at each split. During the prediction phase for classification tasks, each individual tree outputs a predicted class label for a given input. The final classification output of the entire Random Forest is then determined by aggregating these predictions and taking a democratic majority vote among all the trees.

Q51. Name three popular boosting ensemble algorithms covered in statistical classification.

Unit III CO3 | Bloom L1 2 Marks

Three widely used and powerful boosting ensemble algorithms in statistical classification include AdaBoost (Adaptive Boosting), Gradient Boosting Machine (GBM), and XGBoost (Extreme Gradient Boosting). AdaBoost sequentially adjusts the weights of misclassified instances to improve subsequent weak learners. GBM builds trees sequentially by minimizing a differentiable loss function via gradient descent. XGBoost is a highly optimized, scalable, and regularized implementation of gradient boosting that often yields state-of-the-art performance.

Q52. Write the mathematical formulas for Precision, Recall, and F1-Score.

Q6. 6. Derive the Ordinary Least Squares (OLS) error minimization framework for Simple Linear Regression and state its objective function.

Unit II CO2 | Bloom L3 5 Marks Score: 9.1
Ordinary Least Squares (OLS)

Simple Linear Regression models the relationship between a dependent variable $y$ and an independent variable $x$ as: $\hat{y} = mx + c$, where $m$ is the slope and $c$ is the intercept.

Objective Function: The OLS method aims to minimize the Sum of Squared Residuals (SSR) between actual and predicted values. The cost function $J$ is:
$J(m, c) = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 = \sum_{i=1}^{n} (y_i - (mx_i + c))^2$

Derivation Framework:

  • To find the optimal $m$ and $c$, we take the partial derivatives of $J$ with respect to $m$ and $c$, and set them to zero.
  • $\frac{\partial J}{\partial c} = -2 \sum_{i=1}^{n} (y_i - mx_i - c) = 0 \implies \sum y_i = m\sum x_i + nc$
  • $\frac{\partial J}{\partial m} = -2 \sum_{i=1}^{n} x_i(y_i - mx_i - c) = 0 \implies \sum x_i y_i = m\sum x_i^2 + c\sum x_i$
  • Solving these two normal equations yields the optimal formulas for slope $m$ and intercept $c$, which represent the best-fit line minimizing the squared errors.

Q7. 7. Explain how the Gradient Descent optimization algorithm updates model weights iteratively. Contrast its performance against the analytical Normal Equation on high-dimensional datasets.

Gradient Descent vs Normal Equation

Gradient Descent (GD):

GD is an iterative optimization algorithm used to minimize a cost function $J(\theta)$. It updates model weights (parameters) by moving in the direction opposite to the gradient of the cost function with respect to the weights.

  • Update Rule: $\theta_j = \theta_j - \alpha \frac{\partial J(\theta)}{\partial \theta_j}$, where $\alpha$ is the learning rate.
  • It iteratively takes steps proportional to the negative gradient until it converges to a local or global minimum.

Contrast with Normal Equation:

  • The Normal Equation provides an analytical, closed-form solution to linear regression: $\theta = (X^T X)^{-1} X^T y$.
  • High-Dimensional Datasets: The Normal Equation requires computing the inverse of an $(n \times n)$ matrix ($X^T X$), which has a time complexity of $O(n^3)$. For large number of features (e.g., $n > 10,000$), matrix inversion becomes computationally prohibitive.
  • Gradient Descent scales much better with large numbers of features ($O(n^2)$ per iteration) and is highly preferred for high-dimensional datasets and models where analytical solutions do not exist.

Q13. 13. Write the Log-Loss (Binary Cross-Entropy) cost function for Logistic Regression. Explain why standard MSE is non-convex and unsuitable for classification tasks.

Log-Loss (Binary Cross-Entropy)

The cost function for Logistic Regression is Log-Loss, also known as Binary Cross-Entropy.

Formula:

$J(\theta) = -\frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log(h_\theta(x^{(i)})) + (1 - y^{(i)}) \log(1 - h_\theta(x^{(i)})) \right]$

Where $h_\theta(x)$ is the sigmoid predicted probability and $y$ is the actual binary label (0 or 1).

Why MSE is Unsuitable:

  • If we use standard Mean Squared Error (MSE) for Logistic Regression, the cost function becomes $J(\theta) = \frac{1}{2m} \sum (\sigma(W^TX) - y)^2$.
  • Because the sigmoid function $\sigma$ is non-linear, squaring it results in a non-convex cost function landscape with multiple local minima.
  • Gradient Descent is prone to getting stuck in these local minima, failing to find the global optimum.
  • Log-Loss, conversely, guarantees a convex cost function with a single global minimum, penalizing confident wrong predictions heavily using logarithms.

    Formula: $E = -\sum_{i=1}^{c} p_i \log_2(p_i)$, where $p_i$ is the probability of class $i$.
  • Information Gain: The reduction in entropy after splitting a dataset on an attribute. The tree algorithm calculates Information Gain for every possible split and chooses the one with the highest gain.

It measures the probability of misclassifying a randomly chosen element if it were randomly labeled according to the class distribution. It is computationally faster than entropy because it doesn\'t require logarithmic calculations.
    Formula: $Gini = 1 - \sum_{i=1}^{c} p_i^2$

Naive Bayes Classifier

The Naive Bayes classifier is a probabilistic machine learning model based on Bayes\' Theorem, widely used for text classification tasks like spam filtering.

Mathematical Foundation:

  • Bayes\' Theorem states: $P(y|X) = \frac{P(X|y) \cdot P(y)}{P(X)}$
  • Where $P(y|X)$ is the posterior probability of class $y$ given features $X$.
  • $P(X|y)$ is the likelihood, and $P(y)$ is the prior probability of class $y$.

Key Assumptions (The "Naive" Aspect):

  • The core assumption is Conditional Independence of features. It assumes that the presence or absence of a particular feature (e.g., word A) is entirely independent of the presence of any other feature (e.g., word B), given the class variable.
  • Mathematically, the likelihood is decomposed as: $P(X|y) = P(x_1|y) \times P(x_2|y) \times \dots \times P(x_n|y)$.
  • Despite this assumption almost never holding perfectly true in real-world data (words in sentences are usually correlated), Naive Bayes often performs surprisingly well in practice.

Support Vector Machines (SVM)

SVM is a powerful algorithm that finds an optimal boundary between classes in an $N$-dimensional space.

  • Hyperplane: The decision boundary separating different classes. In 2D space, it\'s a line; in 3D, a flat plane.
  • Support Vectors: The specific data points lying closest to the hyperplane. They act as pillars; if they are moved or removed, the position of the dividing hyperplane alters. The algorithm only cares about these vectors.
  • Maximum Margin: SVM aims to find the hyperplane that maximizes the margin, which is the orthogonal distance between the hyperplane and the closest support vectors of each class. A wider margin implies better generalization.
  • Hard Margin vs. Soft Margin:
    - Hard Margin: Strictly separates classes without allowing any misclassification. Only works if data is perfectly linearly separable and is highly sensitive to outliers.
    - Soft Margin (Hinge Loss): Introduces a regularization parameter ($C$) and slack variables to allow a few misclassifications (errors). This yields a more robust, generalized boundary in the presence of noise or overlapping data.

SVM Kernel Trick

The Kernel Trick: Standard SVM only plots linear decision boundaries. When data is non-linearly separable, the "Kernel Trick" mathematically transforms the data into a higher-dimensional space where a linear hyperplane can separate the classes. It computes the dot products between data points in the expanded space efficiently, without explicitly materializing the higher-dimensional coordinates.

Types of Kernels:

  • Radial Basis Function (RBF) Kernel: The most popular kernel. It maps data into an infinite-dimensional space using exponential functions based on the distance between points (controlled by gamma $\gamma$). It can create highly localized, complex, island-like decision boundaries around clusters of data.

Bagging vs. Boosting Ensemble Methods

Ensemble methods combine multiple weak machine learning models to create a single, highly accurate strong model.

Bagging (Bootstrap Aggregating) & Random Forest:

  • Concept: Trains multiple models independently and in parallel on random subsets of the training data (drawn with replacement).
  • Aggregation: Predictions are aggregated via majority voting (classification) or averaging (regression).
  • Random Forest: Uses bagging specifically on Decision Trees. It also uses random subsets of features at each split. It dramatically reduces variance (overfitting).

Boosting (XGBoost, AdaBoost):

  • Concept: Trains multiple models sequentially. Each new model specifically focuses on correcting the errors (misclassified instances or residuals) made by the previous models.
  • AdaBoost: Adjusts weights of data points, penalizing incorrect classifications more in the next round.
  • Gradient Boosting (XGBoost): Fits subsequent trees directly to the residual errors of the previous sequence.
  • Result: Primarily reduces bias (underfitting) and creates highly accurate models, though it is more prone to overfitting than Bagging if not tuned carefully.

Q20. 20. Construct a standard Confusion Matrix. Write the mathematical formulas for Accuracy, Precision, Recall, and F1-Score, explaining why F1-Score is critical for class-imbalanced data.

Unit III CO3 | Bloom L4 5 Marks Score: 9.2
Confusion Matrix and Metrics

Confusion Matrix: A $2 \times 2$ table used to evaluate binary classification performance.

  • True Positive (TP): Predicted Positive, Actual Positive
  • True Negative (TN): Predicted Negative, Actual Negative
  • False Positive (FP - Type I Error): Predicted Positive, Actual Negative
  • False Negative (FN - Type II Error): Predicted Negative, Actual Positive

Evaluation Formulas:

  • Accuracy: $\frac{TP + TN}{TP + TN + FP + FN}$. The overall correct predictions.
  • Precision: $\frac{TP}{TP + FP}$. Out of all predicted positives, how many were actually positive?
  • Recall (Sensitivity): $\frac{TP}{TP + FN}$. Out of all actual positives, how many did the model find?
  • F1-Score: $2 \times \frac{Precision \times Recall}{Precision + Recall}$ (Harmonic Mean).

Importance of F1-Score for Imbalanced Data:
If a dataset has 99% Negative and 1% Positive instances, a model predicting "Negative" every time achieves 99% accuracy but fails its actual purpose. F1-Score completely ignores True Negatives, focusing strictly on the model\'s ability to correctly balance identifying the minority Positive class (Recall) without generating excessive false alarms (Precision).
