Q1. Differentiate between supervised, unsupervised, and reinforcement learning paradigms based on input data and learning targets.

Unit I CO1 | Bloom L2 2 Marks

Supervised learning uses labeled input and target data. Unsupervised learning discovers hidden patterns in unlabeled data. Reinforcement learning learns optimal actions to maximize rewards in an environment.

Q2. List any four key stages of the 7-Step Machine Learning Lifecycle.

Unit I CO1 | Bloom L1 2 Marks

Four key stages are: Data Collection, Data Preprocessing, Model Training, and Model Evaluation/Deployment.

Q3. What is Exploratory Data Analysis (EDA), and what is its primary objective during data preprocessing?

Unit I CO1 | Bloom L2 2 Marks

EDA involves analyzing datasets to summarize their main characteristics, often using statistical graphics. Its objective is to discover patterns, spot anomalies, and check assumptions before formal modeling.

Q4. Explain the significance of feature engineering in preparing raw datasets for model training.

Unit I CO1 | Bloom L2 2 Marks

Feature engineering transforms raw data into meaningful features that better represent the underlying problem to predictive models, thereby improving model accuracy on unseen data.

Q5. Why is categorical label encoding required before passing categorical features into a machine learning algorithm?

Unit I CO1 | Bloom L2 2 Marks Score: 9.5

Most machine learning algorithms require numerical inputs to perform mathematical computations. Categorical label encoding converts string/categorical variables into numerical values so models can process them.

Q6. Mention two common strategies for handling missing values during data cleaning.

Unit I CO1 | Bloom L1 2 Marks

Two common strategies are: 1) Removing rows/columns with missing data, and 2) Imputing missing values using the mean, median, or mode.

Q7. What is the role of data normalization and feature scaling in model fitting?

Unit I CO1 | Bloom L2 2 Marks

Normalization and feature scaling ensure that features with different scales contribute equally to model fitting and prevent features with larger ranges from dominating the objective function.

Q8. Define model fitting and state why model validation is necessary.

Unit I CO1 | Bloom L1 2 Marks

Model fitting is the process of adjusting a model's parameters to best align with training data. Model validation is necessary to ensure the model generalizes well to unseen data and isn't overfitted.

Q9. Distinguish between data collection/fetching strategies and feature selection.

Unit I CO1 | Bloom L2 2 Marks

Data collection involves gathering raw data from various sources, while feature selection involves choosing the most relevant subset of features from the collected data to build a model.

Q10. What is the historical significance of model training in the evolution of Machine Learning?

Unit I CO1 | Bloom L2 2 Marks Score: 8.5

Model training shifted the paradigm from explicitly programming rules to allowing algorithms to automatically infer patterns and rules from historical data.

Q11. Name two common visualization techniques used during EDA to inspect data distributions.

Unit I CO1 | Bloom L1 2 Marks

Two common techniques are Histograms (to view distributions of single variables) and Scatter Plots (to view relationships between two variables).

Q12. Explain the difference between independent variables (predictors) and dependent variables (targets).

Unit I CO1 | Bloom L2 2 Marks

Independent variables (predictors) are the inputs used to make predictions. The dependent variable (target) is the output or outcome being predicted by the model.

Q13. Why is Python widely chosen as a foundational language for machine learning data pipelines?

Unit I CO1 | Bloom L2 2 Marks

Python has a rich ecosystem of specialized libraries (like Scikit-Learn, Pandas, NumPy), an intuitive syntax, and extensive community support, making it highly efficient for building ML pipelines.

Q14. What constitutes a fundamental model validation workflow in the 7-step ML lifecycle?

Unit I CO1 | Bloom L2 2 Marks

It typically involves splitting data into training and testing sets, training the model on the train set, and evaluating its performance on the unseen test set using specific metrics.

Q15. Write the hypothesis function for a Simple Linear Regression model and define its components.

Unit II CO2 | Bloom L1 2 Marks Score: 9.3

The hypothesis function is h(x) = θ0 + θ1*x, where θ0 is the y-intercept, θ1 is the slope (weight), and x is the input feature.

Q16. State the equation for Multiple Linear Regression with n independent variables.

Unit II CO2 | Bloom L1 2 Marks

The equation is y = θ0 + θ1*x1 + θ2*x2 + ... + θn*xn, where θi are the coefficients and xi are the independent variables.

Q17. Define residual error ei in linear regression analysis.

Unit II CO2 | Bloom L1 2 Marks

Residual error ei is the difference between the actual observed value yi and the predicted value ŷi from the linear regression model: ei = yi - ŷi.

Q18. State the primary mathematical objective of the Ordinary Least Squares (OLS) method.

Unit II CO2 | Bloom L1 2 Marks

The primary objective of OLS is to find the line of best fit by minimizing the sum of the squared residual errors between the observed and predicted values.

Q19. Write the Mean Squared Error (MSE) cost function Jθ used in linear regression.

Unit II CO2 | Bloom L1 2 Marks

The MSE cost function is J(θ) = (1/2m) Σ (hθ(xi) - yi)², where m is the number of training examples.

Q20. Why is Gradient Descent preferred over the analytical Normal Equation for high-dimensional datasets?

Unit II CO2 | Bloom L2 2 Marks Score: 8.5

Gradient Descent is computationally much faster for high-dimensional datasets with many features, whereas the Normal Equation requires inverting an n x n matrix, which scales poorly as O(n³).

Q21. What is the learning rate α in Gradient Descent, and what happens if it is set too high?

Unit II CO2 | Bloom L2 2 Marks

The learning rate α determines the step size taken in the direction of the gradient. If it is set too high, Gradient Descent may overshoot the minimum and fail to converge or diverge entirely.

Q22. Define Polynomial Regression and explain how it captures non-linear data trends.

Unit II CO2 | Bloom L1 2 Marks

Polynomial Regression models the relationship between independent and dependent variables as an nth-degree polynomial, allowing the model curve to bend and capture non-linear trends in the data.

Q23. Is Polynomial Regression considered a linear or non-linear model? Explain briefly.

Unit II CO2 | Bloom L2 2 Marks

It is considered a linear model because, although the features are raised to a power (non-linear data transformations), the model is still linear with respect to its parameters (the coefficients).

Q24. Define Overfitting and list two common causes.

Unit II CO2 | Bloom L1 2 Marks

Overfitting occurs when a model learns the training data too well, including its noise, leading to poor generalization. Common causes include overly complex models and training on insufficient/noisy data.

Q25. Define Underfitting and mention how it can be identified.

Unit II CO2 | Bloom L1 2 Marks Score: 9.7

Underfitting occurs when a model is too simple to capture the underlying pattern of the data. It can be identified when the model shows poor performance (high error) on both the training and validation sets.

Q26. Explain the Bias-Variance tradeoff in the context of model complexity.

Unit II CO2 | Bloom L2 2 Marks

The Tradeoff implies that as model complexity increases, bias decreases but variance increases (causing overfitting). Lower complexity increases bias but decreases variance (causing underfitting). The goal is a balance minimizing total error.

Q27. State two techniques to reduce overfitting in regression models.

Unit II CO2 | Bloom L1 2 Marks

Two techniques are adding Regularization (L1/L2) to the cost function and reducing model complexity (e.g., feature selection or pruning).

Q28. What is Regularization, and why is it added to regression cost functions?

Unit II CO2 | Bloom L2 2 Marks

Regularization involves adding a penalty term to the cost function to constrain or shrink the model weights. It is added to prevent overfitting and improve generalization on new data.

Q29. Differentiate between Ridge L2 and Lasso L1 regularization penalties.

Unit II CO2 | Bloom L2 2 Marks

Ridge (L2) adds a penalty equal to the sum of the squared magnitude of coefficients. Lasso (L1) adds a penalty equal to the sum of the absolute values of the coefficients.

Q30. Why does Lasso L1 regularization perform automatic feature selection while Ridge L2 does not?

Unit II CO2 | Bloom L2 2 Marks Score: 9.3

Lasso (L1) tends to shrink less important feature coefficients exactly to zero, effectively performing feature selection. Ridge (L2) shrinks them near zero but rarely exactly to zero.

Q31. Write the mathematical formula for Mean Absolute Error (MAE).

Unit II CO2 | Bloom L1 2 Marks

The formula is MAE = (1/n) Σ |yi - ŷi|, where yi is actual, ŷi is predicted, and n is the number of samples.

Q32. State the formula for Root Mean Squared Error (RMSE) and explain its advantage over MSE.

Unit II CO2 | Bloom L1 2 Marks

RMSE = √((1/n) Σ (yi - ŷi)²). Its advantage is that it penalizes larger errors more heavily than MAE and shares the same units as the target variable.

Q33. What does the R2 (R-squared) coefficient measure, and what is its standard range?

Unit II CO2 | Bloom L2 2 Marks

R-squared measures the proportion of variance in the dependent variable explained by the independent variables. Its standard range is between 0 and 1.

Q34. Why is Adjusted R2 preferred over standard R2 in Multiple Linear Regression?

Unit II CO2 | Bloom L2 2 Marks

Standard R2 artificially increases when any new variable is added. Adjusted R2 penalizes the addition of non-significant predictors, giving a more accurate measure of fit for multiple predictors.

Q35. Write the Sigmoid activation function formula and state its output range.

Unit III CO3 | Bloom L1 2 Marks Score: 9.0

The Sigmoid formula is σ(z) = 1 / (1 + e^(-z)). Its output range is continuously between 0 and 1, making it ideal for probability estimation.

Q36. What is the standard threshold value used in Logistic Regression for binary classification?

Unit III CO3 | Bloom L2 2 Marks

The standard threshold value is 0.5. If the predicted probability is ≥ 0.5, the class is predicted as 1; if < 0.5, the class is predicted as 0.

Q37. Write the single-sample log-loss (binary cross-entropy) cost function formula.

Unit III CO3 | Bloom L1 2 Marks

The formula is Cost = - [y * log(ŷ) + (1 - y) * log(1 - ŷ)], where y is the true label (0 or 1) and ŷ is the predicted probability.

Q38. Define a decision boundary in a binary classification problem.

Unit III CO3 | Bloom L1 2 Marks

A decision boundary is a hyperplane or surface that separates the feature space into two distinct regions, classifying data points into one of the two binary classes.

Q39. Explain the core working mechanism of the K-Nearest Neighbors (KNN) algorithm.

Unit III CO3 | Bloom L2 2 Marks

KNN classifies a new data point based on the majority class among its 'K' closest neighbors in the feature space, calculated using a distance metric like Euclidean distance.

Q40. State the formula for Euclidean distance between two points in n-dimensional space.

Unit III CO3 | Bloom L1 2 Marks Score: 9.3

The formula is d(p, q) = √(Σ (qi - pi)²) from i=1 to n, where p and q are two points with n features.

Q41. What happens to KNN classification performance if K is set too small or too large?

Unit III CO3 | Bloom L2 2 Marks

If K is too small, the model becomes highly sensitive to noise (overfitting). If K is too large, the decision boundary becomes overly smooth, potentially missing local patterns (underfitting).

Q42. Define Entropy in Information Theory and write its mathematical equation.

Unit III CO3 | Bloom L1 2 Marks

Entropy measures the uncertainty or impurity in a dataset. Its equation is H(S) = - Σ p_i * log2(p_i), where p_i is the proportion of elements in class i.

Q43. Define Information Gain and explain its role in building Decision Trees.

Unit III CO3 | Bloom L1 2 Marks

Information Gain is the reduction in Entropy achieved by splitting a dataset on a specific attribute. Decision Trees use it to select the best feature to split on at each node (the one with the highest gain).

Q44. State the Gini Impurity formula used for evaluating node splits in Decision Trees.

Unit III CO3 | Bloom L1 2 Marks

The Gini Impurity formula is Gini = 1 - Σ (p_i)², where p_i is the probability of an item belonging to class i. It measures how often a randomly chosen element would be incorrectly labeled.

Q45. State Bayes' Theorem formula and label each term ((P(A|B), P(B| A), P(A), P(B)).

Unit III CO3 | Bloom L1 2 Marks Score: 8.6

P(A|B) = [P(B|A) * P(A)] / P(B). P(A|B) is posterior probability, P(B|A) is likelihood, P(A) is prior probability, and P(B) is the marginal probability of evidence.

Q46. Why is the Naive Bayes classifier termed "naive"?

Unit III CO3 | Bloom L2 2 Marks

It is called "naive" because it makes the strong, often unrealistic assumption that all features are conditionally independent of each other given the class label.

Q47. Define a Hyperplane and Support Vectors in Support Vector Machines (SVM).

Unit III CO3 | Bloom L1 2 Marks

A Hyperplane is the linear decision boundary that separates classes. Support Vectors are the data points located closest to the hyperplane, which directly influence its position and orientation.

Q48. Differentiate between Hard Margin SVM and Soft Margin SVM.

Unit III CO3 | Bloom L2 2 Marks

Hard Margin SVM strictly separates classes without allowing any misclassifications (sensitive to outliers). Soft Margin SVM introduces a slack variable to allow some misclassifications, improving generalization on noisy data.

Q49. Explain the purpose of Kernel functions (e.g., RBF, Polynomial) in SVM.

Unit III CO3 | Bloom L2 2 Marks

Kernel functions compute the dot product of data points in a transformed, higher-dimensional feature space, enabling SVM to find linear decision boundaries for complex, non-linearly separable data.

Q50. Describe the voting structure and ensemble approach used in Random Forests.

Unit III CO3 | Bloom L2 2 Marks Score: 9.0

Random Forests build multiple decision trees independently using bootstrapped data and random feature subsets. For classification, the final output is decided by a majority vote among all the individual trees.

Q51. Name three popular boosting ensemble algorithms covered in statistical classification.

Unit III CO3 | Bloom L1 2 Marks

Three popular boosting algorithms are AdaBoost (Adaptive Boosting), Gradient Boosting Machine (GBM), and XGBoost (Extreme Gradient Boosting).

Q52. Write the mathematical formulas for Precision, Recall, and F1-Score.

Unit III CO3 | Bloom L1 2 Marks

Precision = TP / (TP + FP), Recall = TP / (TP + FN), F1-Score = 2 * (Precision * Recall) / (Precision + Recall), where TP=True Positives, FP=False Positives, FN=False Negatives.

Q1. Explain the three main machine learning paradigms (Supervised, Unsupervised, and Reinforcement Learning) with their key characteristics and input data requirements.

Unit I CO1 | Bloom L2 3 Marks

Supervised Learning: Uses labeled training data to predict outcomes. Unsupervised Learning: Uses unlabeled data to find hidden patterns (e.g., clustering). Reinforcement Learning: Learns by interacting with an environment to maximize cumulative rewards.

Q2. Describe the first three sequential stages of the 7-Step Machine Learning Lifecycle in data pipeline design.

Unit I CO1 | Bloom L2 3 Marks

The first three stages are: 1) Data Collection: Gathering raw data from various sources. 2) Data Preparation/Cleaning: Handling missing values, outliers, and duplicates. 3) Exploratory Data Analysis (EDA): Analyzing data distributions and relationships using statistics and visualization.

Q3. Detail the importance of data cleaning principles and outline two strategies for handling missing values.

Unit I CO1 | Bloom L2 3 Marks

Data cleaning ensures high data quality, preventing poor model performance. Two strategies for missing values: 1) Imputation: Filling missing cells with the mean, median, or mode. 2) Deletion: Removing rows or columns that have excessive missing values.

Q4. Define Exploratory Data Analysis (EDA) and explain how data visualization techniques aid in discovering dataset distributions.

Unit I CO1 | Bloom L2 3 Marks

EDA is the process of visually and statistically summarizing the main characteristics of a dataset. Visualization techniques like histograms and box plots help reveal data distributions, skewness, and outliers intuitively.

Q5. Explain the role of Feature Engineering and distinguish it from feature selection.

Unit I CO1 | Bloom L2 3 Marks Score: 8.7

Feature Engineering: Creating new features or transforming existing ones to improve model performance. Feature Selection: Choosing a subset of the most relevant original features, discarding redundant or irrelevant ones to simplify the model.

Q6. Why is categorical label encoding necessary in machine learning data preprocessing prior to model fitting?

Unit I CO1 | Bloom L2 3 Marks

Machine learning algorithms perform mathematical computations and require numerical input. Categorical label encoding (like One-Hot Encoding or Label Encoding) transforms string/text labels into numerical representations so algorithms can process them.

Q7. Differentiate between feature normalization and feature scaling, stating why they are applied before model fitting.

Unit I CO1 | Bloom L2 3 Marks

Feature Scaling: Adjusting feature values to a standard range (e.g., Min-Max scaling to [0,1]). Feature Normalization: Adjusting the distribution to have a mean of 0 and standard deviation of 1 (Z-score normalization). Both ensure no single feature dominates the objective function due to scale.

Q8. Explain the concept and significance of model training within the overall machine learning lifecycle.

Unit I CO1 | Bloom L2 3 Marks

Model training is the core phase where an algorithm learns patterns from the provided dataset by optimizing its parameters (e.g., weights in regression) to minimize the error or loss function, establishing the mapping from inputs to outputs.

Q9. Describe fundamental validation strategies used to evaluate the performance of a trained machine learning model.

Unit I CO1 | Bloom L2 3 Marks

Validation strategies include: 1) Train-Test Split: Partitioning data into a training set and a testing set. 2) K-Fold Cross Validation: Dividing data into K folds, training on K-1 folds and testing on the remaining fold iteratively to ensure robust evaluation.

Q10. Differentiate between independent predictor variables and dependent target variables using a concrete example.

Unit I CO1 | Bloom L2 3 Marks Score: 9.3

Independent Predictor Variables: The inputs or features used to make predictions (e.g., house size, location). Dependent Target Variables: The output or outcome being predicted by the model (e.g., house price).

Q11. Explain how raw data collection and fetching strategies impact the downstream efficiency of an ML pipeline.

Unit I CO1 | Bloom L2 3 Marks

Efficient data collection directly affects the quality and quantity of data available. High-quality, representative data fetched seamlessly reduces preprocessing overhead and improves the final model's predictive accuracy and reliability.

Q12. Outline the historical evolution and structural taxonomy of machine learning paradigms.

Unit I CO1 | Bloom L2 3 Marks

Machine learning evolved from early logical rules to statistical learning, and now deep neural networks. Its structural taxonomy primarily divides into Supervised, Unsupervised, Semi-supervised, and Reinforcement Learning, based on the availability of labeled feedback.

Q13. Explain how computing statistical summaries on raw data helps in initial data understanding during EDA.

Unit I CO1 | Bloom L2 3 Marks

Statistical summaries (mean, median, standard deviation, quartiles) provide a quick numerical overview of the dataset's central tendency and dispersion, highlighting potential anomalies, outliers, and scaling requirements before visual analysis.

Q14. Why can raw unstructured/uncleaned datasets not be directly fed into standard machine learning algorithms?

Unit I CO1 | Bloom L2 3 Marks

Standard ML algorithms require numerical, well-structured, tabular data without missing values or infinite entries. Raw data often contains text, noise, inconsistencies, and missing fields, causing algorithms to fail or produce garbage outputs.

Q15. Write the structural mathematical formulation for a Simple Linear Regression model and explain all its terms.

Unit II CO2 | Bloom L3 3 Marks Score: 8.8

Formula: y = β0 + β1x + ε. y: Dependent target variable. x: Independent predictor variable. β0: Y-intercept (value of y when x=0). β1: Slope coefficient (change in y for a 1-unit change in x). ε: Error term.

Q16. Explain Multiple Linear Regression and state its algebraic equation for n independent variables.

Unit II CO2 | Bloom L3 3 Marks

Multiple Linear Regression extends simple regression to model the relationship between one continuous dependent variable and multiple independent variables. Equation: y = β0 + β1x1 + β2x2 + ... + βnxn + ε.

Q17. Define residual error in linear regression and explain its geometric interpretation.

Unit II CO2 | Bloom L2 3 Marks

A residual error is the difference between the actual observed value and the predicted value (e = y - ŷ). Geometrically, it represents the vertical distance from a data point to the fitted regression line.

Q18. Explain the Ordinary Least Squares (OLS) estimation method and state the objective function it minimizes.

Unit II CO2 | Bloom L2 3 Marks

Ordinary Least Squares (OLS) is a method that estimates regression coefficients by minimizing the sum of the squared residuals. Objective function: Minimize Σ(yi - ŷi)².

Q19. Describe the role of the Mean Squared Error (MSE) cost function J(θ) in optimizing regression parameters.

Unit II CO2 | Bloom L2 3 Marks

MSE averages the squared differences between predicted and actual values. In optimizing regression parameters, the MSE serves as the cost function J(θ); the algorithm (like Gradient Descent) minimizes J(θ) to find the best-fitting weights.

Q20. Explain how Gradient Descent updates parameters iteratively to find the optimal slope and intercept.

Unit II CO2 | Bloom L2 3 Marks Score: 9.7

Gradient Descent calculates the partial derivatives (gradient) of the cost function with respect to the slope and intercept. It then updates these parameters iteratively in the opposite direction of the gradient by a step size (learning rate) to reach the minimum cost.

Q21. Define the learning rate (α) in Gradient Descent and explain the consequences of setting it too high or too low.

Unit II CO2 | Bloom L2 3 Marks

The learning rate (α) determines the step size at each iteration. If α is too high, the algorithm may overshoot the minimum and diverge. If α is too low, convergence will be exceedingly slow and might get stuck in local minima.

Q22. Explain Polynomial Regression and state how higher-degree terms allow it to capture non-linear data trends.

Unit II CO2 | Bloom L3 3 Marks

Polynomial regression models the relationship as an nth degree polynomial (e.g., y = β0 + β1x + β2x²). The higher-degree terms introduce curves, allowing the model to fit non-linear patterns in the data.

Q23. Discuss why Polynomial Regression is technically classified as a linear model despite fitting non-linear curves.

Unit II CO2 | Bloom L3 3 Marks

It is technically a linear model because the regression equation is linear in its parameters (the coefficients β). The relationship between the parameters and the dependent variable remains linear, even though the features (x², x³) are non-linear.

Q24. Explain Overfitting in regression models and state two practical techniques to detect and prevent it.

Unit II CO2 | Bloom L2 3 Marks

Overfitting occurs when a model learns the training data and its noise too well, performing poorly on unseen data. Detection: High training accuracy, low validation accuracy. Prevention: 1) Cross-validation. 2) Regularization (L1/L2).

Q25. Explain Underfitting, its primary root causes, and how its error profile differs from overfitting.

Unit II CO2 | Bloom L2 3 Marks Score: 9.7

Underfitting happens when a model is too simple to capture the underlying patterns in the data (high bias). Root causes: Insufficient model complexity or inadequate features. Error profile: High training error and high validation error.

Q26. Describe the Bias-Variance tradeoff and how model complexity influences bias and variance.

Unit II CO2 | Bloom L2 3 Marks

Bias is error from erroneous assumptions (underfitting); variance is error from sensitivity to small fluctuations in training data (overfitting). Increasing model complexity typically decreases bias but increases variance. The tradeoff seeks the optimal balance.

Q27. Explain the principle of Regularization and why penalty terms are added to the regression loss function.

Unit II CO2 | Bloom L2 3 Marks

Regularization prevents overfitting by adding a penalty term to the loss function based on the magnitude of the model's coefficients. This discourages overly complex models with extremely large weights.

Q28. Compare Ridge L2 and Lasso L1 regression with respect to their mathematical penalty terms and impact on weights.

Unit II CO2 | Bloom L3 3 Marks

Ridge (L2): Adds a penalty proportional to the sum of squared weights (λΣw²). It shrinks weights but rarely to zero. Lasso (L1): Adds a penalty proportional to the sum of absolute weights (λΣ|w|). It can force some weights exactly to zero.

Q29. Explain why Lasso L1 regularization performs automatic feature selection whereas Ridge L2 shrinks coefficients without zeroing them.

Unit II CO2 | Bloom L3 3 Marks

Lasso's L1 penalty has a diamond-shaped constraint region, and the loss function's elliptical contours often intersect it at the corners where some coefficients are exactly zero, performing feature selection. Ridge's circular constraint region usually intersects without zeroing coefficients.

Q30. Write the mathematical formulas for Mean Absolute Error (MAE) and Mean Squared Error (MSE) and highlight their differences.

Unit II CO2 | Bloom L3 3 Marks Score: 8.8

MAE: (1/n) Σ|yi - ŷi|. MSE: (1/n) Σ(yi - ŷi)². Differences: MSE heavily penalizes large errors because of the squaring operation, whereas MAE treats all errors proportionally and is more robust to outliers.

Q31. Define Root Mean Squared Error (RMSE) and explain its interpretive advantage over Mean Squared Error (MSE).

Unit II CO2 | Bloom L2 3 Marks

RMSE: √((1/n) Σ(yi - ŷi)²). The interpretive advantage of RMSE is that it expresses the error in the exact same units as the original dependent target variable, making it easier to understand practically than MSE.

Q6. 6. Derive the Ordinary Least Squares (OLS) error minimization framework for Simple Linear Regression and state its objective function.

Unit II CO2 | Bloom L3 5 Marks Score: 9.1
Ordinary Least Squares (OLS)

Simple Linear Regression models the relationship between a dependent variable $y$ and an independent variable $x$ as: $\hat{y} = mx + c$, where $m$ is the slope and $c$ is the intercept.

Objective Function: The OLS method aims to minimize the Sum of Squared Residuals (SSR) between actual and predicted values. The cost function $J$ is:
$J(m, c) = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 = \sum_{i=1}^{n} (y_i - (mx_i + c))^2$

Derivation Framework:

  • To find the optimal $m$ and $c$, we take the partial derivatives of $J$ with respect to $m$ and $c$, and set them to zero.
  • $\frac{\partial J}{\partial c} = -2 \sum_{i=1}^{n} (y_i - mx_i - c) = 0 \implies \sum y_i = m\sum x_i + nc$
  • $\frac{\partial J}{\partial m} = -2 \sum_{i=1}^{n} x_i(y_i - mx_i - c) = 0 \implies \sum x_i y_i = m\sum x_i^2 + c\sum x_i$
  • Solving these two normal equations yields the optimal formulas for slope $m$ and intercept $c$, which represent the best-fit line minimizing the squared errors.

Q7. 7. Explain how the Gradient Descent optimization algorithm updates model weights iteratively. Contrast its performance against the analytical Normal Equation on high-dimensional datasets.

Unit II CO2 | Bloom L4 5 Marks Score: 9.1
Gradient Descent vs Normal Equation

Gradient Descent (GD):

GD is an iterative optimization algorithm used to minimize a cost function $J(\theta)$. It updates model weights (parameters) by moving in the direction opposite to the gradient of the cost function with respect to the weights.

  • Update Rule: $\theta_j = \theta_j - \alpha \frac{\partial J(\theta)}{\partial \theta_j}$, where $\alpha$ is the learning rate.
  • It iteratively takes steps proportional to the negative gradient until it converges to a local or global minimum.

Contrast with Normal Equation:

  • The Normal Equation provides an analytical, closed-form solution to linear regression: $\theta = (X^T X)^{-1} X^T y$.
  • High-Dimensional Datasets: The Normal Equation requires computing the inverse of an $(n \times n)$ matrix ($X^T X$), which has a time complexity of $O(n^3)$. For large number of features (e.g., $n > 10,000$), matrix inversion becomes computationally prohibitive.
  • Gradient Descent scales much better with large numbers of features ($O(n^2)$ per iteration) and is highly preferred for high-dimensional datasets and models where analytical solutions do not exist.

Regularization adds a penalty term to the cost function to prevent overfitting by penalizing large model weights.

Q13. 13. Write the Log-Loss (Binary Cross-Entropy) cost function for Logistic Regression. Explain why standard MSE is non-convex and unsuitable for classification tasks.

Log-Loss (Binary Cross-Entropy)

The cost function for Logistic Regression is Log-Loss, also known as Binary Cross-Entropy.

Formula:

$J(\theta) = -\frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log(h_\theta(x^{(i)})) + (1 - y^{(i)}) \log(1 - h_\theta(x^{(i)})) \right]$

Where $h_\theta(x)$ is the sigmoid predicted probability and $y$ is the actual binary label (0 or 1).

Why MSE is Unsuitable:

  • If we use standard Mean Squared Error (MSE) for Logistic Regression, the cost function becomes $J(\theta) = \frac{1}{2m} \sum (\sigma(W^TX) - y)^2$.
  • Because the sigmoid function $\sigma$ is non-linear, squaring it results in a non-convex cost function landscape with multiple local minima.
  • Gradient Descent is prone to getting stuck in these local minima, failing to find the global optimum.
  • Log-Loss, conversely, guarantees a convex cost function with a single global minimum, penalizing confident wrong predictions heavily using logarithms.

Q16. 16. Explain the mathematical foundation of the Naive Bayes Classifier using Bayes\' Theorem. List all key assumptions made by the model regarding feature independence.

Naive Bayes Classifier

The Naive Bayes classifier is a probabilistic machine learning model based on Bayes\' Theorem, widely used for text classification tasks like spam filtering.

Mathematical Foundation:

  • Bayes\' Theorem states: $P(y|X) = \frac{P(X|y) \cdot P(y)}{P(X)}$
  • Where $P(y|X)$ is the posterior probability of class $y$ given features $X$.
  • $P(X|y)$ is the likelihood, and $P(y)$ is the prior probability of class $y$.

Key Assumptions (The "Naive" Aspect):

  • The core assumption is Conditional Independence of features. It assumes that the presence or absence of a particular feature (e.g., word A) is entirely independent of the presence of any other feature (e.g., word B), given the class variable.
  • Mathematically, the likelihood is decomposed as: $P(X|y) = P(x_1|y) \times P(x_2|y) \times \dots \times P(x_n|y)$.
  • Despite this assumption almost never holding perfectly true in real-world data (words in sentences are usually correlated), Naive Bayes often performs surprisingly well in practice.

Support Vector Machines (SVM)

SVM is a powerful algorithm that finds an optimal boundary between classes in an $N$-dimensional space.

  • Hyperplane: The decision boundary separating different classes. In 2D space, it\'s a line; in 3D, a flat plane.
  • Support Vectors: The specific data points lying closest to the hyperplane. They act as pillars; if they are moved or removed, the position of the dividing hyperplane alters. The algorithm only cares about these vectors.
  • Maximum Margin: SVM aims to find the hyperplane that maximizes the margin, which is the orthogonal distance between the hyperplane and the closest support vectors of each class. A wider margin implies better generalization.

SVM Kernel Trick

The Kernel Trick: Standard SVM only plots linear decision boundaries. When data is non-linearly separable, the "Kernel Trick" mathematically transforms the data into a higher-dimensional space where a linear hyperplane can separate the classes. It computes the dot products between data points in the expanded space efficiently, without explicitly materializing the higher-dimensional coordinates.

Bagging vs. Boosting Ensemble Methods

Ensemble methods combine multiple weak machine learning models to create a single, highly accurate strong model.

Bagging (Bootstrap Aggregating) & Random Forest:

  • Concept: Trains multiple models independently and in parallel on random subsets of the training data (drawn with replacement).
  • Aggregation: Predictions are aggregated via majority voting (classification) or averaging (regression).

Q20. 20. Construct a standard Confusion Matrix. Write the mathematical formulas for Accuracy, Precision, Recall, and F1-Score, explaining why F1-Score is critical for class-imbalanced data.

Unit III CO3 | Bloom L4 5 Marks Score: 9.2
Confusion Matrix and Metrics

Confusion Matrix: A $2 \times 2$ table used to evaluate binary classification performance.

  • True Positive (TP): Predicted Positive, Actual Positive
  • True Negative (TN): Predicted Negative, Actual Negative
  • False Positive (FP - Type I Error): Predicted Positive, Actual Negative
  • False Negative (FN - Type II Error): Predicted Negative, Actual Positive

Evaluation Formulas:

  • Accuracy: $\frac{TP + TN}{TP + TN + FP + FN}$. The overall correct predictions.
  • Precision: $\frac{TP}{TP + FP}$. Out of all predicted positives, how many were actually positive?
  • Recall (Sensitivity): $\frac{TP}{TP + FN}$. Out of all actual positives, how many did the model find?
  • F1-Score: $2 \times \frac{Precision \times Recall}{Precision + Recall}$ (Harmonic Mean).

Importance of F1-Score for Imbalanced Data:
If a dataset has 99% Negative and 1% Positive instances, a model predicting "Negative" every time achieves 99% accuracy but fails its actual purpose. F1-Score completely ignores True Negatives, focusing strictly on the model\'s ability to correctly balance identifying the minority Positive class (Recall) without generating excessive false alarms (Precision).
