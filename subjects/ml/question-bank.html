Q15. Write the hypothesis function for a Simple Linear Regression model and define its components.

Unit II CO2 | Bloom L1 2 Marks Score: 9.3

The hypothesis function in Simple Linear Regression is a linear mathematical equation used to predict a continuous target variable from a single input feature. It is expressed as hθ(x) = θ0 + θ1x, where hθ(x) is the predicted value, θ0 is the y-intercept, θ1 is the slope parameter, and x is the independent input variable.

Q16. State the equation for Multiple Linear Regression with n independent variables.

Unit II CO2 | Bloom L1 2 Marks

Multiple Linear Regression is a statistical modeling technique that predicts a continuous dependent variable using multiple independent features. Its equation with n independent variables is y = θ0 + θ1x1 + θ2x2 + ... + θnxn, where θ0 is the bias term, θ1, ..., θn are the model coefficients, and x1, ..., xn are the input features.

Q17. Define residual error ei in linear regression analysis.

Unit II CO2 | Bloom L1 2 Marks

Residual error ei is the difference between the actual observed value and the value predicted by a regression model for a specific data point. It is defined mathematically as ei = yi - ŷi, where yi is the actual target value and ŷi is the predicted value.

Q18. State the primary mathematical objective of the Ordinary Least Squares (OLS) method.

Unit II CO2 | Bloom L1 2 Marks

Ordinary Least Squares (OLS) is an analytical optimization method used to determine the best-fitting line in linear regression. Its primary mathematical objective is to minimize the sum of squared differences (residual errors) between the actual observed values and the predicted values across all training samples.

Q19. Write the Mean Squared Error (MSE) cost function Jθ used in linear regression.

Unit II CO2 | Bloom L1 2 Marks

The Mean Squared Error (MSE) cost function, denoted as J(θ), is a mathematical objective function that measures the average squared difference between predictions and actual values in linear regression. It is defined as J(θ) = (1/2m) Σi=1m (hθ(x(i)) - y(i))2, where m is the number of training samples, hθ(x(i)) is the predicted value, and y(i) is the actual target.

Q20. Why is Gradient Descent preferred over the analytical Normal Equation for high-dimensional datasets?

Unit II CO2 | Bloom L2 2 Marks

Gradient Descent is an iterative optimization algorithm used to minimize a cost function by updating model parameters in the direction of steepest descent. It is preferred over the analytical Normal Equation for high-dimensional datasets because the Normal Equation requires inverting an n × n matrix with an expensive computational complexity of O(n3), whereas Gradient Descent scales efficiently to large numbers of features.

Q21. What is the learning rate α in Gradient Descent, and what happens if it is set too high?

Unit II CO2 | Bloom L2 2 Marks

The learning rate α is a hyperparameter in Gradient Descent that determines the step size taken towards the minimum of the cost function during each update. If it is set too high, the algorithm can overshoot the minimum, resulting in oscillations or complete divergence of the cost function.

Q22. Define Polynomial Regression and explain how it captures non-linear data trends.

Unit II CO2 | Bloom L1 2 Marks

Polynomial Regression is a regression technique that models the relationship between independent and dependent variables as an n-th degree polynomial. It captures non-linear data trends by transforming the original features into higher-degree powers (such as x2 or x3), allowing the fitted curve to adapt to curved patterns in the data.

Q23. Is Polynomial Regression considered a linear or non-linear model? Explain briefly.

Unit II CO2 | Bloom L2 2 Marks

Polynomial Regression is a regression technique that models non-linear relationships using polynomial terms of the input features. It is considered a linear model because the equation remains linear with respect to its unknown parameters and coefficients, even though the input features undergo non-linear transformations.

Q24. Define Overfitting and list two common causes.

Unit II CO2 | Bloom L1 2 Marks

Overfitting is a modeling error that occurs when a machine learning model learns the training data and noise too closely, failing to generalize to unseen test data. Two common causes of overfitting are excessive model complexity with too many parameters and training on a dataset that is too small or noisy.

Q25. Define Underfitting and mention how it can be identified.

Unit II CO2 | Bloom L1 2 Marks Score: 9.7

Underfitting is a condition where a machine learning model is too simple to capture the underlying patterns and relationships in the data. It can be identified when the model exhibits high training error as well as high validation or test error.

Q26. Explain the Bias-Variance tradeoff in the context of model complexity.

Unit II CO2 | Bloom L2 2 Marks

The Bias-Variance tradeoff is the balance between a model's error from erroneous assumptions (bias) and its sensitivity to small fluctuations in training data (variance). As model complexity increases, bias decreases while variance increases, raising the risk of overfitting. The objective is to choose an optimal model complexity that minimizes total error.

Q27. State two techniques to reduce overfitting in regression models.

Unit II CO2 | Bloom L1 2 Marks

Overfitting reduction techniques are methods applied during model training to improve generalization on unseen data. Two effective techniques to reduce overfitting in regression models are applying regularization (such as Ridge or Lasso) to penalize large weights and performing feature selection to remove irrelevant or redundant variables.

Q28. What is Regularization, and why is it added to regression cost functions?

Unit II CO2 | Bloom L2 2 Marks

Regularization is a technique used to prevent overfitting by adding a penalty term for model complexity to the cost function. It is added to regression cost functions to constrain the magnitude of model coefficients towards zero, which reduces model variance and improves generalization on unseen data.

Q29. Differentiate between Ridge L2 and Lasso L1 regularization penalties.

Unit II CO2 | Bloom L2 2 Marks

Ridge (L2) and Lasso (L1) regularization are techniques used to prevent overfitting by penalizing large model coefficients. Ridge regularization adds a penalty equal to the sum of squared coefficients to shrink weights close to zero, whereas Lasso regularization adds a penalty equal to the sum of absolute values of coefficients, which can shrink weights exactly to zero.

Q30. Why does Lasso L1 regularization perform automatic feature selection while Ridge L2 does not?

Unit II CO2 | Bloom L2 2 Marks Score: 9.3

Lasso (L1) and Ridge (L2) regularization are methods used to constrain model parameters and prevent overfitting in regression. Lasso performs automatic feature selection because its L1 absolute penalty forces coefficients of less important features exactly to zero, effectively eliminating them. In contrast, Ridge's L2 squared penalty shrinks coefficients toward zero without setting them strictly to zero, retaining all features in the model.

Q31. Write the mathematical formula for Mean Absolute Error (MAE).

Unit II CO2 | Bloom L1 2 Marks

Mean Absolute Error (MAE) is a regression evaluation metric that measures the average magnitude of errors between predicted and actual values without considering direction. Its mathematical formula is MAE = (1/n) Σi=1n |yi - ŷi|, where n is the total number of samples, yi is the actual observed value, and ŷi is the model prediction.

Q32. State the formula for Root Mean Squared Error (RMSE) and explain its advantage over MSE.

Unit II CO2 | Bloom L1 2 Marks

Root Mean Squared Error (RMSE) is a standard regression metric that measures the average magnitude of prediction errors by calculating the square root of the mean squared differences between predicted and actual values. Its mathematical formula is RMSE = √((1/n) Σ (y_i - ŷ_i)²). The primary advantage of RMSE over MSE is that it expresses the error in the exact same units as the target variable, making the error magnitude much easier to interpret.

Q33. What does the R2 (R-squared) coefficient measure, and what is its standard range?

Unit II CO2 | Bloom L2 2 Marks

The R-squared (R²) coefficient is a statistical metric that measures the proportion of variance in the dependent variable that is predictable from the independent variables in a regression model. Its standard range lies between 0 and 1 (or 0% to 100%), where 0 indicates that the model explains none of the variance and 1 indicates that it explains all of the variance.

Q34. Why is Adjusted R2 preferred over standard R2 in Multiple Linear Regression?

Unit II CO2 | Bloom L2 2 Marks

Adjusted R-squared is a modified version of the R-squared metric that accounts for the total number of predictor variables included in a multiple linear regression model. Standard R-squared increases automatically whenever any new feature is added, even if that feature adds no predictive value. Adjusted R-squared is preferred because it penalizes the addition of non-informative variables, increasing only when a new predictor genuinely improves model performance.

Q35. Write the Sigmoid activation function formula and state its output range.

Unit III CO3 | Bloom L1 2 Marks Score: 9.0

The Sigmoid function is an S-shaped activation function used in machine learning to map any real-valued number into a continuous probability value. Its mathematical formula is σ(z) = 1 / (1 + e^(-z)). The standard output range of the Sigmoid function is strictly between 0 and 1, making it ideal for binary classification tasks.

Q36. What is the standard threshold value used in Logistic Regression for binary classification?

Unit III CO3 | Bloom L2 2 Marks

The decision threshold in Logistic Regression is a cutoff probability used to convert continuous probability predictions into discrete binary class labels. The standard threshold value used for binary classification is 0.5. If the predicted probability is greater than or equal to 0.5, the sample is assigned to class 1; otherwise, it is assigned to class 0.

Q37. Write the single-sample log-loss (binary cross-entropy) cost function formula.

Unit III CO3 | Bloom L1 2 Marks

Log-loss, or binary cross-entropy, is a cost function used in binary classification to quantify the penalty for incorrect probability predictions. The single-sample mathematical formula is Cost = -[y * log(ŷ) + (1 - y) * log(1 - ŷ)]. In this equation, y represents the true binary label (0 or 1), and ŷ represents the model's predicted probability of belonging to class 1.

Q38. Define a decision boundary in a binary classification problem.

Unit III CO3 | Bloom L1 2 Marks

A decision boundary in binary classification is a geometric surface that partitions the feature space into two distinct regions corresponding to each class. Any data point falling on one side of this boundary is assigned to class 0, while points on the other side are assigned to class 1. This boundary can be linear, such as a hyperplane in Logistic Regression, or non-linear, as seen in Decision Trees.

Q39. Explain the core working mechanism of the K-Nearest Neighbors (KNN) algorithm.

Unit III CO3 | Bloom L2 2 Marks

K-Nearest Neighbors (KNN) is a non-parametric, instance-based learning algorithm that classifies new data points based on their similarity to known training samples. When given an unseen data point, the algorithm computes its distance to all training instances and identifies the K closest neighbors. It then assigns the new point the majority class label among those K nearest neighbors by democratic vote.

Q40. State the formula for Euclidean distance between two points in n-dimensional space.

Unit III CO3 | Bloom L1 2 Marks Score: 9.3

Euclidean distance is a standard geometric metric that measures the straight-line distance between two points in an n-dimensional feature space. Its mathematical formula between points p and q is d(p, q) = √(Σ (q_i - p_i)²) summed from i = 1 to n. Here, p_i and q_i represent the coordinate values of each point along dimension i.

Q41. What happens to KNN classification performance if K is set too small or too large?

Unit III CO3 | Bloom L2 2 Marks

The hyperparameter K in KNN specifies the number of nearest data points used to determine the class label of a new sample. Setting K too small makes the classifier overly sensitive to noise and outliers, causing high variance and overfitting. Conversely, setting K too large includes data points from unrelated classes, leading to an over-smoothed boundary, high bias, and underfitting.

Q42. Define Entropy in Information Theory and write its mathematical equation.

Unit III CO3 | Bloom L1 2 Marks

Entropy is an Information Theory metric that measures the degree of impurity, disorder, or uncertainty within a dataset. Its mathematical formula is H(S) = - Σ (p_i * log2(p_i)) for all classes i in subset S. In this equation, p_i is the proportion of samples belonging to class i, where an entropy value of 0 indicates complete purity.

Q43. Define Information Gain and explain its role in building Decision Trees.

Unit III CO3 | Bloom L1 2 Marks

Information Gain is a metric that measures the expected reduction in entropy achieved by partitioning a dataset on a specific attribute. In building Decision Trees, it serves as the splitting criterion used to select the best feature at each internal node. The algorithm evaluates all candidate features and selects the one with the highest Information Gain to maximize node purity.

Q44. State the Gini Impurity formula used for evaluating node splits in Decision Trees.

Unit III CO3 | Bloom L1 2 Marks

Gini Impurity is a metric used in Decision Tree algorithms to measure the probability of misclassifying a randomly chosen element from a dataset. Its mathematical formula is Gini = 1 - Σ (p_i)², where p_i is the proportion of elements belonging to class i at that node. A Gini Impurity of 0 denotes perfect purity, meaning all instances belong to a single class.

Q45. State Bayes' Theorem formula and label each term ((P(A|B), P(B| A), P(A), P(B)).

Unit III CO3 | Bloom L1 2 Marks

Bayes' Theorem is a probability law used in machine learning to calculate the conditional probability of an event given prior evidence. Its mathematical formula is P(A|B) = [P(B|A) * P(A)] / P(B). In this equation, P(A|B) is the posterior probability, P(B|A) is the likelihood, P(A) is the prior probability of class A, and P(B) is the marginal probability of predictor B.

Q46. Why is the Naive Bayes classifier termed "naive"?

Unit III CO3 | Bloom L2 2 Marks

The Naive Bayes classifier is a probabilistic machine learning model based on Bayes' Theorem used for classification tasks. It is termed "naive" because it makes the strict assumption that all input features are conditionally independent of each other given the class label. Although feature independence is rarely true in real-world data, this assumption simplifies computation while still delivering high classification accuracy.

Q47. Define a Hyperplane and Support Vectors in Support Vector Machines (SVM).

Unit III CO3 | Bloom L1 2 Marks

In Support Vector Machines (SVM), a hyperplane is a linear decision boundary that separates data points of different classes in an n-dimensional space. Support vectors are the critical data points located closest to the hyperplane that determine the margin width. These support vectors uniquely define the position and orientation of the optimal separating hyperplane.

Q48. Differentiate between Hard Margin SVM and Soft Margin SVM.

Unit III CO3 | Bloom L2 2 Marks

Margin classification in Support Vector Machines defines the separation boundary used between distinct classes. Hard Margin SVM strictly prohibits misclassifications or margin violations, requiring the training data to be perfectly linearly separable and making it prone to overfitting. In contrast, Soft Margin SVM allows a controlled degree of misclassification using slack variables, improving robustness and generalization on overlapping data.

Q49. Explain the purpose of Kernel functions (e.g., RBF, Polynomial) in SVM.

Unit III CO3 | Bloom L2 2 Marks

A Kernel function in Support Vector Machines is a mathematical function that computes the inner product of data points in a higher-dimensional space without explicitly computing their coordinates. Its purpose is to enable linear classifiers to solve non-linear classification problems by implicitly mapping non-linearly separable inputs into a space where they become linearly separable. Common examples include the Radial Basis Function (RBF) and Polynomial kernels, which provide high computational efficiency through this kernel trick.

Q50. Describe the voting structure and ensemble approach used in Random Forests.

Unit III CO3 | Bloom L2 2 Marks Score: 9.0

Random Forest is an ensemble learning algorithm that combines predictions from multiple decision trees to improve accuracy and reduce overfitting. Each tree is constructed independently using a bootstrap sample of the training data and a random subset of features at each split. For classification tasks, the ensemble determines the final predicted class through a majority vote among all individual trees.

Q51. Name three popular boosting ensemble algorithms covered in statistical classification.

Unit III CO3 | Bloom L1 2 Marks

Boosting is an ensemble machine learning technique that trains weak learners sequentially, with each subsequent model focusing on the errors of the previous ones. Three popular boosting ensemble algorithms covered in statistical classification are AdaBoost (Adaptive Boosting), Gradient Boosting Machine (GBM), and XGBoost (Extreme Gradient Boosting).

Q52. Write the mathematical formulas for Precision, Recall, and F1-Score.

Unit III CO3 | Bloom L1 2 Marks

Precision, Recall, and F1-Score are classification performance metrics used to evaluate the accuracy of positive predictions. The formulas are Precision = TP / (TP + FP), which measures exactness, and Recall = TP / (TP + FN), which measures completeness. The F1-Score is their harmonic mean, defined by the formula F1-Score = 2 * (Precision * Recall) / (Precision + Recall).

Q1. Explain the three main machine learning paradigms (Supervised, Unsupervised, and Reinforcement Learning) with their key characteristics and input data requirements.

Unit I CO1 | Bloom L2 3 Marks

Machine learning paradigms are the foundational learning frameworks classified by the nature of training data and the type of feedback the algorithm receives.

  • Supervised Learning: Operates on fully labeled datasets where each input feature vector is paired with a known target label (x, y). The model learns a mathematical mapping function from inputs to outputs to predict target values on unseen data (e.g., classification and regression).
  • Unsupervised Learning: Operates on unlabeled datasets that contain only input features without any target labels or desired outputs. The model autonomously discovers intrinsic patterns, data clusters, or latent structures directly from the feature space (e.g., K-Means clustering and Principal Component Analysis).
  • Reinforcement Learning: Operates on sequential environmental states and dynamic feedback signals rather than static datasets. An autonomous agent interacts with an environment by executing actions, receiving numerical rewards or penalties, and optimizing a policy to maximize its cumulative long-term reward.

Q2. Describe the first three sequential stages of the 7-Step Machine Learning Lifecycle in data pipeline design.

Unit I CO1 | Bloom L2 3 Marks

The 7-Step Machine Learning Lifecycle is a systematic engineering workflow that structures the development, deployment, and monitoring of machine learning models.

  • 1. Data Collection: The initial stage where raw data is gathered from primary and secondary sources—such as relational databases, web APIs, system logs, or external datasets—to build the foundational data asset needed to solve the problem.
  • 2. Data Preparation and Cleaning: The stage focused on transforming raw data into high-quality inputs by handling missing values through imputation or removal, eliminating duplicate records, correcting formatting errors, and filtering out extreme noise or anomalies.
  • 3. Exploratory Data Analysis (EDA): The diagnostic stage where descriptive statistics and visualization tools (such as histograms, box plots, and correlation matrices) are used to analyze feature distributions, evaluate relationships between variables, and verify modeling assumptions.

Q3. Detail the importance of data cleaning principles and outline two strategies for handling missing values.

Unit I CO1 | Bloom L2 3 Marks

Data cleaning is the preprocessing practice of detecting and correcting corrupt, inaccurate, incomplete, or duplicate records in raw data to ensure data quality.

  • Importance of Data Cleaning: Machine learning models depend entirely on input data quality; noisy, corrupted, or inconsistent values mislead mathematical optimization, generate false patterns, and cause poor generalization on unseen data.
  • Strategy 1: Statistical Imputation: Missing data points are replaced with estimated values calculated from the available data, such as replacing missing numerical values with the column mean or median, and categorical values with the mode. This strategy preserves the total sample size.
  • Strategy 2: Deletion (Listwise / Column Deletion): Incomplete rows or entire columns are removed from the dataset. Rows are typically dropped when missingness is rare and random, whereas entire columns are dropped when a feature lacks a large percentage of its data and cannot be reliably imputed.

Q4. Define Exploratory Data Analysis (EDA) and explain how data visualization techniques aid in discovering dataset distributions.

Unit I CO1 | Bloom L2 3 Marks

Exploratory Data Analysis (EDA) is an analytical approach that uses summary statistics and graphical visualizations to understand the structure, distributions, and relationships within a dataset before model training.

  • Histograms and Density Plots: Visualize the frequency distribution, spread, and symmetry of continuous variables, allowing practitioners to detect whether data is normally distributed, uniform, or skewed.
  • Box Plots: Display the five-number summary (minimum, first quartile, median, third quartile, and maximum) to summarize data dispersion and immediately pinpoint statistical outliers.
  • Scatter Plots: Map two numerical features against each other on Cartesian axes to reveal linear, non-linear, or clustered relationships between variables.
  • Correlation Heatmaps: Provide color-coded matrices of correlation coefficients to systematically evaluate multicollinearity and feature interactions across the entire dataset.

Q5. Explain the role of Feature Engineering and distinguish it from feature selection.

Unit I CO1 | Bloom L2 3 Marks

Feature Engineering is the process of using domain knowledge and mathematical techniques to transform raw data into new, informative features that help algorithms learn patterns more effectively.

  • Role of Feature Engineering: It extracts relevant information that may not be directly accessible in raw attributes, such as creating interaction terms, combining date components into time intervals, or applying logarithmic transformations to skewed variables. Q18. Explain the Ordinary Least Squares (OLS) estimation method and state the objective function it minimizes.

Objective Function Minimized:

The objective function is the Residual Sum of Squares (RSS), mathematically expressed as:

Minimize RSS = Σ (yi - ŷi)² = Σ (yi - (β0 + β1xi))² (summed over all n data points)

Key Principles:

  • Elimination of Sign Cancellation: Squaring each residual ensures that positive and negative errors do not cancel each other out during aggregation.

Q20. Explain how Gradient Descent updates parameters iteratively to find the optimal slope and intercept.

Unit II CO2 | Bloom L2 3 Marks Score: 9.7

Gradient Descent is an iterative optimization algorithm used to minimize a model's cost function by updating parameters in the direction of steepest descent.

Update Mechanism:

  • Initialization: The algorithm starts with initial values for the slope (θ1) and intercept (θ0), typically initialized to zero or small random values.
  • Gradient Calculation: At each iteration, it computes the partial derivatives of the cost function J(θ) with respect to each parameter (∂J/∂θ0 and ∂J/∂θ1), which indicate the slope of the error surface.
  • Parameter Update Rule: The parameters are simultaneously adjusted in the direction opposite to the gradient:
    θ0 := θ0 - α * (∂J / ∂θ0)
    θ1 := θ1 - α * (∂J / ∂θ1)
    where α is the learning rate.
  • Convergence: This iterative loop continues until the gradients approach zero, indicating that the parameters have reached the minimum of the cost function.

Entropy in Information Theory is a quantitative measure of the impurity, randomness, or uncertainty present within a set of data.

Mathematical Expression:

H(S) = - Σ (pi * log2(pi)) (summed for i = 1 to c classes)

where pi denotes the proportion of samples in subset S belonging to class i.

Significance of Zero Entropy:

  • Perfect Purity: An entropy value of exactly zero (H(S) = 0) denotes complete purity and homogeneity in the dataset.
  • Single-Class Set: It signifies that every single observation in the dataset belongs to the exact same class (where pi = 1 and log2(1) = 0).
  • Zero Uncertainty: Because there is no ambiguity or misclassification risk, no further splitting is necessary for that node in a decision tree.

Q40. Explain Information Gain and describe how a Decision Tree algorithm uses it to select optimal node splits.

Unit III CO3 | Bloom L2 3 Marks Score: 9.3

Information Gain is a splitting criterion in decision tree learning that measures the expected reduction in entropy achieved by partitioning a dataset based on a specific attribute.

Mathematical Formulation:

Information Gain(S, A) = H(S) - Σ (|Sv| / |S|) * H(Sv)

where H(S) is the entropy of the parent set S, and Sv is the subset created when attribute A takes value v.

Node Split Selection Process:

  • Evaluation Across Attributes: At each tree node, the algorithm calculates the Information Gain for every candidate feature available.
  • Maximizing Uncertainty Reduction: The attribute that produces the highest Information Gain is selected as the splitting feature for that node.
  • Iterative Partitioning: Splitting on the maximum Information Gain creates child nodes that are significantly more homogeneous (purer) with respect to class labels, progressively driving entropy down toward zero.

Q6. 6. Derive the Ordinary Least Squares (OLS) error minimization framework for Simple Linear Regression and state its objective function.

Unit II CO2 | Bloom L3 5 Marks Score: 9.1
Ordinary Least Squares (OLS)

Simple Linear Regression models the relationship between a dependent variable $y$ and an independent variable $x$ as: $\hat{y} = mx + c$, where $m$ is the slope and $c$ is the intercept.

Objective Function: The OLS method aims to minimize the Sum of Squared Residuals (SSR) between actual and predicted values. The cost function $J$ is:
$J(m, c) = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 = \sum_{i=1}^{n} (y_i - (mx_i + c))^2$

Derivation Framework:

  • To find the optimal $m$ and $c$, we take the partial derivatives of $J$ with respect to $m$ and $c$, and set them to zero.
  • $\frac{\partial J}{\partial c} = -2 \sum_{i=1}^{n} (y_i - mx_i - c) = 0 \implies \sum y_i = m\sum x_i + nc$
  • $\frac{\partial J}{\partial m} = -2 \sum_{i=1}^{n} x_i(y_i - mx_i - c) = 0 \implies \sum x_i y_i = m\sum x_i^2 + c\sum x_i$
  • Solving these two normal equations yields the optimal formulas for slope $m$ and intercept $c$, which represent the best-fit line minimizing the squared errors.

Q7. 7. Explain how the Gradient Descent optimization algorithm updates model weights iteratively. Contrast its performance against the analytical Normal Equation on high-dimensional datasets.

Gradient Descent vs Normal Equation

Gradient Descent (GD):

GD is an iterative optimization algorithm used to minimize a cost function $J(\theta)$. It updates model weights (parameters) by moving in the direction opposite to the gradient of the cost function with respect to the weights.

  • Update Rule: $\theta_j = \theta_j - \alpha \frac{\partial J(\theta)}{\partial \theta_j}$, where $\alpha$ is the learning rate.
  • It iteratively takes steps proportional to the negative gradient until it converges to a local or global minimum.

Contrast with Normal Equation:

  • The Normal Equation provides an analytical, closed-form solution to linear regression: $\theta = (X^T X)^{-1} X^T y$.
  • High-Dimensional Datasets: The Normal Equation requires computing the inverse of an $(n \times n)$ matrix ($X^T X$), which has a time complexity of $O(n^3)$. For large number of features (e.g., $n > 10,000$), matrix inversion becomes computationally prohibitive.
  • Gradient Descent scales much better with large numbers of features ($O(n^2)$ per iteration) and is highly preferred for high-dimensional datasets and models where analytical solutions do not exist.

Ridge (L2) vs Lasso (L1) Regularization

Regularization adds a penalty term to the cost function to prevent overfitting by penalizing large model weights.

Ridge Regularization (L2):

  • Cost Function: $J(\theta) = MSE + \lambda \sum_{i=1}^{n} \theta_i^2$

  • Therefore, Lasso can completely eliminate less important features, performing automatic feature selection, resulting in sparse models.

Logistic Regression and Sigmoid Function

Logistic Regression is a supervised learning algorithm primarily used for binary classification. Unlike linear regression, which outputs continuous values, logistic regression squashes the output of a linear equation into a probability score between 0 and 1.

The Sigmoid Activation Function:

  • The linear component is $z = W^TX + b$. We pass $z$ through the Sigmoid function $\sigma(z)$ to get probabilities.
  • Formula: $\sigma(z) = \frac{1}{1 + e^{-z}}$

Mathematical Properties:

Log-Loss (Binary Cross-Entropy)

The cost function for Logistic Regression is Log-Loss, also known as Binary Cross-Entropy.

Formula:

$J(\theta) = -\frac{1}{m} \sum_{i=1}^{m} \left[ y^{(i)} \log(h_\theta(x^{(i)})) + (1 - y^{(i)}) \log(1 - h_\theta(x^{(i)})) \right]$

Where $h_\theta(x)$ is the sigmoid predicted probability and $y$ is the actual binary label (0 or 1).

Why MSE is Unsuitable:

  • If we use standard Mean Squared Error (MSE) for Logistic Regression, the cost function becomes $J(\theta) = \frac{1}{2m} \sum (\sigma(W^TX) - y)^2$.
  • Because the sigmoid function $\sigma$ is non-linear, squaring it results in a non-convex cost function landscape with multiple local minima.
  • Gradient Descent is prone to getting stuck in these local minima, failing to find the global optimum.
  • Log-Loss, conversely, guarantees a convex cost function with a single global minimum, penalizing confident wrong predictions heavily using logarithms.

Naive Bayes Classifier

The Naive Bayes classifier is a probabilistic machine learning model based on Bayes\' Theorem, widely used for text classification tasks like spam filtering.

Mathematical Foundation:

  • Bayes\' Theorem states: $P(y|X) = \frac{P(X|y) \cdot P(y)}{P(X)}$
  • Where $P(y|X)$ is the posterior probability of class $y$ given features $X$.
  • $P(X|y)$ is the likelihood, and $P(y)$ is the prior probability of class $y$.

Key Assumptions (The "Naive" Aspect):

  • The core assumption is Conditional Independence of features. It assumes that the presence or absence of a particular feature (e.g., word A) is entirely independent of the presence of any other feature (e.g., word B), given the class variable.
  • Mathematically, the likelihood is decomposed as: $P(X|y) = P(x_1|y) \times P(x_2|y) \times \dots \times P(x_n|y)$.
  • Despite this assumption almost never holding perfectly true in real-world data (words in sentences are usually correlated), Naive Bayes often performs surprisingly well in practice.

Support Vector Machines (SVM)

SVM is a powerful algorithm that finds an optimal boundary between classes in an $N$-dimensional space.

  • Hyperplane: The decision boundary separating different classes. In 2D space, it\'s a line; in 3D, a flat plane.
  • Support Vectors: The specific data points lying closest to the hyperplane. They act as pillars; if they are moved or removed, the position of the dividing hyperplane alters. The algorithm only cares about these vectors.

Q20. 20. Construct a standard Confusion Matrix. Write the mathematical formulas for Accuracy, Precision, Recall, and F1-Score, explaining why F1-Score is critical for class-imbalanced data.

Confusion Matrix and Metrics

Confusion Matrix: A $2 \times 2$ table used to evaluate binary classification performance.

  • True Positive (TP): Predicted Positive, Actual Positive
  • True Negative (TN): Predicted Negative, Actual Negative
  • False Positive (FP - Type I Error): Predicted Positive, Actual Negative
  • False Negative (FN - Type II Error): Predicted Negative, Actual Positive

Evaluation Formulas:

  • Accuracy: $\frac{TP + TN}{TP + TN + FP + FN}$. The overall correct predictions.
  • Precision: $\frac{TP}{TP + FP}$. Out of all predicted positives, how many were actually positive?
  • Recall (Sensitivity): $\frac{TP}{TP + FN}$. Out of all actual positives, how many did the model find?
  • F1-Score: $2 \times \frac{Precision \times Recall}{Precision + Recall}$ (Harmonic Mean).

Importance of F1-Score for Imbalanced Data:
If a dataset has 99% Negative and 1% Positive instances, a model predicting "Negative" every time achieves 99% accuracy but fails its actual purpose. F1-Score completely ignores True Negatives, focusing strictly on the model\'s ability to correctly balance identifying the minority Positive class (Recall) without generating excessive false alarms (Precision).
