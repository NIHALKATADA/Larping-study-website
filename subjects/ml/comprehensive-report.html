Unit I: Machine Learning Basics & Lifecycle

Machine Learning Paradigms & Evolution

  • Supervised Learning: Trained on labeled data (input and targets) to predict future outcomes. Applications include Regression and Classification.
  • Unsupervised Learning: Trained on unlabeled data to discover hidden patterns and groupings. Applications include Clustering and Dimensionality Reduction.
  • Reinforcement Learning: Learns through interaction with an environment via a feedback loop of actions and rewards.
  • Historical Evolution: Transitioned from hard-coded rule-based systems to data-driven automated learning systems with distinct taxonomy models.
Exam Trap: Remember that Unsupervised Learning has NO target labels, whereas Supervised Learning always requires targets!
Now that we have a solid grasp of Machine Learning Paradigms & Evolution, the natural next step is to explore The 7-Step Machine Learning Lifecycle & Data Processing.

The 7-Step Machine Learning Lifecycle & Data Processing

  • Data Collection/Fetching: Gathering raw data. Fetching strategies impact downstream efficiency.
  • Data Cleaning: Handling missing values (e.g., imputation or dropping) and outliers to avoid degrading model fitting.
  • Exploratory Data Analysis (EDA): Understanding distributions using summary statistics and visualization techniques (e.g., histograms). Primary objective is discovering underlying data structures.
  • Feature Engineering: Transforming data. Categorical Label Encoding converts categories into numbers required by ML algorithms. Feature Scaling (Normalization/Standardization) ensures features have a similar scale to speed up gradient descent and prevent biased fits.
  • Model Training/Fitting: Optimizing weights so the model maps inputs to targets. Python is chosen for its immense ML ecosystem.
  • Model Validation: Crucial to ensure the model generalizes to new data rather than memorizing training samples.
  • Prediction/Deployment: Final stage for inference.
  • Feature Selection: Different from engineering, this focuses on selecting the most informative subset of independent variables.
Pro-Tip: Missing values or unscaled data are guaranteed to degrade downstream model fitting! Always preprocess raw data.
With The 7-Step Machine Learning Lifecycle & Data Processing in mind, we can see why Variables & Linear Regression Numerical Problems becomes crucial in this context.

Variables & Linear Regression Numerical Problems

  • Independent Variables (Predictors): The features (X) used to make predictions.
  • Dependent Variables (Targets): The outcome (Y) we want to predict.
Example: For model y = 12 + 4.5x (x=ads in thousands, y=sales), intercept is 12 and slope is 4.5. If x=8, y = 12 + 4.5*8 = 48 thousand sales.

Unit II: Regression Models & Optimization

Regression Hypotheses & Ordinary Least Squares

  • Simple LR Hypothesis: h_theta(x) = theta_0 + theta_1*x.
  • Multiple LR Equation: y = b0 + b1x1 + ... + bnxn.
  • Residual Error (ei): Difference between actual y and predicted y_hat. Geometric interpretation: vertical distance from point to line.
  • OLS Objective: Minimize the sum of squared residual errors.
To fully appreciate Cost Functions & Gradient Descent, we must apply what we just learned about Regression Hypotheses & Ordinary Least Squares.

Cost Functions & Gradient Descent

  • MSE Cost Function J(theta): 1/(2m) * sum(h_theta(x) - y)^2. Used for optimizing regression parameters.
  • Gradient Descent: Iteratively updates weights to minimize the cost function. Preferred over the Normal Equation for high-dimensional data due to better scaling.
  • Learning Rate (alpha): Determines step size. Too high = divergent overshoot; too low = slow convergence.
Exam Trap: Gradient Descent requires feature scaling to ensure smooth and rapid convergence!
Having established the core principles of Cost Functions & Gradient Descent, we now turn our attention to Polynomial Regression.

Polynomial Regression

  • Definition: Fits non-linear curves to data by introducing higher-degree terms (e.g., x^2).
  • Classification: It remains a linear model because it is linear with respect to its coefficients (weights), despite fitting a non-linear relationship.
With Polynomial Regression in mind, we can see why Overfitting, Underfitting & Bias-Variance Tradeoff becomes crucial in this context.

Overfitting, Underfitting & Bias-Variance Tradeoff

  • Overfitting (High Variance): Model learns noise and training data too well. Causes: highly complex model, small dataset. High training accuracy, low testing accuracy.
  • Underfitting (High Bias): Model is too simple to capture data patterns. Causes: overly simple model. Poor training and testing accuracy.
  • Bias-Variance Tradeoff: As complexity increases, bias drops but variance rises. We aim for optimal generalization.
Pro-Tip: Use Regularization or add more data to fix Overfitting. Increase model complexity to fix Underfitting.
While Overfitting, Underfitting & Bias-Variance Tradeoff gives us the theoretical background, Regularization (Ridge vs Lasso) provides the next layer of complexity.

Regularization (Ridge vs Lasso)

  • Regularization: Adds a penalty term to the cost function to restrict weights.
  • Ridge (L2): Adds squared weights penalty. Shrinks coefficients but rarely zeros them.
  • Lasso (L1): Adds absolute weights penalty. Can zero out coefficients, thus performing automatic feature selection.
Having established the core principles of Regularization (Ridge vs Lasso), we now turn our attention to Regression Evaluation Metrics.

Regression Evaluation Metrics

  • MAE: Mean Absolute Error. Average absolute differences.
  • MSE: Mean Squared Error. Average squared differences. Heavily penalizes outliers.
  • RMSE: Root Mean Squared Error. Better interpretation as it's in the same units as the target.
  • R-Squared (R2): Measures proportion of variance explained (0 to 1).
  • Adjusted R2: Penalizes the addition of useless predictors, making it superior for Multiple Linear Regression.

Unit III: Classification & Ensemble Methods

Logistic Regression & Classification Basics

  • Sigmoid Activation: sigma(z) = 1 / (1 + e^-z). Output range is (0, 1), converting real values to probabilities.
  • Decision Boundary: Standard threshold is 0.5.
  • Log-Loss (Binary Cross-Entropy): Single sample = -[y*log(p) + (1-y)*log(1-p)]. Standard MSE is unsuitable because it is non-convex for classification.
With Logistic Regression & Classification Basics in mind, we can see why K-Nearest Neighbors (KNN) becomes crucial in this context.

K-Nearest Neighbors (KNN)

  • Core Mechanism: Calculates distance to all points, finds K nearest, uses majority voting.
  • Distance Metrics: Euclidean (sqrt(sum((xi-yi)^2))).
  • K Tuning: K too small = Overfitting (jagged boundary). K too large = Underfitting (oversmoothed boundary).
While K-Nearest Neighbors (KNN) gives us the theoretical background, Decision Trees & Information Theory provides the next layer of complexity.

Decision Trees & Information Theory

  • Entropy: H = -sum(p * log2(p)). Zero means perfect purity.
  • Gini Impurity: 1 - sum(p^2). Computationally faster than entropy.
  • Information Gain: Entropy(Parent) - Weighted_Entropy(Children). Used to determine optimal splits.
To fully appreciate Naive Bayes & SVM, we must apply what we just learned about Decision Trees & Information Theory.

Naive Bayes & SVM

  • Bayes' Theorem: P(A|B) = [P(B|A) * P(A)] / P(B) (Posterior = Likelihood * Prior / Evidence).
  • 'Naive' Assumption: Assumes features are conditionally independent given the class.
  • SVM Hyperplane & Margin: Hyperplane separates classes. Support vectors are the closest points. Margin is the gap between them.
  • Hard vs Soft Margin: Hard strictly separates; Soft uses slack variables (Hinge Loss) to permit errors on non-separable data.
  • Kernel Trick: (Linear, Polynomial, RBF) maps data into higher dimensions for linear separability.
Transitioning from Naive Bayes & SVM, we now examine Ensemble Methods & Metrics, which builds upon these foundational rules.

Ensemble Methods & Metrics

  • Bagging (Random Forests): Independent parallel voting/averaging to reduce variance.
  • Boosting (AdaBoost, XGBoost): Sequential training to correct errors of previous weak learners.
  • Confusion Matrix: TP, TN, FP, FN.
  • Metrics: Accuracy = (TP+TN)/Total. Precision = TP/(TP+FP). Recall = TP/(TP+FN). F1-Score = 2(P*R)/(P+R).
  • Imbalanced Data: F1-Score is more reliable than Accuracy.
Example: For TP=80, FP=10, Precision = 80/90.
